# Resume Bullet Rewrite Worksheet

Built from Lesson 19's action + artifact + framework pattern. For each of your three capstone projects, fill in the three columns below, then assemble the final bullet. A strong bullet names a real number, a real artifact, and a real technique — not a buzzword list with nothing deployed.

## The pattern

> **Action** (what you did) + **Artifact** (what a reviewer could ask to see, or a number they could ask you to defend) + **Framework** (the real technique or tool you used)

## Final check before using any bullet

- [ ] Does it name a real, specific number (a metric, a count, a percentage) rather than an adjective like "robust" or "scalable"?
- [ ] Does it name a real artifact a reviewer could ask to see — a repo, a deployed endpoint, an audit log — rather than a vague claim of effort?
- [ ] Does it name the actual technique or framework used, not a generic "AI" or "machine learning" placeholder?
- [ ] Does this number match the same number in your project's own README, exactly? Fix any mismatch before either document goes out.
