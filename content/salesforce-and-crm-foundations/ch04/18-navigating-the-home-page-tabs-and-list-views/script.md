# Script — Navigating the Home Page, Tabs and List Views

## Segment 1 (title)

This lesson covers what's actually on screen once you're inside a Salesforce app: the Home page, the tabs bar, and list views for browsing records.

## Segment 2 (screenshot: Customer Service home)

This is the Customer Service app's Home page — a welcome message with office hours and SLA info, plus a dashboard showing Current Open Cases and Open High Priority or Escalations. Compare this to the Sales app's Home page from last lesson: completely different content, even though both are called "Home." An admin builds each app's Home page separately.

## Segment 3 (screenshot: opportunities list view)

Clicking an object's tab doesn't dump every record on you — it opens a list view, a filtered, sorted table. This one is called "High Probability Opportunities," filtered to a specific slice of the Opportunity object and sorted by name.

## Segment 4 (screenshot: list view picker)

Clicking the list view's name opens this picker — Recent List Views, All Other Lists — a fast way to jump between every saved view for this object without leaving the page.

## Segment 5 (code: what you can do)

Inside any list view, you can switch views instantly, sort by clicking a column header, filter down by any field's value, and create and save a brand new list view, either private to you or shared with a group. Building the right list view beats scrolling through hundreds of records looking for the ones you actually need.
