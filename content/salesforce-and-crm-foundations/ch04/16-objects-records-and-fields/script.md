# Script — Objects, Records and Fields

## Segment 1 (title)

Welcome to Chapter 4. Chapter 3 was about how Salesforce works under the hood — starting here, it's about actually using it. This lesson covers the three-level data model you'll rely on constantly: objects, records, and fields.

## Segment 2 (code: spreadsheet analogy)

Think of it like a spreadsheet. The object is the spreadsheet itself — like Account. A record is one row — like "Acme Corp." A field is one column — like Industry or Phone. An object's fields are metadata, the blueprint from Lesson 13. A record's actual field values are data.

## Segment 3 (steps: standard vs custom)

Salesforce ships with standard objects already built — Account, Contact, Lead, Opportunity, Case, and dozens more, ready to use with no setup. When a business has data that doesn't fit any of those, admins create custom objects, which behave exactly like standard ones once built.
