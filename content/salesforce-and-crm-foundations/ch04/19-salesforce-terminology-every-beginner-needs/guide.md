## Why a dedicated glossary lesson

You've covered a lot of ground across Chapters 1 through 4 — CRM concepts, the Salesforce ecosystem, platform architecture, and now the interface itself. Salesforce also has a notoriously dense internal vocabulary, and mixing up two similar-sounding terms (like "object" and "app," or "profile" and "permission set") is one of the most common ways beginners get confused in their first few weeks. This lesson is a deliberate pause to consolidate everything into one place.

## Platform & architecture (Chapters 2–3)

| Term | Meaning |
|---|---|
| Org (organization) | A company's own isolated environment on the Salesforce platform |
| Multitenancy | One shared application/infrastructure serving many customers, with data isolated per org |
| Instance (pod) | The specific server cluster an org is physically hosted on |
| Edition | The product tier (Essentials, Professional, Enterprise, Unlimited, Developer) |
| License | A per-user grant of access (user license, permission set license, feature license) |
| Metadata | The blueprint/configuration that defines how an org's structures and behavior work |
| Release | A platform-wide upgrade, shipped three times a year (Spring, Summer, Winter) |
| trust.salesforce.com | Salesforce's public site for live status, security, and compliance information |

## Interface & navigation (Chapter 4)

| Term | Meaning |
|---|---|
| Object | The definition of a type of thing tracked (Account, Contact, Opportunity, etc.) |
| Record | One specific instance of an object |
| Field | One piece of information on a record |
| App | A curated, named bundle of tabs for a specific job function |
| App Launcher | The "waffle" icon used to switch apps and search for objects |
| Lightning Experience | Salesforce's current, modern user interface |
| Tab | A link to one object's list of records |
| List view | A filtered, sorted table of an object's records |
| Home page | An app's configurable landing dashboard |

## A few more you'll meet constantly going forward

- **Setup** — the admin control panel for every configuration option in an org, reached via the gear icon.
- **Profile** — the baseline access-control record every user has exactly one of.
- **Permission set** — an additional, stackable grant of access layered on top of a profile.
- **Flow** — Salesforce's modern declarative automation tool (you'll build these hands-on later in this career path).
- **Report** — a customizable, tabular or summarized view of record data, often the foundation for a dashboard.
- **Dashboard** — a visual collection of charts and components, usually built from one or more reports.
- **AppExchange** — Salesforce's marketplace for installable third-party apps and components (Lesson 9).
- **Sandbox** — a separate copy of an org used for testing, safely isolated from live Production data.
- **Admin** — the person (possibly you, soon) responsible for configuring and maintaining an org.
