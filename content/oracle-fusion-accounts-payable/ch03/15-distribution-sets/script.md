# Script — Distribution Sets

## Segment 1 (title)

Last lesson showed how a single invoice's lines turn into distributions. But some invoices are the same shape every time - the monthly rent bill always splits the same way between the same two departments. Re-entering that split every month is exactly what a distribution set automates away.

## Segment 2 (steps)

A distribution set is a predefined template of distribution lines - GL accounts, optionally with percentages - that you select once on an invoice. Instead of manually entering distributions every time a recurring invoice comes in, you pick the set and the accounting generates itself.

## Segment 3 (code)

A Full distribution set fixes both the accounts and the percentage split, and those percentages must total exactly 100. A set built for Brightfield's rent might be 70% Sales facility, 30% Admin facility - select it on any rent invoice, any amount, and Payables creates that exact split automatically.

## Segment 4 (steps)

A Skeleton distribution set fixes only the accounts, leaving amounts at zero for someone to fill in at entry time. That's useful when the right accounts never change, but the split does - say, a shared cost split by headcount that's different every month. You still skip re-selecting the accounts; you just type in that month's numbers.

## Segment 5 (outro)

A ten thousand dollar rent invoice against that 70/30 Full set produces a seven thousand and a three thousand dollar distribution with nobody re-typing the split. Up next, lesson sixteen: invoice import overview, for invoices that arrive in bulk rather than one at a time.
