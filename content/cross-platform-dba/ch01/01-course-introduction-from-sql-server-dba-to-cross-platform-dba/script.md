# Script — Course Introduction: From SQL Server DBA to Cross-Platform DBA

## Segment 1 (title)

This course closes out the SQL Server Database Administrator path, but it isn't another SQL Server course. It asks what happens when the job also includes Oracle, MySQL, or PostgreSQL, because that's what the company actually runs.

## Segment 2 (code: what transfers)

Every DBA instinct from this path transfers directly — measure before you change something, a recovery model determines what's restorable, an untested backup isn't a real backup. Those are relational database facts, not SQL-Server-specific facts. What doesn't transfer is syntax, tooling, and architecture detail.

## Segment 3 (steps: why these three platforms)

Oracle, MySQL, and PostgreSQL alongside SQL Server cover the large majority of real-world relational deployments. Oracle dominates large enterprise and legacy systems, MySQL is everywhere in web applications, and PostgreSQL is the default for new open-source projects.

## Segment 4 (outro)

This course teaches each platform on its own terms, the same discipline Azure Database Administrator used for the cloud. Next up: why organizations end up running multiple database platforms in the first place.
