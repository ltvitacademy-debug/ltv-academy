# Script — Comparing SQL Server, Oracle, MySQL & PostgreSQL at a Glance

## Segment 1 (title)

This lesson is a map, not a deep dive. Before Chapter 2 spends five lessons on Oracle alone, it's worth stepping back and seeing how all four platforms sit next to each other.

## Segment 2 (code: the comparison at a glance)

SQL Server: commercial, per-core, enterprise Windows shops. Oracle: commercial, often the most expensive, entrenched in large enterprise and legacy systems. MySQL: open source, powers a huge share of the web. PostgreSQL: fully open source, the default for new projects, increasingly common in enterprise too.

## Segment 3 (steps: a few honest caveats)

Oracle Corporation actually owns MySQL today. Open source doesn't mean free of all cost at scale. And typical use case describes tendencies, not rules — you'll find Oracle running web apps and PostgreSQL running core finance systems.

## Segment 4 (outro)

Licensing pressure and use-case fit are two of the real reasons companies end up multi-platform. Next up: setting up your own cross-platform lab environment.
