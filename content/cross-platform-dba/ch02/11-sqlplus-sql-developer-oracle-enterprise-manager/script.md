# Script — SQL*Plus, SQL Developer & Oracle Enterprise Manager

## Segment 1 (title)

Chapter 2 closes with the tools a DBA actually opens day to day. Oracle's tooling landscape maps loosely onto the sqlcmd, SSMS, and monitoring-dashboard split a SQL Server DBA already knows — but each tool here has its own real identity and audience.

## Segment 2 (steps: three tools)

SQL*Plus is Oracle's original command-line client, used for scripts and admin one-liners. SQL Developer is Oracle's free, Java-based GUI IDE for browsing schemas and writing SQL and PL/SQL day to day. Oracle Enterprise Manager handles monitoring — EM Express for a single database, Cloud Control for many databases across an organization.

## Segment 3 (code: SQL*Plus session)

A typical SQL*Plus session is about as lightweight as it gets: connect with a net service name, run SQL directly at the prompt, exit when you're done. It's the closest thing Oracle has to sqlcmd — scriptable and always available, no GUI required.
