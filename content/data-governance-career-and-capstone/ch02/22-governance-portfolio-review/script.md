# Lesson 22 — Governance Portfolio Review · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

This lesson walks through your own portfolio the exact way a hiring manager will, so nothing in it surprises you in the room.

## S2 · STEPS — The order reviewers look in

Reviewers skim in a predictable order. The one-page executive summary first — can you explain the whole thing in one page. Then the glossary — is it specific, with named owners. Then the SQL — is it real and correctly written for the failure case. Then the lineage diagram and the RACI matrix — real hops, and exactly one Accountable role per activity.

## S3 · STEPS — Questions each artifact must survive

Each artifact type has a signature follow-up. For the glossary: why this exact definition and not a slightly different one. For the SQL: walk me through this WHERE clause, row by row. For the lineage diagram: what if the break were at a different hop. For the RACI matrix: who is the one Accountable role, and why them.

## S4 · STEPS — Pre-share checklist

Before you send a link to anyone: no real company names or data anywhere. Every document marked clearly as a fictional training capstone. A named author and date on everything. Numbers that match across every document. And every SQL script actually runs.
