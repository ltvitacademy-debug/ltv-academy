# Lesson 15 — Assembling the Deliverables · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Fourteen lessons of separate artifacts need to become one package
before anything else in this chapter can start.

## S2 · STEPS CARD (the gathering problem)

Right now it's scattered: a charter in a lab response, a CDE list in
one lesson, SQL checks in a third. This lesson gathers all fourteen
into one numbered package — Lesson 16 writes the synthesis on top of
it.

## S3 · CODE CARD (files 1-7)

The package starts with the charter, landscape inventory, CDE
register, RACI, glossary and dictionary, classification, and the
quality-check SQL — files one through seven, numbered in build order.

## S4 · CODE CARD (files 8-14)

Files eight through fourteen continue it: lineage, authoritative
sources, access and retention policy, KPIs and workflow, the
operating model, the AI governance strategy, and the architecture.

## S5 · STEPS CARD (consistency check)

Marcus runs four checks before calling it done: name consistency
across files, CDE consistency between the register and later
documents, decision consistency between Lesson 9 and Lesson 14, and
whether every file says when it was last reviewed.

## S6 · STEPS CARD (why it matters)

The check catches real drift — DateOfBirth shows up in Lesson 6's
classification but not Lesson 3's register. A package with silent
inconsistencies is worse than one with an honest gap, because it
looks finished when it isn't.

## S7 · OUTRO CARD

Next: Lesson 16 turns this assembled package into one written
enterprise governance strategy document.
