# Lesson 1 — Capstone Kickoff: The LTV Global Scenario · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Welcome to the capstone. Over the next several lessons you'll build one
complete data governance program for a single fictional company — LTV
Global — applying everything you've learned across this entire career
path.

## S2 · STEPS CARD (the company)

LTV Global is a fictional, illustrative mid-sized multinational
consumer-products company — outdoor and home goods, roughly forty-eight
hundred employees, headquartered in Atlanta with offices in Leeds and
Singapore. It is not a real business; it exists purely so this capstone
has one consistent scenario to build against.

## S3 · STEPS CARD (the systems)

Its data lives in five fictional systems: Atlas, the ERP system of
record for orders and products; Beacon, the sales CRM; Comet, the
e-commerce storefront; Harbor, the warehouse system; and Summit, the
governed analytics layer almost nothing feeds reliably today.

## S4 · STEPS CARD (the trigger)

A UK customer's data access request took six weeks and four
departments to answer, and two systems returned different order
histories for the same person. That gap reached the board, and new
Chief Data Officer Dana Whitfield was given a mandate to build a real
governance program, starting now.

## S5 · STEPS CARD (what this capstone builds)

Over the next eleven lessons you'll build one continuous deliverable
set: a data landscape inventory, scored critical data elements, named
owners and stewards, a glossary and dictionary, sensitivity
classification, real SQL quality checks, a lineage trace, authoritative
sources, access and retention policies, governance KPIs, and finally an
operating model.

## S6 · OUTRO CARD

Next: Lesson 2 reviews LTV Global's full data landscape — mapping every
system before you can govern any of them.
