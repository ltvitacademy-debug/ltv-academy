# Script — The AWS Certification Landscape, Overview

## Segment 1 (title)

Last lesson of this course: a real, honest look at the AWS certification landscape — what it actually covers, and where AWS Fundamentals fits into it.

## Segment 2 (steps: four tiers)

AWS organizes certifications into four tiers. Foundational, the Cloud Practitioner exam, is a broad overview. Associate is role-focused and hands-on. Professional goes deep on multi-service, scenario-heavy tradeoffs. Specialty goes narrow and deep on one domain.

## Segment 3 (code: the Associate tier, by role)

The Associate tier splits by role: Solutions Architect, Developer, SysOps Administrator — and a newer one, Data Engineer Associate, which tests exactly this course's territory. Worth knowing it replaced an older Specialty-tier data certification — AWS revises this lineup as the platform and job market change.

## Segment 4 (steps: read the landscape honestly)

The honest way to use this landscape: match the tier to work you're actually doing. Cloud Practitioner roughly matches this course. Data Engineer Associate roughly matches the course that comes next. Don't chase the badge that sounds most impressive — chase the one that matches your actual track.
