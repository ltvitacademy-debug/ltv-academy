## Four tiers, not one ladder everyone has to climb

AWS organizes its certifications into four tiers. They're not a
strict prerequisite chain — you don't have to pass every Associate
exam before attempting a Professional one — but they do represent a
real progression in scope and depth.

```
Foundational   Cloud Practitioner — broad, non-technical-friendly
               overview of AWS services, pricing, and support

Associate      Role-focused, hands-on: Solutions Architect,
               Developer, SysOps Administrator, Data Engineer

Professional   Deep, scenario-heavy: Solutions Architect Pro,
               DevOps Engineer Pro — multi-service, real-world
               tradeoff questions, not single-service recall

Specialty      Narrow and deep on one domain: Security, Machine
               Learning, Advanced Networking, and others
```

## Foundational: AWS Certified Cloud Practitioner

The entry point — this is roughly the scope of this entire course:
what AWS is, core services at a glance, pricing models, the shared
responsibility model, basic security concepts. It's a legitimate
credential on its own for non-engineering roles, and a reasonable
first target if you want an exam to validate this course's material
specifically.

## Associate: the hands-on, role-focused tier

Three long-standing Associate certifications split by role:

```
Solutions Architect – Associate   designing resilient,
                                   cost-effective architectures
Developer – Associate             building and deploying
                                   applications on AWS
SysOps Administrator – Associate  operating and monitoring
                                   AWS workloads day to day
```

A fourth, newer Associate certification is the one most directly
relevant to this course's track: **AWS Certified Data Engineer –
Associate**, which tests exactly the territory this course and the
AWS Data Engineering course that follows it are built around — data
ingestion, transformation, storage, and orchestration on AWS. It's
worth knowing this certification replaced an older Specialty-tier
data credential, which is a useful reminder that AWS's certification
lineup isn't static — it's revised as the platform and the job market
change.

## Professional and Specialty: depth over breadth

Professional-tier exams (Solutions Architect Professional, DevOps
Engineer Professional) assume Associate-level fluency and test
multi-service tradeoffs under realistic constraints — cost versus
resilience, migration strategy, multi-account governance. Specialty
exams go deep on one domain instead — Security, Machine Learning, and
Advanced Networking are the long-running ones — and are worth pursuing
only once you actually work in that domain, not as a general resume
line.

## Reading a certification honestly

A certification tests what you can recall and reason through under
exam conditions — it doesn't replace building things. The most useful
way to use this landscape: pick the tier and specialty that matches
work you're actually doing or about to do, not the one that sounds
most impressive on paper.

## Where this course leaves you

This course covered the cloud and AWS fundamentals — accounts, IAM,
core services, networking basics, cost, the CLI and SDK — that
**AWS Data Engineering**, the next course in this path, assumes you
already have. That's the honest scope of AWS Fundamentals: not a
certification prep course, but the foundation everything after it is
built on.

```
AWS Fundamentals (this course)  →  AWS Data Engineering
      accounts, IAM, core            S3, Glue, Redshift, Athena,
      services, CLI/SDK               Lambda, Kinesis, Step
                                      Functions, DMS — real depth
```

## Key terms

| Term | Meaning |
|---|---|
| Foundational tier | Cloud Practitioner — broad, entry-level AWS overview |
| Associate tier | Role-focused, hands-on exams (Solutions Architect, Developer, SysOps, Data Engineer) |
| Professional tier | Deep, multi-service, scenario-based exams |
| Specialty tier | Narrow, deep exams on one domain (Security, Machine Learning, Networking) |
| AWS Certified Data Engineer – Associate | The Associate-tier certification most directly aligned with this course's track |
