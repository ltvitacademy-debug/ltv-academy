# Script — What Is AWS?

## Segment 1 (title)

AWS launched in 2006 and remains the largest public cloud provider by market share — well over 200 individual services, available on demand, billed by actual usage.

## Segment 2 (code: not one product)

AWS isn't a single thing you turn on — it's a catalog of services: S3 for storage, Glue for ETL, Redshift for warehousing, Lambda for compute, and two hundred more, each its own tool, used together.

## Segment 3 (steps: not a translation exercise)

If you've already worked through an Azure course in this catalog, resist mapping every AWS service directly onto its closest Azure equivalent. Some ideas transfer — object storage is object storage — but AWS has its own service boundaries and idioms this course teaches on their own terms.

## Segment 4 (outro)

Cloud and AWS fundamentals first — everything AWS Data Engineering's real depth will assume you already have. Next up: AWS's global infrastructure — regions and availability zones.
