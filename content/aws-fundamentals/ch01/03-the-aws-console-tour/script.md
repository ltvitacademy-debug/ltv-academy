# Script — The AWS Console, Tour

## Segment 1 (title)

The AWS Management Console is the browser-based front end to your whole account — one consistent web app fronting all two hundred-plus services, not a separate site for each one.

## Segment 2 (code: region selector)

The most important control on the page is the Region selector, top right. Almost everything is scoped to whatever Region is currently selected — an EC2 instance you created in us-east-1 simply won't show up if you switch to eu-west-1, because it doesn't exist there.

## Segment 3 (steps: finding your way around)

With that many services, nobody memorizes a menu tree. The search bar jumps straight to a service by name, the Services menu groups everything by category for browsing, and the account menu top right holds billing, support, and your signed-in identity.

## Segment 4 (outro)

"My resource disappeared" is almost always "wrong Region selected." Next up: how AWS accounts and AWS Organizations actually work.
