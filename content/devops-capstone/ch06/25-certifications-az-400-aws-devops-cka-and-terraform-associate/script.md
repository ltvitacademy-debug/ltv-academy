# Script — Certifications: AZ-400, AWS DevOps, CKA & Terraform Associate

## Segment 1 (title)

This is it — the last lesson of the DevOps Capstone, and of the entire DevOps Engineer path. Before we close things out, let's cover four certifications worth considering next, because every one of them maps onto something you just finished building.

## Segment 2 (steps)

AZ-400 is Microsoft's DevOps certification, built around pipelines, infrastructure as code, and monitoring on Azure. AWS Certified DevOps Engineer Professional is AWS's harder, scenario-heavy equivalent. CKA tests Kubernetes administration hands-on, in a live terminal. And Terraform Associate covers the core workflow and state management, multiple choice only — the most approachable first certification of the four.

## Segment 3 (steps)

AZ-400 assumes you're already comfortable with Azure fundamentals, and covers source control strategy, CI/CD design, infrastructure as code, and monitoring — almost a checklist of what you built for Northbridge. If you're staying in the Azure ecosystem, this is the most natural next step.

## Segment 4 (steps)

AWS's professional-tier exam assumes real hands-on AWS time and leans heavily on scenario questions. The capstone used Azure, not AWS, but the underlying skills transfer directly — promotion gates, credential-free secrets, incident response built on golden signals. What's actually new is mostly AWS's own service names.

## Segment 5 (code)

CKA is different from the other three — it's a fully hands-on exam in a live terminal, not multiple choice. You're handed a real cluster and asked to troubleshoot a broken deployment or debug a failing readiness probe, under a time limit. That's exactly the kubectl fluency you built running AKS and debugging this capstone's own services.

## Segment 6 (steps)

Terraform Associate is the most approachable of the four, and the capstone's own state-collision story is almost exam material directly — understanding why remote state and locking matter, not just memorizing the commands, is exactly what this exam rewards.

## Segment 7 (outro)

You started this course with two services that only ran on a laptop. You've since provisioned real infrastructure, survived a state-locking collision, built a pipeline that promotes all the way to production behind an approval gate, run a real incident drill, caught a secrets leak before it ever reached git history, and turned every bit of it into a resume and real interview answers. That's the complete loop this path set out to teach. Congratulations on finishing the DevOps Engineer path.
