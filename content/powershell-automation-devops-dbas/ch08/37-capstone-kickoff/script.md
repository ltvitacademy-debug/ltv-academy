## Segment 2 (steps: the manual routine, right now)

Meet Meridian Outfitters: an outdoor-gear e-commerce retailer with one full-time DBA, Priya Nair. Today her routine is almost entirely manual — backups run by hand most nights, a 40-minute morning health check done by eyeball, and schema changes deployed from emailed scripts pasted straight into production.

Over the next five lessons you'll build MeridianDBAOps: real PowerShell automation for backups, health checks, and maintenance; a source-controlled CI/CD pipeline for schema changes; and monitoring tuned so Priya isn't paged for every transient blip.
