# Script — Account Balances and Inquiries

## Segment 1 (title)

Welcome to Chapter 5: Balances, Inquiries and Monitoring. Every journal you've posted so far has been quietly updating a summarized balance behind the scenes. This lesson is about reading those balances back out, starting with the Inquire on Detail Balances page.

## Segment 2 (steps)

Posting a journal does two things. It stores the detail — the actual journal lines, forever. And it updates a summarized balance for that account combination, for that period, for that balance type. When you check "how much is in this account," you're reading the summarized balance, not re-adding every journal line by hand.

## Segment 3 (steps)

Inquire on Detail Balances is where that lookup happens. Give it a ledger, a period, and an account combination — even a partial one, like "all cost centers under Division 100" — and it returns the balance, with options to pivot the view.

## Segment 4 (code)

Here's a real inquiry for LTV Manufacturing Corporation: Utilities Expense, Corporate cost center, period March 2026. The same account returns different numbers depending on which time frame you pick — period-to-date for just March, or year-to-date for everything since the fiscal year began.

## Segment 5 (steps)

Mixing those up is one of the most common mistakes. Balance sheet accounts like Cash are always read year-to-date, because cash doesn't reset each period. Income statement accounts are usually read period-to-date when you want to know what one month cost.

## Segment 6 (outro)

An inquiry is usually just the starting point — if a balance looks wrong, the next move is to drill into the journal lines behind it, which we cover fully in lesson 27. Up next, lesson 23: Account Monitor, a live watchlist built on these same balances.
