# Lesson 19 — Automated vs. Manual Lineage · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Lesson 17 and 18 covered what to document and how to draw it. This
lesson covers how it actually gets built and kept current — by hand,
by a tool, or, in practice, usually some of both.

## S2 · STEPS CARD (manual lineage)

Manual lineage is written by hand — a diagram, a wiki page, a mapping
spreadsheet. Cheapest way to start: no tooling, just someone who
understands the pipeline writing it down. The weakness is durability
— it's accurate the day it's drawn, and nothing after that.

## S3 · STEPS CARD (automated lineage)

Automated lineage is generated by a tool scanning actual pipeline
code, queries, or execution logs — building the graph from what the
code does, not what someone remembers. Re-run the scan after a code
change, and the graph updates with it.

## S4 · STEPS CARD (the real blind spot)

The trade-off: automated scanning only sees what's expressed in code
it can parse. A manual Excel export, a one-off laptop script, a
copy-paste into another system — none of that shows up. Those
undocumented hops are often where the most dangerous gaps live.
