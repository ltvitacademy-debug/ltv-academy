# Lesson 25 — Lineage Review Checklist · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE CARD

This course's closing lesson: one usable checklist pulling together all
five chapters, built to review any lineage record you're handed, or any
one you're about to build yourself.

## S2 · STEPS CARD (checklist by chapter)

Concepts — full path captured, business and technical views connected,
column-level where it matters. Tracing — real source systems, specific
transformation logic, all the way to final consumption. Dependencies —
every downstream consumer checked, fragile upstream fields flagged, a
real source of record when multiple systems overlap.

## S3 · STEPS CARD (documentation and applied practice)

Documentation — findable by someone other than the builder, with a plan
to keep it current. Applied practice — when something breaks, walk the
lineage path backward instead of re-checking everything from scratch,
and update the record itself after any fix, not just the code.

## S4 · STEPS CARD (the one habit)

Every case study in this course shared one shape: an upstream change
quietly broke an assumption nobody had written down. The habit that
catches it earlier every time: check what's downstream before assuming
an upstream change is fine.

## S5 · OUTRO CARD

That closes all 25 lessons of Data Lineage & Impact Analysis. The Data
Governance path continues next with Master & Reference Data Management
— deciding which system gets to be the one authoritative version of a
customer, a product, or an account, that everything else defers to.
