# Script — Configuration Workbooks

## Segment 1 (title)

Every fit and every approved configuration gap eventually needs to become an actual setup value inside Oracle Fusion. A configuration workbook is the structured document that captures those setup decisions before anyone touches the Setup and Maintenance work area.

## Segment 2 (steps)

Skipping the workbook and configuring straight from workshop notes loses the audit trail: nobody can see why a setting was chosen, business sign-off has nothing concrete to approve, and a technical consultant has no single source of truth for values like business unit names. The workbook makes every decision visible and traceable before it becomes a live configuration.

## Segment 3 (steps)

A workbook mirrors Oracle's own task lists inside Setup and Maintenance, one section per task list, one row per setup object. Each row captures the object name, every attribute needing a value, the proposed value, the related requirement or gap ID, and a sign-off column.

## Segment 4 (steps)

The functional consultant drafts the workbook from fit-gap outcomes and workshop decisions. The business process owner reviews and signs off each section, confirming the proposed values are actually correct for their process. Only after sign-off does it move into the Configure phase as the literal input to Setup and Maintenance.

## Segment 5 (outro)

Brightfield's workbook includes a row for its wire transfer auto-match rule on the operating account, with tolerance values drawn from the gap resolution and signed off by the Treasury Manager before anyone keys it in.
