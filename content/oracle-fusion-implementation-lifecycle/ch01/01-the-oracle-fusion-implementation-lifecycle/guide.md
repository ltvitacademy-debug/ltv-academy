## Oracle True Cloud Method

Oracle's on-premise applications (E-Business Suite and earlier) were implemented using AIM (Application Implementation Method), later replaced by OUM (Oracle Unified Method). For Fusion Cloud implementations, Oracle's current cloud-native delivery methodology is **Oracle True Cloud Method (TCM)**. TCM is agile and iterative rather than a single long waterfall, and it is organized around a set of phases: **Engage, Drive, Design, Configure, Validate, Transition, and Realize**.

TCM's guiding principle is often summarized as **"adopt, not adapt."** Instead of starting from a blank sheet and designing every process from scratch, the project starts from Oracle's pre-built reference business processes and standard functionality — sometimes called Oracle Modern Best Practice flows — and only extends or customizes where a documented business need genuinely requires it. That principle will come up again and again in this course: fit-gap analysis, configuration workbooks, and solution design all exist to enforce it.

## Oracle Cloud Success Navigator

Oracle Cloud Success Navigator (CSN) is the digital platform that operationalizes TCM. It organizes an implementation into programs and projects, gives role-specific tasks and configuration pathways, tracks milestones with entry and exit criteria for each phase, and applies a set of **Oracle Cloud Quality Standards** meant to keep the customer, the implementation partner, and Oracle aligned on scope and expectations. Think of CSN as the project's shared playbook and progress tracker — a functional consultant will see tasks assigned to them inside it, not just in a separate project plan.

## Our fictional company: Brightfield Industrial Group

Throughout this course you'll follow **Brightfield Industrial Group**, a fictional mid-size industrial equipment manufacturer implementing Oracle Fusion Financials to replace an aging on-premise system. Brightfield isn't a real Oracle customer — it's a worked example so you can see each methodology concept applied to one consistent, realistic scenario rather than a different company every lesson.

## Key terms

| Term | Meaning |
|---|---|
| Oracle True Cloud Method (TCM) | Oracle's current cloud implementation methodology; successor to OUM/AIM for Fusion projects |
| Adopt, not adapt | TCM's guiding principle: start from Oracle standard functionality, extend only where justified |
| Oracle Cloud Success Navigator (CSN) | The digital platform that tracks tasks, milestones, and quality standards for a TCM-based project |
| Oracle Modern Best Practice | Oracle's pre-built, documented reference business processes used as the implementation starting point |

## Recap

Oracle Fusion implementations run on Oracle True Cloud Method, a phased, iterative methodology built around "adopt, not adapt," tracked day to day through Oracle Cloud Success Navigator. This course walks that lifecycle from requirements through go-live and support, using Brightfield Industrial Group as a running example.
