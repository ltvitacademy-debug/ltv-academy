# Script — The Oracle Fusion Implementation Lifecycle

## Segment 1 (title)

Welcome to Oracle Fusion Implementation Lifecycle, the course that opens the Security and Implementation stage of the Oracle Fusion Financials Consultant path. Every course before this one taught you a module. This course teaches you the project a functional consultant actually works inside, from first requirement to go-live.

## Segment 2 (steps)

Oracle's current cloud implementation methodology is called Oracle True Cloud Method, or TCM. It replaced OUM, which itself replaced the older AIM methodology from the on-premise world. TCM is agile and iterative, organized around phases: Engage, Drive, Design, Configure, Validate, Transition, and Realize.

## Segment 3 (steps)

TCM's guiding principle is adopt, not adapt. Instead of designing every process from a blank sheet, the project starts from Oracle's pre-built reference business processes and standard functionality, and only extends or customizes where a documented business need genuinely requires it. You'll see that principle again in fit-gap analysis and solution design.

## Segment 4 (steps)

Oracle Cloud Success Navigator is the digital platform that operationalizes TCM. It organizes the project into programs and milestones, assigns role-specific tasks, tracks entry and exit criteria for each phase, and applies Oracle's Cloud Quality Standards to keep the customer, the partner, and Oracle aligned.

## Segment 5 (outro)

Across this course you'll follow Brightfield Industrial Group, a fictional manufacturer implementing Oracle Fusion Financials, through every phase of that lifecycle. Up next, lesson two: the roles that make up an implementation team.
