# Script — Automatic Receipts and Remittances

## Segment 1 (title)

For customers on standing direct-debit agreements, manually keying every receipt doesn't scale. Automatic receipts let Receivables create receipts itself, in bulk, for transactions that are eligible.

## Segment 2 (steps)

A transaction qualifies when the receipt method's class is set to automatic creation, the due date falls within the batch's configured lead days, and the transaction total meets the minimum receipt amount.

## Segment 3 (steps)

The batch moves through a defined sequence: create the batch, approve it as a control point, format it for the bank, confirm the receipts as final, and remit them for actual processing. A company can stop at any stage for a manual check, or run straight through.

## Segment 4 (steps)

A remittance batch groups confirmed receipts into one submission to the bank, selected by maturity date and amount, up to a configured maximum total - instead of sending one-off transactions.

## Segment 5 (outro)

Automatic receipts turn hundreds of individual entries into one controlled batch. Up next, lesson 28: lockbox processing, where the bank itself supplies the payment data.
