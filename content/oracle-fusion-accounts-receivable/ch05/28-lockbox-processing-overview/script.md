# Script — Lockbox Processing Overview

## Segment 1 (title)

Most customers still mail a check to a P.O. box the company's bank manages - a lockbox. The bank deposits the checks and sends a data file. AutoLockbox turns that file into receipts automatically.

## Segment 2 (steps)

AutoLockbox moves through three stages. Import reads the bank's file into an interface table. Validate checks the data for consistency - record counts, duplicate receipts, open periods, valid customers and transactions. Post creates the actual receipts and applies what it can.

## Segment 3 (steps)

Lockbox files aren't always perfect. A customer reference might not match anyone, an invoice number might not exist, or the transmission total might not reconcile. When validation fails, Receivables flags the problem for manual review instead of silently dropping anything.

## Segment 4 (steps)

For a business with a large volume of mailed checks, lockbox dramatically cuts manual data entry and speeds up cash application. Money gets deposited and recorded the same day it arrives.

## Segment 5 (outro)
