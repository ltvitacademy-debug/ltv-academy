# Navigating Setup

**Chapter 2 · Getting Comfortable in Setup · Lesson 6 of 14**

Chapter One got you a real org. Chapter Two is about getting comfortable *in* it — starting with
Setup, the screen you'll spend more time in than any other as a Salesforce admin.

## What you'll learn

- The three core pieces of Setup Home: Quick Find, the Home/Object Manager tabs, and Search Setup
- How the App Launcher (grid icon) differs from Setup (gear icon) — a common early mix-up
- How the Setup sidebar is organized into Administration and Platform Tools

## Opening Setup

From any Salesforce page, click the gear icon in the top right, then **Setup**. You land on Setup
Home, which has three pieces worth knowing cold:

1. **Quick Find** — the search box pinned to the top of the left sidebar. Type into it, and the
   entire sidebar filters live to match.
2. **Home / Object Manager tabs** — at the very top of the page, letting you jump between Setup's
   general pages and the Object Manager, which lists every object in the org.
3. **Search Setup** — the box at the top of the page itself, which can jump you directly to a
   specific Setup page by name, independent of which sidebar category you're currently browsing.

## App Launcher vs. Setup

A genuinely common early mix-up: the **grid icon** next to the gear opens the **App Launcher** —
for switching between installed apps and jumping to records — not Setup. The **gear icon** is what
opens Setup. They sit right next to each other in the header, which is exactly why it's worth
deliberately looking at both once so you stop hesitating between them.

## How the sidebar is organized

Setup's left sidebar is broadly split into two sections:

- **Administration** — Users, Data, Email: who has access to the org, and what the data itself
  looks like
- **Platform Tools** — Apps, Objects, Automation, and more: how the org itself is built and
  configured

**Object Manager** is deliberately pulled out of the sidebar into its own top-level tab next to
Home, because admins open it so frequently — it's the quickest way to get to any object's fields,
page layouts, and relationships.

## Key terms

| Term | Meaning |
|---|---|
| Setup | Salesforce's configuration area, opened via the gear icon |
| Quick Find | The sidebar search box that filters Setup's left-hand menu live |
| App Launcher | The grid icon for switching apps/records — not the same as Setup |
| Object Manager | Setup's dedicated tab listing every standard and custom object |
