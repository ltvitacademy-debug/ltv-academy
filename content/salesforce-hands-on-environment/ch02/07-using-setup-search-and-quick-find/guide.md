# Using Setup Search and Quick Find

**Chapter 2 · Getting Comfortable in Setup · Lesson 7 of 14**

Lesson 6 introduced Quick Find and Search Setup. This lesson goes deeper: where else Quick Find
shows up, and the actual rule for which search box to reach for.

## What you'll learn

- That Quick Find appears inside individual pages too, not just the main sidebar
- That the App Launcher's search box works on the exact same live-filter pattern
- The concrete rule for choosing between the sidebar's Quick Find and Search Setup

## Quick Find shows up more than once

The sidebar's Quick Find isn't the only Quick Find in Salesforce. **Object Manager** has its own
Quick Find box, scoped to whatever list you're currently viewing — for example, filtering an
object's **Fields & Relationships** list down to one matching field as you type. It's the same
live-filtering pattern, just scoped to a smaller list.

## The same pattern, outside Setup entirely

This live-filter behavior isn't unique to Setup. The **App Launcher**'s own search box works
identically: type a letter or two, and every matching app and item narrows instantly, with the
matching text highlighted in the results. Once you recognize this pattern, search boxes across the
rest of Salesforce stop feeling unfamiliar.

## Quick Find vs. Search Setup: the actual rule

These two boxes look similar but do different jobs:

- **Search Setup** (top of the page) searches **every Setup page in the org**, by name, no matter
  where you currently are in Setup. Use it when you already know what the page is called.
- **Quick Find** (sidebar) filters **whatever category list is currently in view**. Use it when
  you're already browsing and just want to narrow what's in front of you.
- **Object Manager's own Quick Find** filters only the list on that specific object's page (fields,
  page layouts, and so on).

A simple rule: if you know the name, search globally with Search Setup. If you're already looking
at a relevant list, filter locally with whichever Quick Find is on that page.

## Key terms

| Term | Meaning |
|---|---|
| Search Setup | Global search box at the top of Setup — finds any Setup page by name |
| Quick Find (sidebar) | Filters Setup's left-hand category list live |
| Quick Find (in-page) | The same filtering pattern, scoped to one page (e.g., Object Manager) |
