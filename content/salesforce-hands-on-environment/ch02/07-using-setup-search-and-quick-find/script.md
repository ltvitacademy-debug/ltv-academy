# Script — Using Setup Search and Quick Find

## Segment 1 (title)

Lesson 6 showed you where Quick Find and Search Setup live. This lesson is about actually using them well, including a Quick Find box you'll find in a second place entirely.

## Segment 2 (screenshot: Object Manager Quick Find)

Quick Find isn't just on Setup's main sidebar — it shows up inside pages too. Here's Object Manager's own Quick Find box, filtering an object's Fields and Relationships list down to just the one field you typed.

## Segment 3 (screenshot: App Launcher search)

This same behavior shows up everywhere in Salesforce, not just Setup. The App Launcher has its own search box that works identically: type a letter, and every matching app and item narrows live, with the matching text highlighted so you can see exactly why each result matched.

## Segment 4 (screenshot: Quick Find vs Search Setup)

So here's the real distinction. The sidebar's Quick Find, on the left, filters whatever category list is currently in view. Search Setup, at the top of the page, searches every single Setup page in the org by name, no matter where you currently are. Two boxes, two different jobs.

## Segment 5 (steps: when to use which)

So which one do you reach for? If you already know the page's name — like "Profiles" or "Flows" — use Search Setup; it finds it from anywhere. If you're already browsing a category and just want to narrow what's in front of you, use the sidebar's Quick Find. And inside Object Manager specifically, use its own local Quick Find to filter that one object's fields or layouts.
