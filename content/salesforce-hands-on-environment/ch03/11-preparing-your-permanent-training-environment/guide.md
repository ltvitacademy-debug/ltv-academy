# Preparing Your Permanent Training Environment

**Chapter 3 · Your Permanent Training Environment · Lesson 11 of 14**

Chapter Three is about treating your Trailhead Playground as a genuinely long-term tool — not
something you recreate every time a new course in this path starts.

## What you'll learn

- Why reusing one playground beats creating a new one per course
- How to rename a playground safely, any time, without affecting its login
- Where the "Install a Package" tool lives, for stocking your org with reusable apps

## Pick one org and commit to it

Unless you have a specific reason not to (for example, a lab that explicitly requires a fresh,
empty org), reuse the Trailhead Playground you created back in Lesson 3 for every course in this
path. Fragmenting your work across several different playgrounds costs you more in confusion —
remembering which org has which setup — than a single, slightly busier org ever will.

A few habits worth building now:

- **Name it something recognizable** — "LTV Training Org" beats a randomly generated name you'll
  forget in a month.
- **Log in periodically.** Long stretches of total inactivity can cause a playground to go stale.
  A recurring calendar reminder, even monthly, is enough to keep it active.

## Renaming safely

If you want to clean up the name later, go back to your [Hands-On Orgs
page](https://trailhead.salesforce.com/me/hands-on-orgs) and click **Rename** next to the org. This
only changes the label you see on that page — it has no effect on the org's actual login username,
so it's completely safe to do at any point, not just right after creation.

## Stocking your permanent org with tools

Trailhead Playgrounds include a built-in **Install a Package** tool: paste in a package's ID
directly, and it installs into your org. This is genuinely useful for a permanent training
environment — install something once, and it's there for every future lesson or lab that uses it,
instead of reinstalling it from scratch each time.

When installing, Salesforce asks **where** to install the package — into "Production" or into a
"Sandbox." For a personal training org like yours, there is no sandbox tier underneath it (sandboxes
only exist under real company production orgs, as Lesson 5 covered), so your playground is the
"Production" option here.

## Key terms

| Term | Meaning |
|---|---|
| Rename | Updates a playground's display label on Hands-On Orgs, without touching its login |
| Install a Package | A Trailhead Playground tool for installing an app/package by ID |
