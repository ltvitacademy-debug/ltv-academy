# Understanding Developer Edition Orgs

**Chapter 1 · Your Free Practice Environment · Lesson 4 of 14**

"Trailhead Playground" is a friendly label Salesforce puts on top of something with a more formal
name: a **Developer Edition** org. Understanding what that actually means helps you understand
exactly what you can and can't do in your practice org.

## What you'll learn

- Where to see an org's Organization Edition for yourself, in Setup
- What Developer Edition actually is: a real, permanent, capped license tier
- Why it still supports everything this course teaches, including AppExchange packages

## Checking an org's edition for yourself

In Setup, the **Company Information** page (covered in more depth in Lesson 9) shows an
**Organization Edition** field. Open it in your own Trailhead Playground, and it reads **Developer
Edition**. This is true of every Trailhead Playground — the friendly name is just Trailhead's label
for an org that's fundamentally a Developer Edition org underneath.

## What Developer Edition actually is

Developer Edition isn't a trial, and it isn't a stripped-down demo. It's a genuine, standing
Salesforce license tier that Salesforce offers for free specifically so people can build and
practice on the platform:

- **Not a countdown** — unlike a 30-day trial org, it doesn't expire on a fixed schedule
- **Capped, not crippled** — limited to two paid user licenses and roughly 10MB of data storage,
  which rules out running a real company but is more than enough for learning
- **Full admin feature set** — Setup, Object Manager, Flow, security and sharing, reports and
  dashboards — everything this course covers works exactly the same as it would in a paid org

## Logging in directly

Because it's a real org, it has a real username and password, exactly like any other Salesforce
login. Trailhead creates and manages those credentials for you automatically when the playground is
provisioned — you don't have to set them up by hand, though you can retrieve them any time from
your Hands-On Orgs page.

## Installing real packages

Because a Developer Edition org is a full org, it fully supports the **AppExchange** — Salesforce's
marketplace for pre-built apps and components. You can install free packages into your playground
exactly the way a real admin would install and evaluate a package before rolling it out in
production. That's a genuinely useful way to practice beyond just this course's labs.

## Key terms

| Term | Meaning |
|---|---|
| Developer Edition | The real, free, permanent Salesforce license tier a Trailhead Playground runs on |
| Organization Edition | The Company Information field that shows which edition an org is |
| AppExchange | Salesforce's marketplace for installable pre-built apps and components |
