# Script — Understanding Developer Edition Orgs

## Segment 1 (title)

You've created a Trailhead Playground. Now let's open the hood and look at what it actually is underneath that friendly name.

## Segment 2 (screenshot: Company Information page)

This is the real Company Information page in Setup, and every org has one. Look at Organization Edition — on a Trailhead Playground, it reads Developer Edition. That's not a coincidence; it's literally what a playground is built on.

## Segment 3 (steps: what Developer Edition is)

Developer Edition is a real, genuine Salesforce license tier — not a trial that counts down. It's capped, not crippled: two paid user licenses and about 10 megabytes of data storage, which is plenty for practice but not for running an actual company. Every feature an admin needs is in there — Setup, Flow, security, reports, everything this course walks through.

## Segment 4 (screenshot: Get Login Credentials)

You log into it exactly like any other Salesforce org, with a real username and password. Salesforce just creates and manages those credentials for you automatically when it provisions the playground.

## Segment 5 (screenshot: Install package)

And because it's a genuinely full org, you can install real, free AppExchange packages into it — exactly the way an admin would evaluate a package before installing it into a company's production org.
