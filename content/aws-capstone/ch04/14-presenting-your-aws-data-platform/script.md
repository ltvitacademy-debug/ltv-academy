# Script — Presenting Your AWS Data Platform

## Segment 1 (title)

Building the Northfield pipeline was the hard part. Presenting it well in an interview is a separate skill most candidates never practice — this lesson is the story arc for doing it right.

## Segment 2 (steps: the five-beat story arc)

This capstone was built in exactly the order to present it: business problem, then architecture, then the actual build. Most candidates stop there. Production practices and results are what separate a weekend tutorial from a project that proves you'd survive on a real data team.

## Segment 3 (code: live vs. describe)

Show the CloudWatch dashboard live, and run a fast Athena query if you can — both are visual and reliable. Describe the Step Functions graph, the IAM policy JSON, and the GitHub Actions workflow from a diagram instead, since console demos of dense JSON are unpredictable under interview pressure.

## Segment 4 (code: what would you do at scale)

This question comes up almost every time, and this capstone already has honest answers: DMS with change data capture for closer-to-real-time ingestion, concurrency scaling for Redshift, and a shrinking RPO through more frequent batches for disaster recovery.
