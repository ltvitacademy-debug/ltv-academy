# Script — What-If Analysis & Goal Seek

## Segment 1 (title)

Every formula normally runs forward — plug in inputs, read a result. Goal Seek runs it backward: you already know the result you want, and it solves for the input that gets you there.

## Segment 2 (steps: three fields)

It lives under Data, What-If Analysis, Goal Seek, and every run asks for the same three things. Set cell, the formula whose result you care about. To value, the exact target. By changing cell, the one input Goal Seek is allowed to adjust.

## Segment 3 (screenshot: goal seek result)

Microsoft's own example solves a loan: you know the payment you can afford, and Goal Seek finds the interest rate that gets a hundred-thousand-dollar loan to land on exactly that payment.

## Segment 4 (steps: worked example)

Here's a worked example. Unit Price times Units Sold equals Total Revenue, and you're short of a fifty-thousand-dollar target. Set cell is the Total Revenue formula, To value is fifty thousand, By changing cell is Unit Price. Run it, and Excel finds the exact price — to the cent.

## Segment 5 (steps: data table contrast)

One more distinction worth knowing. Goal Seek solves for one target using one changing input. A Data Table, under the same menu, tests many input scenarios at once instead — a different tool for a different job.
