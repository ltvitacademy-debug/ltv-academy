# Script — PivotCharts

## Segment 1 (title)

A PivotChart looks like a normal chart, but it stays linked to the PivotTable it came from — and it has one interactive feature a normal chart doesn't.

## Segment 2 (screenshot: source data)

Start with the same source data any PivotTable would use — categories down, months across.

## Segment 3 (screenshot: resulting PivotChart)

Select a cell inside the PivotTable and choose Insert Chart, and Excel builds the chart directly from that PivotTable's current rows, columns, and values. Rearrange the PivotTable's fields, and the chart updates automatically — no rebuilding required.
