# Script — Building a PivotTable

## Segment 1 (title)

A PivotTable groups and summarizes rows of source data by dragging fields into zones. Where that source data comes from — a raw range or a real Table — matters more than most people realize.

## Segment 2 (screenshot: PivotTable from table or range)

Point a PivotTable at a raw cell range, and that range is fixed forever — new rows added later won't be included until someone manually fixes the reference. Point it at a real Excel Table instead, and the PivotTable automatically expands as the Table grows.

## Segment 3 (screenshot: Insert PivotTable pane)

Insert > PivotTable offers a recommended layout preview based on the shape of the source data. Accepting it still produces a fully editable PivotTable — it's a starting point, not a locked-in structure.

## Segment 4 (screenshot: PivotTable Fields pane)

Every PivotTable is built from four zones: Filters narrows the whole report, Rows and Columns group the data, and Values aggregates it — defaulting to Sum for numbers and Count for text the moment a field lands there.
