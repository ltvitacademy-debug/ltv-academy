# Script — SUMIFS, COUNTIFS & AVERAGEIFS

## Segment 1 (title)

SUMIF and COUNTIF answer one-condition questions. Real analyst questions almost never stop at one condition — that's what the SUMIFS, COUNTIFS, and AVERAGEIFS family is for.

## Segment 2 (code: SUMIFS)

SUMIFS sums a range across multiple conditions at once. The range being summed comes first, then each condition as a criteria-range and criteria pair — that argument order is flipped from SUMIF, and it's worth memorizing deliberately.

## Segment 3 (code: COUNTIFS and AVERAGEIFS)

COUNTIFS follows the same pattern but skips the sum range entirely, since counting only needs to know which rows match. AVERAGEIFS puts the averaged range first, exactly like SUMIFS. Once the pattern clicks for one, all three read the same way.
