# Script — Date & Text Functions

## Segment 1 (title)

Four function families that show up constantly in real analyst work: month-end dates, precise durations, formatted text, and cleaning up messy imported strings.

## Segment 2 (code: EOMONTH and DATEDIF)

EOMONTH returns the last day of a month offset by however many months you specify — no manual leap-year logic needed. DATEDIF calculates a precise duration in years, months, or days between two dates. It's real and fully working, Excel just doesn't show it in autocomplete.

## Segment 3 (code: TEXT, LEFT, RIGHT, MID, TRIM)

TEXT formats a number or date as a display string — essential when concatenating a formatted value into a sentence, since joining a raw number strips its formatting. LEFT, RIGHT, and MID pull characters from a string, and TRIM removes extra spaces — including the invisible ones that silently break a lookup.
