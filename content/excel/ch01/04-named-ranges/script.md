# Script — Named Ranges

## Segment 1 (title)

A named range lets a formula use a real word instead of a cell address — and the payoff isn't convenience for you, it's clarity for whoever opens this workbook after you.

## Segment 2 (code: defining and using a name)

Select a cell, type a name into the Name Box, and press Enter — that name is now usable in any formula. B2 times TaxRate reads as plain English; B2 times dollar-B-dollar-1 tells a reader nothing without checking what that cell actually holds.

## Segment 3 (screenshot: Name Manager)

Every name in a workbook lives in the Name Manager — Formulas, Name Manager, or Ctrl+F3. It's where you rename a name, fix what it refers to, or spot a hash-REF error meaning whatever it used to point at got deleted. Tables get automatic names here too.
