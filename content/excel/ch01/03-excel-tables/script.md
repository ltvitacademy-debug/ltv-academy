# Script — Excel Tables

## Segment 1 (title)

Converting a range into a real Excel Table with Ctrl+T isn't a cosmetic upgrade — it's a different underlying object, one that behaves differently the moment new data shows up.

## Segment 2 (screenshot: table overview)

Filter arrows on every header, banded rows, and an optional Total row all come free the instant a range becomes a Table. But the real reason analysts use them is bigger: add a new row directly beneath a Table, and every formula and every formatting rule extends to it automatically — no dragging, no copy-down.

## Segment 3 (code: structured references)

Inside a Table, formulas can reference columns by name — Table1 bracket Sales means the entire Sales column, and it stays correct as rows are added. The at-symbol version, at-Sales, means the value in the current row. Both are self-documenting in a way a plain B2-colon-B500 reference never is.
