# Script — Finding Errors in a Trial Balance

## Segment 1 (title)

If a trial balance doesn't balance, something is definitely wrong - and this lesson is a troubleshooting toolkit for finding it quickly instead of re-checking every transaction from scratch.

## Segment 2 (steps)

Common causes include a one-sided entry where a matching debit or credit was never entered, a transposition error where digits got swapped when keying an amount, an amount posted to the wrong column entirely, or simply a math error totaling the trial balance's own columns.

## Segment 3 (steps)

Two quick tricks narrow things down fast. If the difference divides evenly by nine, a transposition error is plausible - swapping two digits always produces a difference divisible by nine. If the difference divides evenly by two, check whether an amount was posted entirely to the wrong side instead of offsetting it.

## Segment 4 (code)

Picture a fictional firm, Westbridge Consulting Group, off by exactly ninety dollars. Ninety divided by nine is ten, a clean whole number - transposition is likely. Sure enough, an entry recorded forty-five hundred as forty-five ninety in one account while posting forty-five hundred correctly on the other side.

## Segment 5 (outro)

Even in a modern system, imbalances can still occur from manual entries, data conversion during an implementation, or integration issues. A consultant who knows these classic error patterns diagnoses a client's balance issue dramatically faster. That completes chapter four.
