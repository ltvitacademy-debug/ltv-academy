# Script — Activity Management Settings

## Segment 1 (title)

Tasks, events, and emails are some of the most-used records in Salesforce, and almost every one of them lands on a record's Activity timeline. This lesson covers the settings that control how that timeline fills up and behaves.

## Segment 2 (screenshot: settings navigation)

Activity-related settings live in a few places under Setup. Base Activity Settings controls things like relating multiple contacts to one task, group tasks and events, and simplified Lightning task creation. Einstein Activity Capture has its own Settings node for syncing real email and calendar accounts.

## Segment 3 (screenshot: review sync settings)

Inside Activity Capture's setup wizard, an admin reviews exactly what syncs: Emails, Events, and Contacts each get their own enable toggle and sync direction — for example, Microsoft Exchange to Salesforce only, or two-way.

## Segment 4 (screenshot: default activity sharing)

A separate step sets the sharing default for synced activities: Share with Everyone, so any user can see an activity on a record they have access to, or Don't Share, which keeps synced items private unless the user explicitly shares them.

## Segment 5 (screenshot: activity timeline on a record)

Whatever settings produced it, the result users actually see is one thing: the Activity Timeline on a record, where tasks, events, and synced emails appear together in one chronological feed — no jumping between separate lists.

## Segment 6 (steps: the admin's checklist)

As an admin, the checklist is: configure base Activity Settings for how users create and relate tasks and events, connect a sync source if your org uses Activity Capture, set the sharing default, and trust the timeline to assemble the rest automatically.
