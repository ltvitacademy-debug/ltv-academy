# Script — Release Updates and Critical Updates

## Segment 1 (title)

Salesforce doesn't just add features three times a year — it also changes how existing features behave. Release Updates, the modern replacement for the older Critical Updates console, is how Salesforce surfaces those changes ahead of time, with a deadline and a way to test the impact first.

## Segment 2 (screenshot: release notes TOC)

Release Updates lives in Setup's Quick Find, and it's documented as its own section inside every seasonal release's official release notes — not a buried, one-off setting.

## Segment 3 (screenshot: Enable Test Run)

Many updates offer Enable Test Run — turn it on or off in the org during the test period, which runs until the Complete Steps By date. That date is the real deadline: Salesforce activates the update automatically once it passes, reviewed or not.

## Segment 4 (steps: the admin's workflow)

Review what's listed, read the details Salesforce provides on what's changing and why, enable test run to see the real impact, then activate deliberately — rather than letting the deadline make the decision by default.
