# Lesson 2 — Users and User Management · Voiceover script

Segments map 1:1 to slides. Target: ~2.5 minutes total.

---

## S1 · TITLE CARD

Last lesson we found where admins work. This lesson we open the single most important list in that toolkit: Users. Every person who logs into your Salesforce org — every seller, every support agent, every integration — exists as one record on this page. Understanding that record is the real starting point of this course.

## S2 · IMAGE: setup-admin-nav.png (Users item in Administration nav)

From Setup, Quick Find "Users", and you land here. This list shows every user ever created in the org, active or not — Salesforce never truly deletes a user, which matters a lot once we get to deactivation in the next lesson.

## S3 · IMAGE: new-user-buttons.png (New User / Reset Password / Add Multiple Users)

Three buttons run the entire lifecycle. New User adds one person. Add Multiple Users opens a batch form for up to ten at once — handy for onboarding a whole team. And Reset Password is the single most common ticket an admin gets: someone's locked out, and this button fixes it in seconds.

## S4 · STEPS CARD (Identity / License / Profile / Role)

Strip a user record down to its essentials and you get four things. Identity — name, email, username. License — what kind of access they're entitled to buy. Profile — their baseline permissions. And Role — their place in the reporting hierarchy, which controls what records they can see. We'll spend the rest of this chapter on each one.

## S5 · IMAGE: user-access-summary.jpg (User Access Summary tab)

And when someone asks "what can this person actually do in Salesforce?" — which happens constantly — this is where you answer it. The User Access Summary tab, right on the user's own page, lists every permission they hold and exactly which profile or permission set granted it.

## S6 · OUTRO CARD

That's the Users page: one list, every person, three buttons, and a record built from identity, license, profile, and role. Next lesson, we fill out that New User form for real — and learn the right way to turn a user off when they leave.
