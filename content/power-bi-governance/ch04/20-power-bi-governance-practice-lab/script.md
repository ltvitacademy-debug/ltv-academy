# Lesson 20 — Power BI Governance Practice Lab · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

This lab doesn't introduce anything new — it's every mechanism this course covered, applied yourself, in the order a real governance rollout actually follows.

## S2 · STEPS CARD (part one)

Start with the foundation. Review a few tenant settings and decide who should actually have access. Then set up one real workspace, assigned to a domain, with real roles — not everyone as admin.

## S3 · STEPS CARD (part two)

Next, secure it and earn trust. Apply row-level security and a sensitivity label. Certify the dataset against written criteria. And before you'd ever change it for real, run impact analysis first.

## S4 · STEPS CARD (part three)

Then ship it deliberately. Build a three-stage pipeline — Development, Test, Production, three real workspaces. And walk through one deployment, reviewing exactly what's different before every push downstream.

## S5 · OUTRO CARD

That's Power BI Governance, complete — from one workspace's tenant settings all the way to an enterprise-wide rollup. Well done. The Data Governance path continues next with Cloud Data Governance: Azure & AWS — the same instincts, applied to where the data lives before it ever reaches a report.
