# Lesson 18 — Enterprise BI Governance · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Every lesson so far has worked at the scale of one workspace, one dataset, one pipeline. Enterprise governance means answering the same questions across the whole tenant at once.

## S2 · SCREENSHOT (governance status)

Domains, workspaces, item counts, how much carries a description, how recently each item was touched — one view across the entire estate. Notice how directly this maps to earlier lessons: items by last access date is usage metrics, applied tenant-wide.

## S3 · STEPS CARD (every chapter, one dashboard)

This single surface really is the whole course, rolled up. Workspaces from Chapter One. Sensitivity and trust from Chapters Two and Three. And lifecycle — the same pipeline discipline from last lesson, now visible as a tenant-wide pattern.

## S4 · SCREENSHOT (recommended actions)

A dashboard full of numbers only matters if it leads somewhere — so the same screen surfaces concrete actions. Establish sources of truth with endorsements is Lessons 11 and 12, pointed at the whole tenant instead of one dataset.

## S5 · SCREENSHOT (org-wide insights)

And here's what real scale looks like: over a hundred workspaces, thousands of items. That's not a scale where anyone manually checks each item's label by hand — which is exactly why every mechanism this course covered is built to scale down to one judgment call, and roll up into a view like this.
