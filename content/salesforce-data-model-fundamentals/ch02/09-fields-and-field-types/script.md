# Script — Fields and Field Types

## Segment 1 (title)

Chapter 1 was about objects — the tables that hold your company's records. Now we go one level deeper: fields, the individual columns inside those tables. Every value you've ever seen on an Account or a Contact lives in a field.

## Segment 2 (screenshot: data types)

Every custom field, no matter its type, starts the same way: Object Manager, into an object, into Fields and Relationships, then New. That opens Step 1, Choose the Field Type — grouped into calculated fields like Formula and Roll-Up Summary, relationship fields like Lookup, and simple value types like Checkbox, Currency, and Date.

## Segment 3 (screenshot: Object Manager)

Object Manager is the same starting point you used for object settings back in Chapter 1 — the full list of every object, standard and custom, one click away from Setup.

## Segment 4 (screenshot: New button)

Inside any object, the Fields and Relationships list has that same New button every single time. What changes isn't the button — it's the choice you make on the very next screen.

## Segment 5 (steps: four families)

Four families worth knowing by name: calculated fields that compute a value, relationship fields that connect two objects, simple value fields like text and numbers, and choice fields — picklists — that restrict input to a defined list.

## Segment 6 (outro)

A field's data type is mostly locked in once you save it, which makes this the highest-leverage decision in the whole flow. Next up: the simple value types — text, number, date, and checkbox — in detail.
