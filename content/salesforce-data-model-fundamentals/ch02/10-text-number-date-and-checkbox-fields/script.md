# Script — Text, Number, Date, and Checkbox Fields

## Segment 1 (title)

These four types make up the simple value family from last lesson — fields that just hold a piece of data, no formula, no relationship. They're the most common fields in any org by a wide margin.

## Segment 2 (screenshot: number and text)

A Text field stores up to 255 characters and asks for a Length setting up front — set it too low and users hit save errors the first time they need more room. A Number field asks for two settings instead: Length and Decimal Places, deciding precision before anyone enters data.

## Segment 3 (screenshot: date and checkbox)

Date and Date/Time just store a calendar value, with a pop-up picker doing the work. Checkbox is the simplest field Salesforce offers — one True or False value, with nothing to configure at all.

## Segment 4 (screenshot: record with values)

Here's what it looks like once these are filled in: a Property record with Property Name as Text, Bedrooms and Square Footage as Number, Price as Currency, and Listed On as Date — four data types, each doing one simple job.

## Segment 5 (outro)

Nothing about that record's layout gives away which fields are custom and which are standard. Next up: picklists — the fields that restrict input to a defined list of values instead of leaving it open-ended.
