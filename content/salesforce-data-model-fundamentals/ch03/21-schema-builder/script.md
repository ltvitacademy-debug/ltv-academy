# Script — Schema Builder

## Segment 1 (title)

Every relationship diagram in this chapter so far has actually been a Schema Builder screenshot. This lesson finally introduces the tool itself — where to find it, what it shows, and why it's worth opening before you touch Object Manager at all.

## Segment 2 (screenshot: quick find)

Schema Builder lives in Setup like everything else in this chapter — type its name into the Quick Find box and it's one click away, no deeper navigation required.

## Segment 3 (screenshot: canvas)

Once it opens, you choose which objects to display, and Schema Builder lays them out as cards on a visual canvas. Each card lists every field with its data type, and every relationship is drawn as a connecting line. This is the same Favorite, Offer, and Property example Lessons 16 and 17 used — proof that all of it was visible on one screen the whole time.

## Segment 4 (screenshot: second example)

A busier object tells the same story at a larger scale. User fans out to many other objects at once — exactly the kind of density Lesson 20 flagged as worth a second look on anything less central than User itself.

## Segment 5 (screenshot: vs Object Manager)

Object Manager is where you actually create fields and relationships — Schema Builder is read-first by design, built for understanding structure, not editing it row by row. The same object detail Object Manager shows as a scrollable list, Schema Builder shows as one compact card.
