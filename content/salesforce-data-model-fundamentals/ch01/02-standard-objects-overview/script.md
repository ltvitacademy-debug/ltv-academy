# Script — Standard Objects Overview

## Segment 1 (title)

Lesson 1 defined what an object is. This lesson tours the objects Salesforce already built for you, before you create anything of your own.

## Segment 2 (steps: standard vs custom)

Every object in an org falls into one of two categories. A standard object is one Salesforce built and ships in every single org — Account, Contact, Lead. A custom object is one an admin built for that org specifically, and its API name always ends in double underscore c.

## Segment 3 (screenshot: setup menu)

Every object, standard or custom, is managed from the same place. The gear icon in the top right opens Setup, and Object Manager — the master list of every object in the org — is one click from there.

## Segment 4 (screenshot: Object Manager full list)

Open Object Manager and you'll see a long list — fifty-two or more rows in a typical org. Account, Activity, Address, Alternative Payment Method, and on from there. The Type column is what tells you, at a glance, which rows are Standard Object and which are Custom Object.

## Segment 5 (screenshot: Account with contacts)

Here's one of those standard objects actually doing its job: an Account record, Edge Communications, with two related Contacts attached. Account, Contact, Lead, Opportunity, and Case are the handful of standard objects you'll spend most of this course living inside.

## Segment 6 (outro)

You don't need to memorize all fifty-two rows. Know that the list exists, know where to find it, and know the handful of core ones by name. Next up: Accounts and Contacts, the first two in depth.
