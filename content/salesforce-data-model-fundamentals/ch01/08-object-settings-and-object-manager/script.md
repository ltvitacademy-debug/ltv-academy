# Script — Object Settings and Object Manager

## Segment 1 (title)

Every lesson in this chapter has quietly pointed back to one screen. This lesson makes it explicit: Object Manager, the single place every object's settings live, standard or custom.

## Segment 2 (steps: Setup, Object Manager, one object's settings)

The path is always the same three steps. Setup, from the gear icon on every page. Object Manager, the full list of every object in the org. Then one specific object's settings — fields, layouts, record types, buttons, all organized in a left-hand rail.

## Segment 3 (screenshot: Setup Home)

Here's Setup Home, where the path starts. Object Manager sits right next to Home at the top — one click away, and usually faster than typing into Search Setup if you already know you're headed there.

## Segment 4 (screenshot: Fields & Relationships)

Click into any object and you land here — Account, open to Fields and Relationships. That left rail — Page Layouts, Buttons Links and Actions, Record Types, Search Layouts — is identical no matter which object you picked. Learn it once on Account, and you know it on every object in the org.

## Segment 5 (screenshot: Edit command)

Settings aren't just about adding things. Back on Object Manager's own list, every row has an Edit command too — object-level settings, not just the fields inside it.

## Segment 6 (outro)

That's Chapter One. Object, standard versus custom, the core Sales Cloud objects, and the tool that manages all of them. Chapter Two goes one level deeper — what actually lives inside an object: fields.
