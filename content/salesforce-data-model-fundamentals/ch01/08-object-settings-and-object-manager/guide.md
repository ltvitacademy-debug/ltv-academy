# Object Settings and Object Manager

**Chapter 1 · Objects · Lesson 8 of 23**

Every lesson in this chapter has quietly referenced the same screen. This lesson makes it explicit:
**Object Manager** is the single place where every object's settings live, whether that object is
standard or custom.

## What you'll learn

- The three-step path to any object's settings: Setup → Object Manager → the object itself
- What lives in the left-hand settings rail, and why it's the same for every object
- That Object Manager's own list has object-level settings too, like Edit

## The path, every time

1. **Setup** — the gear icon in the top-right corner of any Salesforce page.
2. **Object Manager** — sits right at the top of Setup, next to Home. It lists every object.
3. **One object** — click its name to open that specific object's settings.

This path doesn't change based on which object you're after. Account, Contact, a custom Energy
Audit object — all three are reached exactly the same way.

## The settings rail is the same for every object

Once you're inside an object (for example, Account), a left-hand rail lists its settings:

| Section | What it controls |
|---|---|
| Fields & Relationships | The object's fields and its relationships to other objects |
| Page Layouts | How fields are arranged on the record page |
| Lightning Record Pages | The modern, drag-and-drop record page layout |
| Buttons, Links, and Actions | Custom buttons and quick actions on the record |
| Record Types | Different field sets/picklist values for different business processes |
| Search Layouts | What columns show in list views and search results |

This rail looks identical whether you're on a standard object or a custom one — learn it once, and
you can navigate any object's settings.

## Settings at the object level, not just the field level

Object Manager's own list isn't read-only either. Each row has an **Edit** command (reached from the
dropdown at the end of the row) that opens *object-level* settings — things like the object's label,
description, and sharing defaults — separate from the field-level settings found inside the object
itself.

## Recap

- Setup → Object Manager → the object is the path to any object's settings, standard or custom.
- The settings rail (Fields & Relationships, Page Layouts, Record Types, etc.) is identical across
  every object.
- Object Manager's list has its own Edit command for object-level settings.
