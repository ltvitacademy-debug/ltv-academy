# Script — Activities: Tasks and Events

## Segment 1 (title)

Every object so far has been about data at rest — a company, a deal, an issue. Activities are about the work itself: the calls, follow-ups, and meetings reps actually do.

## Segment 2 (steps: Task vs Event)

Two objects cover it. A Task is a to-do with a due date — a call to make, an email to send, a follow-up. An Event is something on the calendar, with a start time and an end time, like a demo or an onsite visit.

## Segment 3 (screenshot: Activity Timeline)

Every record that supports Activities gets a timeline like this one. Upcoming and overdue items sit at the top, past activity is grouped by month below, and Tasks, Events, and logged calls all show up in the same feed.

## Segment 4 (screenshot: completed task)

Checking a Task off is simple — click the checkbox right in the timeline, and it strikes through in place. No separate screen, no status dropdown to hunt for.

## Segment 5 (screenshot: New Event form)

An Event's New form looks similar to a Task's, but notice it asks for a Start date and time and an End date and time — not a single due date. That's the real difference: a Task is due, an Event is scheduled.

## Segment 6 (outro)

Task for to-dos, Event for scheduled time, both living on the same Activity Timeline. Next up: Custom Objects — what you build when the standard ones genuinely aren't enough.
