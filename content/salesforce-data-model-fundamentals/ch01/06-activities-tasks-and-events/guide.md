# Activities: Tasks and Events

**Chapter 1 · Objects · Lesson 6 of 23**

Every object covered so far describes data at rest — a company, a deal, an issue. **Activities**
describe the work itself: the calls, emails, follow-ups, and meetings that actually move those
records forward.

## What you'll learn

- The difference between a Task and an Event
- What the Activity Timeline is, and which records get one
- How logging a call fits into the Task object

## Task: a to-do with a due date

A **Task** is a to-do item — call this lead, send that email, follow up next Tuesday. A Task has a
**Due Date** and a **Status** (Not Started, In Progress, Completed), and it can be checked off right
from the timeline it appears on, without opening a separate record. "Log a Call" is really a shortcut
that creates a Task that's already marked complete, with a description of what was discussed.

## Event: scheduled time

An **Event** is something on the calendar — a demo, an onsite visit, a call booked for a specific
slot. Instead of a single due date, an Event has a **Start** date/time and an **End** date/time. Like
a Task, an Event can be tied to a Contact (who it's with) and to an Account, Opportunity, or other
record (what it's about).

## The Activity Timeline

Any record that supports Activities — Lead, Contact, Account, Opportunity, Case, and more — gets an
**Activity Timeline**: upcoming and overdue items at the top, past Tasks/Events/logged calls grouped
by month below. It's the single place to see everything that's happened, and everything that's
coming up, for that specific record.

## Key terms

| Term | Meaning |
|---|---|
| Task | A to-do item with a due date and a status |
| Event | Scheduled time with a start and an end |
| Log a Call | A shortcut that creates an already-completed Task describing a call |
| Activity Timeline | The combined feed of Tasks, Events, and logged calls on a record |

## Recap

- A Task is due; an Event is scheduled between a start and an end time.
- Logging a call creates a completed Task — it doesn't use a separate object.
- The Activity Timeline aggregates Tasks and Events for any record that supports them.
