# Capstone: Wrap-Up & Portfolio Presentation

MERSQL01 started as a server nobody was watching and finished as a server with a documented
architecture, a real security model, real maintenance jobs, a resolved production incident, and
a change-management process. That arc is this course, compressed into one continuous scenario —
and finishing it closes something bigger than just this course.

## What you'll learn

- How this course fits into the SQL Server Database Administrator career path
- What "completing the Job Ready stage" actually means for what you can do now
- What comes next, and why it builds directly on everything you just did

## What this course covered

Twelve chapters, ending in the seven-lesson capstone you just finished: architecture, installing
and configuring an instance, creating and configuring databases, storage and files, security
fundamentals, maintenance plans, SQL Server Agent, linked servers, change management, production
support, and upgrades and patching — then all of it applied at once to Meridian Freight &
Logistics' real, specific server. That's deliberate. A DBA course that only covered topics in
isolation wouldn't prove you can do the job; running them together against one consistent
scenario is closer to what the job actually looks like.

## Where this sits in the path

This is the third and final course in the **Job Ready** stage of the **SQL Server Database
Administrator** career path:

1. **T-SQL Development** — the SQL language foundation
2. **T-SQL for Database Administrators** — using T-SQL like a DBA, not just a developer
3. **SQL Server Database Administration** — this course, general on-prem administration

Finishing this course closes the Job Ready stage entirely. That's a real milestone, not a
formality — it means you can walk into a junior or full DBA role and recognize the situation
this capstone put you in, because you've already handled a version of it: an under-maintained
server, a security gap, a production incident, a schema change that has to go out safely.

## What's next: Advanced SQL Server

The path continues into the **Advanced SQL Server** stage, and it opens with **SQL Server
Performance Tuning** — the natural next step from where this course leaves off. This course
taught you to keep a server healthy, secure, and maintained; Performance Tuning teaches you to
make a *healthy* server fast, digging into execution plans, indexing strategy, wait statistics,
and query tuning in the kind of depth Chapter 10's triage methodology only had room to touch on.
After that, the Advanced SQL Server stage continues into HA/disaster recovery, Azure
administration, and PowerShell automation for DBAs — each one assuming you can already do
everything this course just proved you can do.

## Your portfolio artifact

The MERSQL01 capstone is worth writing up properly outside this course — as a portfolio piece
or a resume bullet, not just something you did in a training environment. The five-beat
structure from Lesson 69 (inherited state, fixes applied, incident handled, change deployed,
measurable improvement) is exactly the shape a hiring manager wants to read, and every number
in it — the 15-minute RPO, the 12-minute incident resolution, the reviewed and reversible
schema change — is something you can defend in detail because you actually did the work to
produce it.

## Key terms

| Term | Meaning |
|---|---|
| Job Ready stage | The first stage of this career path; completing it means you have the baseline skills for a DBA role |
| Advanced SQL Server stage | The next stage: performance tuning, HA/DR, Azure administration, PowerShell automation |
| Portfolio artifact | A concrete, specific piece of work (like this capstone) written up to demonstrate real skill to an employer |
