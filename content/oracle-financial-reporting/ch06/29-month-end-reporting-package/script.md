# Script — Month-End Reporting Package

## Segment 1 (title)

This final lesson pulls together everything from this course into the deliverable a consultant actually produces at the end of a real close, the month-end reporting package. This is about sequencing, not new tools.

## Segment 2 (steps)

A standard package draws on nearly everything we've covered. Income Statement and Balance Sheet, the headline deliverables. Trial Balance, the GL-wide check. AP and AR aging, the overdue picture on both sides. Reconciliation reports confirming subledgers tie to the GL. And supporting detail, Account Analysis or an Asset Register extract, as needed.

## Segment 3 (code)

The build order matters. Confirm subledgers are closed first. Run the Trial Balance, if it doesn't balance, stop and investigate before anything else. Run reconciliations. Run AP and AR aging. Run the Income Statement and Balance Sheet last, once every supporting check is already clean.

## Segment 4 (steps)

Nearly everything in this course is mechanically simple once you know it. What separates a competent consultant from a struggling one isn't knowing how to run a Trial Balance, it's knowing to run it before the Income Statement, so a problem gets caught while it's still cheap to fix.

## Segment 5 (outro)

This sequencing, investigate first, reconcile next, publish last, is exactly what this path's capstone tests, a CFO reporting the books don't balance, and you working through every module to find and fix it.
