# Script — Smart View Setup

## Segment 1 (title)

Chapter 5 covers Excel-native, live analysis of ledger balances, plus collaborative reporting. The tool is Smart View. Before anything else, let's get it installed and connected.

## Segment 2 (steps)

Smart View is a Microsoft Office add-in, most commonly used in Excel, giving multidimensional pivot analysis combined with full Excel functionality. Unlike a one-time export, it keeps a live connection, refresh a worksheet and pull current balances again, pivot dimensions right inside Excel's own grid.

## Segment 3 (steps)

It installs as a separate add-in package, then shows up as a new ribbon tab in Excel, Word, and PowerPoint. Because it's a genuine Office add-in, it behaves like a native Excel feature, its own ribbon, its own menus, functions that work inside regular formulas.

## Segment 4 (steps)

Once installed, it needs a shared connection, a URL pointing at your organization's Fusion instance, provided by an administrator. Signing in uses the same Oracle Fusion credentials and the same security model from chapter one, Smart View has no separate login of its own.

## Segment 5 (outro)

If Smart View won't connect for a client, that's often a data security or duty role issue, not a Smart View bug, the same troubleshooting instinct from lesson six. Up next, lesson twenty-one: ad hoc analysis once that connection is live.
