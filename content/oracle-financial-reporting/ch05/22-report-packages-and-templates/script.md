# Script — Report Packages and Templates

## Segment 1 (title)

So far, Smart View has been about one person exploring data. Now its other job: Report Packages, giving several people a secure, structured way to jointly produce one polished deliverable.

## Segment 2 (steps)

Picture a quarterly board package, five people each own a section, and the final document needs consistent formatting, proper review, and a clear sign-off trail. Emailing Word documents back and forth quickly becomes unmanageable. Report Packages provide a secure, collaborative, process-driven way to define, author, review, and publish exactly this kind of report.

## Segment 3 (steps)

Development has up to three phases. Author: contributors draft their assigned sections, mixing live financial data with written commentary. Review: designated reviewers leave comments on their assigned areas, without necessarily having edit rights. Sign-off: approvers formally sign off, creating a recorded trail before publication. Not every package needs all three.

## Segment 4 (steps)

This matters for Smart View specifically because packages come in two formats. Word- or PowerPoint-based packages get reviewed directly in Smart View, inside that familiar Office interface. PDF-based packages get reviewed through the Narrative Reporting web interface instead, not through Smart View.

## Segment 5 (outro)

So knowing which type a package is tells you immediately which tool a reviewer actually needs open. Up next, lesson twenty-three: refreshing and distributing the reports you've built in this chapter.
