# Script — Matrix Reports

## Segment 1 (title)

A summary report groups rows. A matrix report groups rows and columns at the same time, producing a real two-dimensional grid. This lesson is about building one and reading it correctly.

## Segment 2 (steps: rows plus columns)

The Outline tab splits grouping into Group Rows and Group Columns. A summary report only ever uses Group Rows. The moment you also drag a field into Group Columns, the report becomes a matrix report, and every cell is the intersection of one row group and one column group.

## Segment 3 (screenshot: outline with both groups filled)

Here's that outline panel with both areas filled in: Account Name under Group Rows, Stage under Group Columns. That combination alone is what turns this into a matrix.

## Segment 4 (screenshot: real matrix - camp attendance)

And here's a finished matrix: camp year down the rows, month across the columns, with Camp Capacity, Number of Campers, and Average Attendance Percent in every cell, plus row and column totals.

## Segment 5 (screenshot: pipeline by owner and stage)

This is the classic business version: opportunity owner down the rows, sales stage across the columns, color-coded by how healthy each number looks. One screen answers "where is every rep's pipeline sitting, stage by stage" at a glance.

## Segment 6 (outro)

Reach for a matrix report whenever you need to compare one dimension across another. If several different report types need to sit side by side instead, that's a joined report, which is exactly where we're headed next.
