# Script — Report Filters

## Segment 1 (title)

A report type decides what a report could show. Filters decide what it actually shows. This lesson covers the standard filters every report starts with, plus two sharper tools: field-to-field filters and cross filters.

## Segment 2 (steps: three filter tools)

Standard filters compare a field to a value you type in. Field-to-field filters compare one field to another field on the same record. Cross filters check whether a related record exists at all, using with or without. Each one answers a different kind of question.

## Segment 3 (screenshot: standard filters pane)

Here's the default Filters tab. Show Me controls which subset of records, Close Date narrows the date range, and type-specific filters like Opportunity Status and Probability come built in. Add filter searches for any other field to filter on.

## Segment 4 (screenshot: field-to-field filter)

This is a field-to-field filter in action: Actual Cost in Campaign, greater than, and instead of typing a number, the Type is set to Field, comparing against Budgeted Cost in Campaign. That catches every campaign running over budget, without writing a formula.

## Segment 5 (screenshot: cross filter)

And this is a cross filter: Accounts, without, Contacts. It finds every account that has zero related contact records — a relationship question a standard filter can't ask, because there's no single field to compare.

## Segment 6 (outro)

Standard filters for values you know, field-to-field filters for comparing two fields on the same record, cross filters for relationships. Stack as many as you need; the badge next to Filters always shows how many are active. Next up: grouping those filtered results into summary reports.
