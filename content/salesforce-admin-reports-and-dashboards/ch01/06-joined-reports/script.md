# Script — Joined Reports

## Segment 1 (title)

Every format so far stayed inside one report type. A joined report breaks that rule, putting several separate blocks side by side in a single view. This lesson is about when that earns its complexity and how the pieces fit together.

## Segment 2 (steps: three moves)

Open the Report dropdown, choose Choose Format, and pick Joined Report instead of the default. Your existing report becomes block one. Click Add Block to add up to four more, each on its own report type if you need it.

## Segment 3 (screenshot: Choose Format dialog)

Here's that exact dialog. Report on top, for a single report type. Joined Report below it, selected, for blocks of the same or different report types side by side. One click and Apply is all it takes.

## Segment 4 (screenshot: joined outline with cross-block formula option)

Once you're in a joined report, the Outline panel gets a Group Across Blocks section, one field every block groups by, so rows line up. And the Columns dropdown for each block now offers Add Cross-Block Summary Formula, reaching across every block at once.

## Segment 5 (screenshot: a real three-block joined report)

Here's a finished joined report: three blocks, Sales Month, Year, and Twelve Months, each with its own Close Date, Amount, and Opportunity Name columns, each with its own count and subtotal at the bottom. Three separate reports, one screen.

## Segment 6 (screenshot: cross-block formula result)

And here's a cross-block formula doing real work: Win Rate from the Closed Opps block, divided against Projected Amount Won from the Open Pipeline block, both showing per owner in a single row. That's the payoff for the extra setup.

## Segment 7 (outro)

Choose format, group across blocks, then reach for a cross-block formula when one block's numbers need to be measured against another's. Next up: the formulas that make all of this possible.
