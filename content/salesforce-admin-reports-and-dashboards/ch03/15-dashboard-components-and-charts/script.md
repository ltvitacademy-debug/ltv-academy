# Script — Dashboard Components and Charts

## Segment 1 (title)

Every widget on a dashboard starts the same way: a real report. This lesson follows that path — report, chart picker, finished component — end to end.

## Segment 2 (screenshot: source report)

Here's the raw material — a real "Leads by Lead Source" report, grouped by source, with total records and subtotals already calculated. A chart widget doesn't invent new math; it visualizes exactly what a report like this one already produces.

## Segment 3 (screenshot: Add Widget dialog)

This is the real Add Widget dialog. Pick the source report, choose Display As — bar, column, line, donut, and more as icons across the top — set the value and what it's sliced by, and a live preview updates on the right before you ever commit.

## Segment 4 (screenshot: rendered component)

And here's that exact same report, now a donut chart sitting on a live dashboard — twenty-two leads sliced by source, each color matched to a legend, refreshed every time the dashboard runs.

## Segment 5 (steps: matching chart to question)

Picking the right chart type matters more than it looks. Donut or pie for parts of a whole. Bar or column for comparing a few categories. Line for a trend over time. Funnel for a sequence with expected drop-off, like pipeline by stage. Match the chart to the question, not the other way around.

## Segment 6 (outro)

A widget is only as good as its source report and its chart type — get both right and a dashboard actually answers questions at a glance. Next up: letting people filter that dashboard themselves, and sharing it once it's built.
