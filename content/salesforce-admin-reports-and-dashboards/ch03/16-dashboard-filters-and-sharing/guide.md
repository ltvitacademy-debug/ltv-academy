# Dashboard Filters and Sharing

**Chapter 3 · Dashboards · Lesson 16 of 22**

A dashboard built for an entire sales org is more useful when any one viewer can narrow it to their own region, product line, or quarter without an admin rebuilding anything. **Dashboard filters** do that. And once the dashboard looks right, the same **folder sharing** rules from Lesson 10 decide who's allowed to open it at all.

## What you'll learn

- How dashboard filters differ from report filters
- Adding a filter in the Dashboard Builder
- How a viewer actually uses a filter on a live dashboard
- Sharing a dashboard folder — same mechanics, same rules

## Dashboard filters vs. report filters

A report filter is baked into the report and applies every time it runs, for everyone. A **dashboard filter** is interactive — it sits on top of the dashboard, lets a viewer narrow what they're looking at in the moment, and resets each time they leave. One dashboard, many viewers, each narrowing it to what matters to them, without touching the underlying reports at all.

## Adding a filter in the builder

In the Dashboard Builder, click **+ Filter** and pick a field to filter on — Type, Shipping Country, Account Name, or any field the underlying reports share. Add up to three filters per dashboard. Each one becomes a dropdown sitting at the top of the dashboard once it's saved, ready for any viewer to use.

## Using a filter as a viewer

On a live dashboard, the filter dropdowns sit right under the header — a viewer picks a value (or leaves it at "All") and every widget tied to that filterable field updates together. No edit access is needed to use a filter; it's a viewing-time convenience, not a configuration change.

## Sharing the dashboard

Dashboards are shared exactly like reports: through the **folder** they're saved in (Lesson 10). Open the folder's Share dialog, pick who gets access, and set Viewer, Editor, or Manager. A dashboard filter doesn't change who can see the dashboard — it only changes what they see within the access they already have.

## Recap

- Dashboard filters are interactive and viewer-facing; report filters are baked in and apply to everyone.
- Add up to three filters per dashboard through + Filter in the builder.
- Using a filter requires no special access — it's available to anyone who can already view the dashboard.
- Sharing is controlled entirely by the dashboard's folder, identical to report folder sharing.
