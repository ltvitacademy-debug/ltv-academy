# Script — Dashboard Filters and Sharing

## Segment 1 (title)

A dashboard built for an entire org is more useful when any viewer can narrow it to their own region or quarter, without an admin rebuilding a thing. That's a dashboard filter.

## Segment 2 (screenshot: adding a filter in the builder)

Here's the real Dashboard Builder with three filters already added — Type, Shipping Country, Account Name — each one a field the underlying reports share. Plus Filter up top is how you add them; up to three per dashboard.

## Segment 3 (screenshot: live filter bar)

And here's what a viewer actually sees: a Date filter dropdown sitting right under the dashboard header, next to Refresh, Edit, and Subscribe. Pick a value and every widget tied to that field updates together — no edit access required, just viewing.

## Segment 4 (screenshot: sharing the folder)

Filters change what a viewer sees within their access. Who gets that access at all is still the folder's job — the same Share dialog from reports, Viewer, Editor, or Manager, applied to the dashboard's folder instead of a report's.

## Segment 5 (outro)

One dashboard, filtered differently for every viewer, shared through the same folder rules as everything else — that's the whole model. Next up: dynamic dashboards, where even the running user changes per viewer, not just the filter.
