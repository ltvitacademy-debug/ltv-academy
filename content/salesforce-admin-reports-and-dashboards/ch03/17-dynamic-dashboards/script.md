# Script — Dynamic Dashboards

## Segment 1 (title)

Every dashboard has a running user — whoever's data access decides what actually shows up. Usually that's one fixed person. A dynamic dashboard changes that rule entirely.

## Segment 2 (screenshot: Viewing as / Change)

Here's the real tell. Right under the dashboard header: "As of Jan 25, 2018, 2:39 PM, Viewing as Fred Williamson, Change." That line only appears on a dynamic dashboard — the running user is whoever's actually looking at it, not one fixed person baked in at build time.

## Segment 3 (screenshot: a second real example)

Same feature, a different dashboard: "Viewing as Barbara Weinstein." Three different people could open this exact same dashboard and see three different, individually-accurate sets of numbers — because each one is running as themselves.

## Segment 4 (steps: static vs dynamic)

The choice lives in the dashboard's properties, under View Dashboard As. Pick a specific person and you get a static dashboard — one consistent picture for everyone, right for an executive view. Pick The Dashboard Viewer and it's dynamic — each person sees their own access reflected, right for a dashboard forty reps all open and expect to show their own pipeline.

## Segment 5 (outro)

One setting, and the same dashboard definition serves everyone correctly instead of forty separate dashboards doing the same job badly. That's dynamic dashboards. Next up: the design habits that make any dashboard, static or dynamic, actually worth opening.
