# Script — Dashboards

## Segment 1 (title)

A report answers one question. A dashboard puts a whole set of answers on one screen — charts, tables, single numbers — so someone can see the state of the business at a glance.

## Segment 2 (screenshot: dashboards list and folders)

Dashboards live exactly where reports do: in folders, with the same sharing rules. Here's the real Dashboards tab — Recent, Created by Me, Private Dashboards, and the Folders list down the left, same structure you already know from reports.

## Segment 3 (screenshot: Dashboard Builder canvas)

This is the real Dashboard Builder. Plus Widget and Plus Filter sit across the top, Save and Done to the right, and the grid below is where everything gets arranged. Every number you see already placed — pipeline, open pipe, won deals — is a widget backed by a report.

## Segment 4 (screenshot: finished dashboard)

And here's a finished one. A funnel, a bar chart, a table, a donut, a line chart, all refreshed together, all built the same way — pick a widget type, point it at a report, drag it into place.

## Segment 5 (outro)

A dashboard stores no data of its own — it's an arrangement of widgets, and every widget is only as good as the report behind it. Next up: a closer look at those widgets themselves, and the chart types available for each one.
