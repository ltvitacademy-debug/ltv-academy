# Lesson 60 — Data Governance in Production · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

Data governance in production — what it actually means, beyond a
vague compliance word.

## S2 · STEPS CARD (three real questions)

Cataloging is knowing what data exists and where — purview does
for fabric what unity catalog does for databricks. Lineage traces
where a value came from. Ownership is who's actually responsible
for it.

## S3 · CODE CARD (lineage, traced)

Lineage traces a dashboard number back through every stage that
produced it — genuinely useful when the question is which of these
four stages introduced the error.

## S4 · OUTRO CARD

A real-time dashboard that's wrong is wrong right now, in front of
whoever's watching — exactly why governance matters more here, not
less. Next up: handling PII and sensitive data, governance's
sharpest edge.
