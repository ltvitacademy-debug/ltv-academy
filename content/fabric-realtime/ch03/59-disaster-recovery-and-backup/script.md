# Lesson 59 — Disaster Recovery and Backup Strategies · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

Disaster recovery and backup strategies — two real numbers, not a
vague promise that backups exist.

## S2 · CODE CARD (two numbers)

RPO answers how much data loss is acceptable. RTO answers how long
recovery is allowed to take. Both force a real conversation about
cost versus risk.

## S3 · CODE CARD (what's already covered)

Item definitions are already covered by git integration. Delta's
time travel covers table history. What's genuinely still open is
the streaming data itself, beyond its own retention window.

## S4 · STEPS CARD (where the line is)

An incident is something wrong within a system that's still there
— mitigate, then fix. A genuine disaster is the system itself
being gone — that calls for restoring from what was actually,
deliberately backed up.

## S5 · OUTRO CARD

Two different problems, two different responses. Next up: data
governance in production — who's allowed to touch what, and why.
