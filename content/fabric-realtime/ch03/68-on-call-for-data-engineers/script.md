# Lesson 68 — On-Call for Data Engineers · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

On-call for data engineers — picking severity tiers back up, and
finally attaching a name to each one.

## S2 · CODE CARD (severity tiers, with a name attached)

Sev one pages the on-call engineer immediately, any hour. Sev two
waits for business hours. Sev three just gets logged. Without a
defined rotation, page someone fails exactly when it matters most.

## S3 · CODE CARD (what makes a rotation sustainable)

A rotation with one person, indefinitely, eventually fails
completely — not gradually, but exactly during the real sev one
that needed a fresh, alert engineer.

## S4 · STEPS CARD (handoff)

The moment one shift ends and another begins, context can silently
disappear. A short, deliberate handoff — what's unresolved, what
to watch — is cheap insurance against the next person starting
blind.

## S5 · OUTRO CARD

A real rotation, a real escalation path, a real handoff. Next up:
a production incident, start to finish — every piece of this
chapter, in motion.
