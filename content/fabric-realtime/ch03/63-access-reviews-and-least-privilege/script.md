# Lesson 63 — Access Reviews and Least Privilege · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

Access reviews and least privilege — granting exactly what's
needed, and nothing more.

## S2 · CODE CARD (permission creep)

An engineer gets temporary prod access to help an incident. The
incident resolves, but nobody revokes the grant. A year later, ten
more grants like it exist — each reasonable at the time,
collectively excessive now.

## S3 · CODE CARD (access reviews)

Every quarter, list every write and admin grant. Ask if this
person still needs it right now. Revoke anything the answer is no
or not sure to — the same recurring pattern as right-sizing
capacity.

## S4 · STEPS CARD (where this connects)

Masking controls who sees sensitive values. Secrets management
protects specific credentials. Access reviews protect the broader
accounts that could bypass or request either one.

## S5 · OUTRO CARD

None of Chapter 3's security lessons fully works without this
recurring check behind it. Next up: capacity planning — looking
ahead, not just reacting.
