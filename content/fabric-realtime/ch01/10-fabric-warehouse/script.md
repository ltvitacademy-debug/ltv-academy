# Lesson 10 — Fabric Warehouse · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

Let's meet the other real engine sharing OneLake — Fabric
Warehouse.

## S2 · CODE CARD (real T-SQL engine)

A lakehouse is Spark-first, with a SQL endpoint bolted on. A
Warehouse flips that — it's SQL-first, full T-SQL, the exact
dialect this track's own T-SQL course covered. And its tables
still live in the same OneLake, same Delta format underneath.

## S3 · CODE CARD (full T-SQL)

New item, Warehouse, name it, create — and it opens to a T-SQL
editor, genuinely the same kind of interface the T-SQL course's
SSMS lessons used. And unlike a lakehouse's read-only SQL
endpoint, a Warehouse supports real inserts, updates, and full
transactions.

## S4 · CODE CARD (completing the circle)

This track actually started with a standalone T-SQL course. A
Fabric Warehouse is where that entire skill set becomes directly
relevant to real data engineering work — the same syntax, now
against a lakehouse-adjacent warehouse table.

## S5 · OUTRO CARD

Same storage, a genuinely different engine on top. Next lesson:
lakehouse versus warehouse, choosing the right one.
