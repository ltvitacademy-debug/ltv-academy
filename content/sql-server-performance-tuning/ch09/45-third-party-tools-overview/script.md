# Script — Third-Party Tools, Overview

## Segment 1 (title)

Everything so far in this chapter is free and built into SQL Server. It's worth being honest that a whole commercial software category exists to make this easier at scale — this lesson is a high-level overview of that category, not a buyer's guide to any one product.

## Segment 2 (code: a real commercial category)

Names like SolarWinds SQL Sentry, Redgate SQL Monitor, and Idera SQL Diagnostic Manager sit in this same general category. They're built on the same underlying DMVs this chapter's been using, just packaged, automated, and sold at a real licensing cost.

## Segment 3 (steps: what the category typically adds)

What the category typically adds: continuous historical collection that's already running and graphed, built-in alerting with tunable — sometimes adaptive — thresholds, and a fleet-wide view across dozens of instances at once, which gets genuinely hard to maintain yourself past a handful of servers.

## Segment 4 (outro)

None of that replaces understanding what a wait type actually means — a dashboard only helps someone who already knows what to do with what it shows. Next up: the free, DIY alternative, built entirely with your own T-SQL.
