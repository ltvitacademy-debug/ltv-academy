# Script — A Systematic Approach to Performance Tuning

## Segment 1 (title)

This course goes far past troubleshooting an active incident. Performance tuning is its own discipline — query tuning, index tuning, wait-based methodology, configuration tuning — all built around one systematic loop.

## Segment 2 (code: troubleshooting vs. tuning)

Troubleshooting is reactive — something's on fire, find the expensive query, fix it. Tuning is deliberate and repeatable: making a system measurably faster whether or not anything's currently broken. A DBA who only troubleshoots is always one incident behind.

## Segment 3 (steps: the systematic loop)

Every technique in this course plugs into the same loop: measure what normal looks like, identify the specific bottleneck, make one deliberate change, then verify — measure again and confirm that exact bottleneck actually moved.

## Segment 4 (outro)

Skipping straight to "make a change" without measuring first is the single most common mistake this course exists to correct. Next up: actually defining what "slow" means, precisely.
