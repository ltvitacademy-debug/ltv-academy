## How six courses became one pipeline

| Course | What it taught | Where it shows up in this capstone |
|---|---|---|
| T-SQL Development | Querying and designing a database | Every query against `AdventureWorks2012`, and the shape of `stg.WorkOrder` |
| SSIS Development | Moving and transforming data | `WorkOrderETL.dtsx`, the package that moves work order data into the warehouse |
| SSRS Development | Paginated reporting | `WorkOrderProductionSummary.rdl`, grouped by product with a computed scrap rate |
| Power BI (track) | Interactive visualization | The dashboard's scrap-rate trend, on-time-versus-late, and volume-by-product visuals |
| Data Modeling & Data Warehousing | Dimensional design | `dw.FactWorkOrder` as an accumulating snapshot, its role-playing date keys, its conformed and static dimensions |
| This capstone | Putting all five together, then presenting and selling it | The finished, working, explainable pipeline itself |

None of those five earlier courses taught you to build *this* pipeline
— they taught you the individual pieces. This capstone is what you
built the first time you had to make every one of those pieces agree
with every other one, on a business process none of them had already
solved for you. That's the actual skill a Microsoft BI developer role
is hiring for, and it's the one this program was built to prove you
have.
