# Script — Building Your Resume Around This Project

## Segment 1 (title)

You just built a real, working pipeline. None of that matters on a resume if it's summarized as "completed a BI capstone project." This lesson turns that project into bullets a hiring manager can actually act on.

## Segment 2 (steps: the bullet structure)

Every strong resume bullet answers three questions in one sentence: what did you do — a specific action verb, not "worked on" — what did you do it with, meaning the named tool, and what changed because you did it, ideally something measurable.

## Segment 3 (code: sample bullets)

Walk each deliverable through that structure separately. The pipeline gets its own bullet: designed and built an SSIS ETL pipeline loading AdventureWorks manufacturing data into a dimensional warehouse. The dashboard gets its own: built a Power BI dashboard on the same warehouse tables surfacing scrap rate by product and location. Four deliverables, four bullets — not one sentence trying to cover everything.

## Segment 4 (steps: resume structure)

This project doesn't belong buried in your skills list. Give it a dedicated Projects section, positioned above older, unrelated work history — right under your summary and skills. That placement tells the reader exactly where to look for evidence you can do the job.

## Segment 5 (outro)

Next lesson, you'll take this same project and package it for a portfolio — a GitHub repo, a README, and a way of talking about it that leads with the business problem, not the tool list.
