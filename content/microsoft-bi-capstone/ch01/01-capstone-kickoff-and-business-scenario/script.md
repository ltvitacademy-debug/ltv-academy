# Script — Capstone Kickoff & Business Scenario

## Segment 1 (title)

Welcome to the Microsoft Data & BI Capstone. Every course before this one taught you one piece of the Microsoft BI stack in isolation. This capstone is where those pieces stop being separate skills and become one job.

## Segment 2 (steps: the five-tool pipeline)

You're going to build a single pipeline: raw data loaded into SQL Server, moved and transformed by an SSIS package, landed into a dimensionally modeled warehouse, then read by both an SSRS paginated report and a Power BI dashboard — built end to end, the way you'd actually be asked to at a real BI developer job.

## Segment 3 (steps: the business scenario)

The business process this capstone models is manufacturing work orders — how AdventureWorks tracks the physical production of the bikes it sells. SSIS and SSRS Development already modeled Sales. Data Warehousing already modeled Procurement. Work orders are a genuinely unused business process, which means you're making real modeling decisions, not repeating an answer this catalog already gave you.

## Segment 4 (outro)

Next lesson, you'll plan the full architecture — every tool this pipeline touches, and how data actually moves between them — before you build a single piece of it.
