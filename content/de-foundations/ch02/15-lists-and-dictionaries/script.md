# Lesson 15 — Lists and Dictionaries · Voiceover script

Segments map 1:1 to slides. Target: ~2 minutes total.

---

## S1 · TITLE CARD

Single values only get you so far. Lists and dictionaries are how
Python holds more than one value at a time — and they show up
constantly in this course.

## S2 · CODE CARD (lists)

A list holds values in order, accessed by position. Zero gets you the
first element, negative one gets you the last. And lists are mutable
— append adds a new one right onto the end, no rebuilding required.

## S3 · CODE CARD (dictionaries)

A dictionary holds values by name instead of position — a key, and a
value. This should look familiar. It's structurally identical to
Lesson 8's JSON object, and that's not a coincidence — Lesson 24 reads
real JSON and hands you back exactly this.

## S4 · CODE CARD (list of dicts)

Put a bunch of dictionaries into a list, and you get something that
looks a lot like rows in a table — because that's exactly what it is.
This is the precise shape you get back from reading a JSON file full
of records, and it's what a Pandas DataFrame, coming up in Lesson 21,
formalizes into something far more powerful.

## S5 · OUTRO CARD

Position for lists, name for dictionaries, and a list of dictionaries
is basically a table already. Next lesson: conditions — making
decisions based on a value. See you there.
