# Lesson 14 — Variables and Data Types · Voiceover script

Segments map 1:1 to slides. Target: ~2 minutes total.

## S1 · TITLE CARD

Every language starts here. Python's version of variables and data
types is refreshingly simple, and it's the absolute foundation for
everything else in this chapter.

## S2 · CODE CARD (assignment)

No declaration keyword, no upfront type. Just a name, an equals sign,
a value. Python figures out the type from the value itself — that's
called dynamic typing.

## S3 · CODE CARD (five types)

Five core types you'll use constantly, mapped to real taxi columns.
Fare amount is a float. Passenger count is an int. Vendor ID — even
though it looks numeric — is actually stored as text, a string. A
shared ride flag is a boolean, true or false. And a genuinely missing
value is None.

## S4 · CODE CARD (type checking)

When something behaves unexpectedly, type of tells you exactly what
Python decided a value's type actually is. You'll reach for this
constantly once you start reading real files in Lesson 22.

## S5 · OUTRO CARD

And remember: None means genuinely absent, not zero, not an empty
string. Confusing those is a real, common bug. Next lesson: lists and
dictionaries, for holding more than one value at a time. See you
there.
