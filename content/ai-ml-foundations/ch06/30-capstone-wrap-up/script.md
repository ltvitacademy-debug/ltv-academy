# Script — Capstone: Wrap-Up & Portfolio Presentation

## Segment 1 (title)

Six chapters, one throughline: understand what a model is actually doing, then do it yourself. This lesson closes the loop — recapping the course, and turning the capstone into something you'd actually show someone.

## Segment 2 (steps)

Chapters one and two: supervised learning, features and labels, the first real models. Chapter three: working with real data, including the leakage mistake this capstone's own scaler step avoided. Chapter four: what's inside a neural network. Chapter five and six: using models other people trained, honestly, then training and evaluating your own.

## Segment 3 (code)

A portfolio piece only works if someone can read it in two minutes and trust it. Problem, data, method, results with real numbers, and limitations — the same five pieces every real model card in chapter five had.

## Segment 4 (code)

Disclose the same way lesson 26 taught you to read: state the test set size next to every metric, say plainly this is one split and not cross-validated, and name the dataset's real limitation. A model card's self-reported tag and your own disclosure are the same honesty.

## Segment 5 (code)

None of this is required to call it done, but if you want to go further: run cross-validation to see how much the numbers move, try a second model and report both, or plot the two strongest coefficients against each other.

## Segment 6 (outro)

This course started with supervised versus unsupervised learning and ends with you training and honestly evaluating a real classifier. That's the working understanding the next course builds on: Generative AI & LLMs, starting with how large language models actually work. Congratulations on finishing AI/ML Foundations.
