# Lesson 20 — Portfolio Presentation Strategy · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

This lesson turns your three capstone repos into a portfolio a recruiter or hiring manager will actually click through, not just skim past.

## S2 · STEPS — Pin three, not thirty

GitHub only features six pinned repos, so pin your three capstones from this course -- the RAG assistant, the data analyst, and the tool-using agent -- not a scattering of tutorial follow-alongs. Three complete, documented projects beat fifteen abandoned ones.

## S3 · STEPS — The README's five parts

A strong README front-loads five things in order: a one-sentence description, an architecture diagram, a demo link near the top, your real eval results, and the key design decisions a reviewer can't get anywhere else.

## S4 · STEPS — Common mistakes

Pinning a tutorial clone with no changes. A README that's just a license and boilerplate setup steps. No eval numbers anywhere, so a reviewer can't judge "it works." And a demo link that's quietly broken.
