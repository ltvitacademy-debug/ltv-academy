# Lesson 17 — Running Depreciation · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Welcome to Chapter 4. Everything so far has been setup. This lesson covers the process that actually turns it into numbers.

## S2 · STEPS — What Calculate Depreciation does

Run once per period, per book, it walks every in-service asset and calculates that period's depreciation based on method, remaining life, and net book value.

## S3 · STEPS — Preview versus final

Preview mode calculates and lets you review without committing or closing anything — run it as many times as needed. Final mode commits the numbers and closes the current period, advancing the book forward.

## S4 · STEPS — Rollback, a narrow window

If something's wrong immediately after a final run, but before accounting has been created against it, rollback reverses that period's depreciation so it can be rerun. Once accounting is created, rollback isn't the normal path anymore — a later correcting adjustment is.

## S5 · STEPS — Assets that failed to depreciate

An asset can fail to depreciate from a data problem — a missing account, an invalid category, a bad cost. The exception report lists exactly which assets and why, and a period generally cannot close while any assets have failed.
