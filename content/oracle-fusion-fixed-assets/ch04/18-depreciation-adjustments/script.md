# Lesson 18 — Depreciation Adjustments · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Assets don't always get set up right the first time. This lesson covers what happens to depreciation that already should have been taken under the corrected numbers.

## S2 · STEPS — The catch-up problem

Correct an asset's life or method after periods have already closed with the old numbers, and there's a gap: the depreciation that would have been taken under the corrected figures, for periods already in the books.

## S3 · STEPS — Two ways to resolve it

Amortized spreads the catch-up across the asset's remaining life, smoothing the correction into future periods. Expensed recognizes the whole catch-up amount immediately, in the current period, as a one-time hit.

## S4 · CODE — Working the numbers

Meridian's hundred-thousand-dollar machine, corrected from a ten-year to an eight-year life after two years. The old rate took twenty thousand; the corrected rate should have taken twenty-five thousand. That five-thousand-dollar gap is the catch-up.

## S5 · STEPS — A real accounting decision

Expensed puts that five thousand dollars in the current period all at once. Amortized spreads it across the remaining six years instead. Which one to use is a policy decision, not a technicality — documented upfront, not chosen case by case.
