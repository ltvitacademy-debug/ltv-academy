# Lesson 21 — Asset Revaluation · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Not every change to an asset's value is a correction of a mistake. This lesson covers revaluation — restating value to reflect current conditions.

## S2 · STEPS — Restating, not correcting

Cost adjustments and reclassifications fix something that was originally wrong. Revaluation is different: it restates an asset's carrying value for inflation, market value, or policy reasons, under accounting frameworks that explicitly allow it, like IFRS.

## S3 · STEPS — Two dedicated accounts

An upward revaluation uses a revaluation reserve to capture the increase, typically recorded in equity rather than income. Revaluation amortization then gradually recognizes that reserve's effect over the asset's remaining life.

## S4 · CODE — Effect on going-forward depreciation

Meridian revalues a building: four hundred thousand net book value, twenty years remaining, up to a five-hundred-thousand fair value. The hundred-thousand-dollar increase goes to reserve. Depreciation going forward is calculated on the new, higher basis.

## S5 · STEPS — Deliberate and infrequent

Because it changes the fundamental depreciation basis, revaluation isn't run casually. Companies that use it apply it on a defined cycle, consistently across a whole category, not selectively to individual assets.
