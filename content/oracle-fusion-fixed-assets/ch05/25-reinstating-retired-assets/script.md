# Lesson 25 — Reinstating Retired Assets · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Retirements happen by mistake more often than you'd think. This lesson covers how to undo one cleanly.

## S2 · STEPS — What reinstatement restores

The asset's status returns to in-service. Any gain or loss recorded during the retirement is reversed. Depreciation resumes, picking back up as though the retirement gap never happened.

## S3 · STEPS — Not the same as a new addition

A fresh addition starts a brand-new depreciation schedule with a new date placed in service. Reinstatement instead preserves the asset's original identity and depreciation history up to the point of the mistaken retirement.

## S4 · STEPS — A practical time limit

Reinstatement is clean while the retirement is still in the current open period, before its accounting has been created and transferred. Once that's posted and the period's closed, the same one-way calendar problem from earlier applies.

## S5 · STEPS — Reinstatement versus a genuine replacement

Reinstatement is for reversing an error — the retirement itself was the mistake. If an asset was correctly retired and later replaced with something new, that's a brand-new addition, not a reinstatement.
