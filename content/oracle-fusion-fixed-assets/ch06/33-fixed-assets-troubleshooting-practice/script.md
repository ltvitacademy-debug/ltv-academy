# Lesson 33 — Fixed Assets Troubleshooting Practice · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Thirty-two lessons built a mental model. This closing lesson turns it into a diagnostic toolkit, with four realistic Meridian Fabrication Co. problems.

## S2 · STEPS — Four scenarios

Depreciation won't run for three assets. A partial retirement looks wrong. Assets and GL don't agree on accumulated depreciation. A machine got retired by mistake. Each one traces back to a specific earlier lesson.

## S3 · STEPS — Working through the diagnoses

Failed depreciation traces to category integrity, account mapping, or an incomplete cost adjustment. A wrong-looking partial retirement is usually a data-entry error in the retire-by-units math. An out-of-balance reconciliation starts with checking timing first.

## S4 · STEPS — The mistaken retirement

Caught the same week, before period close — that's a reinstatement, not a new addition. The goal is restoring the original asset's history, not starting over.

## S5 · STEPS — A repeatable habit

Symptom, likely cause, the specific lesson that explains the mechanism, then the fix. Every troubleshooting scenario in this course follows that same order — never guess at a fix before understanding the mechanism.
