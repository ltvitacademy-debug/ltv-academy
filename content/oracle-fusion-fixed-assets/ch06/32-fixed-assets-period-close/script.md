# Lesson 32 — Fixed Assets Period Close · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Every chapter in this course has been building toward this moment. This lesson covers period close — the full sequence, not a single button.

## S2 · STEPS — The sequence, step by step

Finish transaction entry. Run depreciation in preview, fix exceptions. Run depreciation final, which actually closes the period. Run Create Accounting final. Transfer to GL. Reconcile.

## S3 · STEPS — Why the order isn't arbitrary

Each step depends on the one before it. Final depreciation before transaction entry is done means missing transactions never get depreciated at all. Transferring to GL before Create Accounting even runs isn't possible — there's nothing there yet.

## S4 · STEPS — What has to be true to close

A period generally cannot close while any assets have failed to depreciate, and once it's closed, the calendar's one-way rule means there's no going back. Preview isn't optional busywork — it's the last real chance to catch a problem.

## S5 · STEPS — Close tests everything before it

A clean close is evidence every earlier chapter's setup actually worked. A messy one — exceptions everywhere, reconciliation not tying out — is usually a symptom of something that went wrong much earlier, surfacing all at once.
