# Lesson 28 — Creating Accounting for Assets · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Welcome to Chapter 6. Every transaction in this course has an accounting consequence. This lesson covers how it actually becomes a journal entry.

## S2 · STEPS — Turning transactions into journal entries

Create Accounting reads additions, depreciation, adjustments, transfers, and retirements, and generates the actual subledger journal entries behind each one, using the same engine shared across Payables and Receivables.

## S3 · STEPS — A few representative examples

An addition debits cost, credits clearing. A depreciation run debits expense, credits accumulated depreciation. A retirement with a gain removes cost and reserve, records proceeds, and credits a gain account. Every one uses the default accounts set up back in Chapter 2.

## S4 · STEPS — Draft versus final

Draft mode generates entries for review without posting them anywhere permanent. Final mode commits them, making them eligible to transfer to the General Ledger. Draft is exactly where a wrong account gets caught before it's real.

## S5 · STEPS — The bridge to GL

Assets keeps far more detail than GL ever needs — asset numbers, locations, categories. Create Accounting is what summarizes all of that into the account-level entries GL actually wants.
