# Lesson 11 — Adding an Asset Manually · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Welcome to Chapter 3: Adding Assets. This lesson covers the full manual Add Asset flow — the right tool when an asset needs deliberate, field-by-field attention.

## S2 · STEPS — When to add manually

Oracle Fusion Assets gives you three ways to create an asset: full manual add, Quick Additions, and mass additions from Payables. Manual add is right for a one-off, high-value, or non-standard asset where you expect to override several category defaults.

## S3 · STEPS — What it captures

A manual addition walks through description and category, location and key flexfield, financial information like cost and date placed in service, depreciation information pre-populated from the category but overridable, and assignment information for cost center and employee.

## S4 · CODE — A worked example

Meridian Fabrication Co. buys an eighty-five-thousand-dollar inspection robot. No realistic salvage value, a seven-year life instead of the category's usual ten, placed in service March fifteenth. The person adding it overrides life and salvage, but keeps the category's straight-line method and mid-month convention.

## S5 · STEPS — Multiple distributions

One asset doesn't have to charge one cost center. If three departments share the robot, it can be split across multiple distributions, each with its own percentage and expense account — same asset, same depreciation schedule, allocated proportionally.
