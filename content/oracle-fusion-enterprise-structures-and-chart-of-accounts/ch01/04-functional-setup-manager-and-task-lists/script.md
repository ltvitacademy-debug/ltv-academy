# Script — Functional Setup Manager and Task Lists

## Segment 1 (title)

You know what Setup and Maintenance looks like and what you're building. This lesson covers the engine behind both: Functional Setup Manager, the tool that decides which setup tasks exist for you and organizes them into a trackable list.

## Segment 2 (steps)

Oracle Fusion contains far more setup tasks than any one implementation needs. Functional Setup Manager takes your choice of offerings, like Financials, and functional areas within them, and generates exactly the task list that matches — including every prerequisite task that choice implies.

## Segment 3 (code)

That generated list lives inside an implementation project. You pick the offering and functional areas, and FSM builds a hierarchical task list automatically. Oracle recommends scoping a project to no more than one offering, since multi-offering projects are harder to export and hand off between environments.

## Segment 4 (steps)

The task list isn't just a reading list — it's a tracking tool. Each task gets an owner, a status, and notes. The predefined offering top task list already reflects the correct dependency order, so chart of accounts and calendar tasks won't show up after the ledger task that depends on them.

## Segment 5 (outro)

Functional Setup Manager turns your choice of offerings into a generated, trackable task list. That closes out chapter one — you can sign in, navigate Setup and Maintenance, see the big picture, and understand the tool organizing the work. Chapter two starts building: legal entities and ledgers.
