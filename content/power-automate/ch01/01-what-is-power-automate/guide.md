# What Is Power Automate? Platform Overview

Welcome to Microsoft Power Automate, the first course in your Business Process Automation studies. Throughout this course you'll build real flows using **Castlebridge Logistics**, a fictional mid-size regional trucking and warehousing company, as your running example — Castlebridge's shipping approvals, dispatch notifications, and warehouse paperwork all run through flows you'll learn to build. Before touching the designer, this lesson answers the question everything else depends on: what is Power Automate, and where does it fit?

## What you'll learn

- What Power Automate actually is, and where it sits inside the Microsoft Power Platform
- The three kinds of automation it covers: cloud flows, desktop flows (RPA), and process mining
- What the real Power Automate home page looks like and where you go to start building
- Why a company like Castlebridge Logistics automates with it instead of hiring a developer to write custom integration code

## A low-code automation service, not a programming language

Power Automate is Microsoft's low-code automation service, part of the Power Platform alongside Power BI, Power Apps, and Power Pages. "Low-code" means you build automation by configuring pre-built **connectors**, **triggers**, and **actions** in a visual designer, instead of writing integration code by hand. At Castlebridge Logistics, this is the difference between waiting weeks for a developer to wire SharePoint to Outlook, and a dispatch supervisor building that same connection herself in an afternoon.

## Three kinds of automation under one name

"Power Automate" actually covers three distinct capabilities:

- **Cloud flows** — automations that run in Microsoft's cloud, connecting apps like SharePoint, Outlook, Teams, and hundreds of other services. This is what the rest of this course focuses on, starting with Lesson 2.
- **Desktop flows (RPA)** — robotic process automation that clicks, types, and reads data in older desktop applications that have no modern connector, such as a legacy freight-rate lookup tool.
- **Process mining** — analyzes your existing system logs to show how a business process actually runs today, surfacing bottlenecks before you automate anything.

## Why Castlebridge Logistics automates with it

- It connects applications Castlebridge's staff already use daily — SharePoint, Outlook, Teams, Excel — without requiring a developer or a deployment.
- Business users, not IT, can own and maintain their own flows, like a dispatch supervisor's shipping approval flow.
- It scales from a single person's instant flow up to automations that run across the whole warehouse operation.

## Key terms

- **Power Platform** — Microsoft's suite of low-code tools: Power BI, Power Apps, Power Pages, and Power Automate
- **Cloud flow** — an automation that runs in Microsoft's cloud, built from a trigger and one or more actions
- **Desktop flow (RPA)** — robotic process automation that operates desktop applications directly, used when no cloud connector exists
- **Process mining** — analysis of existing system logs to understand how a business process runs before automating it
