# Script — What DevOps Is (and Isn't)

## Segment 1 (title)

Welcome to CI/CD Pipelines, the tenth course in the DevOps Engineer path. Before you write a single pipeline, let's get one word straight, because almost everyone misuses it: DevOps. You'll follow Northbridge Retail, a mid-size e-commerce retailer, as its engineers build real pipelines throughout this course.

## Segment 2 (steps)

For decades, Dev and Ops were separate teams with opposing incentives. Developers were measured on shipping features fast; operations staff were measured on keeping production stable, which meant resisting change. A developer at a company like Northbridge Retail could finish a feature on Monday and wait weeks for a change-advisory board to approve the deployment window. DevOps emerged around 2009 as a direct response: if the people who build software and the people who run it share responsibility and tooling, releases get faster and safer at the same time.

## Segment 3 (steps)

DevOps has three layers. Culture is shared ownership of reliability and blameless retrospectives instead of finger-pointing. Practices are things like continuous integration, infrastructure as code, and monitoring. Tools are the systems that make those practices possible — Git, GitHub Actions, Azure Pipelines, Kubernetes, and everything else in this course. None of the three works alone; a team with great tools but no shared ownership hasn't actually changed anything.

## Segment 4 (steps)

Three misconceptions come up constantly. DevOps isn't a job title for one more silo — hiring one person to sit between Dev and Ops rebuilds the same wall, even though the title itself is useful shorthand for specialized skills. It isn't just automation — automating a broken process just makes it fail faster. And it isn't the same thing as CI slash CD, which is this entire course's subject, but only one of DevOps's practices alongside infrastructure as code and monitoring.

## Segment 5 (outro)

This course goes deep on exactly one DevOps practice: the automated path code takes from a commit to production. Up next, lesson two: the software delivery lifecycle.
