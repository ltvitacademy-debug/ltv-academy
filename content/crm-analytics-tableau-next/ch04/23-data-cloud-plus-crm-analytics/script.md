# Script — Data Cloud + CRM Analytics, Together

## Segment 1 (title)

CRM Analytics and Data Cloud, now branded Data 360, are separate products. This lesson closes the chapter by connecting them. Product details have moved recently, so confirm setup specifics in the current release notes.

## Segment 2 (screenshot: Data Explorer)

This is Data Explorer in Data Cloud, with its object-type list: data lake objects, data model objects, and calculated insights. Those are the three kinds of Data Cloud object that CRM Analytics can be pointed at.

## Segment 3 (steps: three objects)

Data lake objects are the raw ingested data. Data model objects are the mapped, standardized model, including unified profiles. Calculated insights are the pre-aggregated metrics from lesson 21.

## Segment 4 (code: two paths)

There are two ways in. Extract and prepare: sync into connected objects, shape it with a recipe, and build a dataset, a copy tuned for CRM Analytics. Or query live: the dashboard asks Data Cloud at query time, with no copy, but the source wasn't built for interactive dashboards.

## Segment 5 (steps: habits)

So prefer calculated insights over raw objects for aggregates, filter early, and pick only the fields you need. If a dashboard needs speed or joins with other datasets, use a recipe and a dataset instead. Many solutions mix both.
