# Script — What Tableau Next Is

## Segment 1 (title)

You know Tableau Desktop and Tableau Cloud. Salesforce also has a product called Tableau Next, and the name invites confusion. Names and licensing have shifted quickly, so check current release notes for specifics.

## Segment 2 (screenshot: architecture)

This is Salesforce's own diagram of the layers: a data layer, a semantic layer, visualization, and actionability, with a marketplace for sharing assets, and Agentforce analytics skills on the right. Data 360, formerly Data Cloud, is the data foundation. Tableau Semantics is the semantic layer.

## Segment 3 (screenshot: workspace)

And this is a workspace, from an early Trailhead screenshot when the product still carried a beta label. It lists a team's assets by type: dashboards, visualizations, semantic models, and tables. Interface details may have changed since.

## Segment 4 (steps: assets)

So the things you build are separate assets. Data you connect, a semantic model that adds business meaning, visualizations, dashboards, and metrics that track measures over time.

## Segment 5 (code: not version two)

One important point: Tableau Next is not Tableau, version two. Tableau Desktop and Cloud continue to exist. Tableau Next is a separate product built on Salesforce, with the semantic model as its central idea.
