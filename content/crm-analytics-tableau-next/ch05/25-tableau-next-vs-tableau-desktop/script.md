# Script — Tableau Next vs. Tableau Desktop

## Segment 1 (title)

You already know how to build in Tableau Desktop. So what carries over to Tableau Next, and what is genuinely different? Product details are changing quickly, so check current release notes for specifics. This lesson gives you a concept map, so you know which skills you keep and which habits you need to update.

## Segment 2 (screenshot: visualization builder)

This is the Tableau Next visualization builder, from Salesforce's documentation. Fields on the left, filters and marks in the middle, columns and rows across the top. If you have used Tableau, this drag-and-drop layout will feel very familiar, and your chart design judgment transfers directly. Choosing a chart type, using color with purpose, and filtering carefully all still apply.

## Segment 3 (screenshot: semantic model fields)

But look at where the fields come from. This list shows a semantic model, with calculated fields and objects like Orders and People. That is the first big difference: fields come from a shared model, not from one workbook's own connection. Every chart built on this model starts from the same definitions.

## Segment 4 (steps: four differences)

There are four differences to internalize. It runs in the browser, inside Salesforce. Data comes through Data 360. Definitions live in a semantic model. And Agentforce is built into the platform. Tableau Desktop and Cloud have AI features too, so the difference is integration, not whether AI exists.

## Segment 5 (code: translation)

Here is a rough translation. A data source with calculations becomes a semantic model. A workbook becomes separate assets in a workspace. Publishing becomes sharing, embedding, or templates. Licensing differs too, so check what applies to you. Neither tool replaces the other, and Lesson 29 helps you choose between them.
