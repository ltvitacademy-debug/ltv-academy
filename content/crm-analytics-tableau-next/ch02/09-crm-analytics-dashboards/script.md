# Script — CRM Analytics Dashboards

## Segment 1 (title)

You built native dashboards before, where each widget came from a report. CRM Analytics dashboards look similar, but every widget queries a dataset instead, and that changes what they can do.

## Segment 2 (screenshot: create dialog)

Starting one is simple. Choose Create, then Dashboard, and you're offered a blank dashboard, or a dashboard from a template. Templates carry proven layouts and suggested widgets, but here's the catch: you can only apply a template when the dashboard is created, not afterward. When you save, you pick the app it lives in.

## Segment 3 (screenshot: finished dashboard)

Here's a finished sales performance dashboard. Filter selectors run along the top. Below are a stacked column chart, a panel of key metric numbers, and a detail table. Each of these is a widget on a cell-based grid, and each is powered by a step, a query against a dataset.

## Segment 4 (steps: widget types)

The core widget types: numbers for a single key metric, charts to compare values across a dimension, tables for record-level detail, and filter widgets, like lists, dates, and toggles, that viewers use to change what they see. Text, image, and link widgets handle titles and navigation.

## Segment 5 (screenshot: faceting)

And now the interactive part, called faceting. Here, one filter is set to a single opportunity owner, and the chart, the key numbers, and the table all narrow to that person's records at once. Nobody edited anything or reran a report. Widgets facet automatically when they share a dataset, and Chapter 3 shows how to connect the rest.
