# Script — Capstone: Wrap-Up & Portfolio Presentation

## Segment 1 (title)

Six lessons ago, Bellhaven had one database on one unprotected server and two numbers from the
business. This lesson closes the loop — what got built, what testing actually proved, and how to
present this project yourself.

## Segment 2 (steps: what got built, chapter by chapter)

Chapter 1's backup discipline became a real schedule matched to a 5-minute RPO. Chapter 3's
decision framework became the choice of one Availability Group over an FCI or log shipping alone.
Chapters 4 through 6 became AG_Bellhaven itself, and Chapter 8 became two real tests plus a
runbook someone else could actually run.

## Segment 3 (code: what the tests proved)

The part worth leading with in an interview isn't the configuration — it's that Lesson 45 measured
an actual failover time well inside the 15-minute RTO with zero data loss, and Lesson 46 measured
a real data-loss window against the 5-minute RPO instead of assuming it held. That's the
difference between a design and a proven system.

## Segment 4 (outro)

This course completes the second of four Advanced-stage courses in the SQL Server Database
Administrator path, alongside SQL Server Performance Tuning, Azure Database Administrator, and
PowerShell Automation & DevOps for DBAs. From here, the rest of the Advanced stage builds the same
kind of concrete, tested project for the cloud and automation sides of the job.
