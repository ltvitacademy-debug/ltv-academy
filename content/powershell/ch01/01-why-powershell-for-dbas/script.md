# Script — What Is PowerShell & Why for DBAs and Admins?

## Segment 1 (title)

This course's goal is stated plainly: by the end, you should be able to read an existing PowerShell script, understand what it does, modify it safely, and run it — not write a 500-line module from scratch.

## Segment 2 (code: the one real difference)

If you've used bash or cmd.exe, the biggest adjustment is this — PowerShell's pipeline passes real objects between commands, not plain text. That's the entire reason objects-versus-text gets its own dedicated lesson later — it's what makes a PowerShell script more reliable than an equivalent shell script silently depending on a text format never changing.

## Segment 3 (steps: why this matters for a DBA)

Checking a fleet of servers for configuration drift, automating a routine maintenance task across many databases, and connecting to Azure resources without clicking through the Portal every time — real, common DBA jobs this course builds toward.

## Segment 4 (outro)

Basics, then objects and pipelines, then scripts and control flow, then PowerShell specifically for Azure and SQL. Next up: the console, ISE, and VS Code — where you'll actually write this.
