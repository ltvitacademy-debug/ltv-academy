# Script — The Console, ISE & VS Code

## Segment 1 (title)

Three places you'll type or write PowerShell — the console, the ISE, and VS Code — and only one of them is where you should actually be writing scripts.

## Segment 2 (steps: the three environments)

The console is a read-eval-print loop, great for a quick one-liner but nothing is saved when you close it. The ISE is Microsoft's legacy script editor — still preinstalled on older servers, but stuck on Windows PowerShell 5.1 and no longer actively developed. VS Code with the PowerShell extension is what Microsoft actively develops for today, with real syntax highlighting, autocomplete, and a debugger.

## Segment 3 (code: the honest recommendation)

Use the console for a one-off command you'll never need again. Use VS Code for anything you'll save, rerun, or hand to a teammate — which is almost everything starting in Chapter 3, where every script in this course is written in VS Code.

## Segment 4 (outro)

Install VS Code and the PowerShell extension now if you haven't already. Next up: cmdlets and syntax — the Verb-Noun pattern behind every command you'll type.
