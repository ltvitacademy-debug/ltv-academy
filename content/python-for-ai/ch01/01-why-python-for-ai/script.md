# Script — Why Python for AI Engineering?

## Segment 1 (title)

Welcome to Python for AI Engineering. Before we write a single line of code, let's answer the question you're probably already asking: why Python, specifically?

## Segment 2 (steps: the three reasons)

It isn't an accident. Every major AI provider — OpenAI, Anthropic, Google, Meta — ships its official SDK in Python first, sometimes only in Python for the newest features. PyTorch and TensorFlow, the two frameworks behind nearly every modern AI model, are Python libraries at their core. Three things explain why: readable syntax that puts less ceremony between an idea and working code, a massive ecosystem of libraries built over two decades, and first-class support — every provider builds for Python first.

## Segment 3 (code: what AI engineers actually do)

Here's something worth clearing up early: most AI engineering work isn't training models from scratch. That's a smaller, research-heavy specialty. Most of the job is integration — calling a model's API, shaping the data you send it, handling what comes back, and wiring all of that into a real application that works reliably at scale. That's almost entirely Python: a request to an API, data structures to hold it, functions to organize the logic, and error handling for when something goes wrong.

## Segment 4 (code: what this course covers)

This course assumes zero prior programming. Chapters 1 and 2 build the core language itself — variables, control flow, functions, error handling, and the data structures you'll use constantly to shape data for an AI API. From there, the path moves into object-oriented Python, packaging, real HTTP API calls, async programming for handling multiple AI calls at once, testing, and a capstone project.

## Segment 5 (outro)

Every piece of this course earns its place because it shows up in real AI-engineering code, not because it's a computer-science classic. Next up: getting Python itself installed and your environment ready to write code.
