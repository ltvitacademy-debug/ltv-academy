# Script — Introduction to Copilot Studio

## Segment 1 (title)

Every AI call you've made so far in this course has lived inside a Power Automate flow you designed step by step. That works great when you already know the exact sequence a task needs. This lesson introduces Microsoft Copilot Studio, the tool built for the tasks that don't arrive in a fixed sequence.

## Segment 2 (steps)

A Power Automate flow is deterministic — you draw the exact path from trigger to outcome, and it always takes that path. A Copilot Studio agent works differently. You give it instructions, knowledge, and a set of tools, and at runtime it reasons about the request and decides what to do. It's a different design job: instead of drawing a flowchart, you're writing a job description. And underneath, it still relies on the same AI Builder and Azure AI connectors you already know.

## Segment 3 (screenshot)

This is the Copilot Studio Home page, accessed separately from Power Automate at copilotstudio-dot-microsoft-dot-com. From here you choose what to build: an agent, or a workflow. It's licensed on its own too, so expect a different sign-in experience the first time you open it.

## Segment 4 (steps)

Copilot Studio gives you three things to build. An agent is the conversational brain — it holds instructions, connects to knowledge sources, and calls tools to take action. A workflow is a drag-and-drop automation builder paired tightly with generative AI steps. And an agent flow is Copilot Studio's own flow format, built with a trigger and actions just like a Power Automate flow — it can run on its own, or attach to an agent as a tool the agent calls when it needs to.
