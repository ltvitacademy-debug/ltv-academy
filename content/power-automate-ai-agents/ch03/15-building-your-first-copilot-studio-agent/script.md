# Script — Building Your First Copilot Studio Agent

## Segment 1 (title)

Time to build one. In this lesson you'll create a real Copilot Studio agent for Castlebridge Logistics — a first pass at the kind of agent you'll finish in this chapter's capstone. You won't connect it to any flows yet; that's next lesson. For now, get comfortable with the creation experience itself.

## Segment 2 (screenshot)

The fastest way to start is to describe what you want on the Home page, in your own words, up to around a thousand characters. Castlebridge's IT team might type something like: help users understand Copilot Studio and how Castlebridge uses it alongside Power Automate.

## Segment 3 (steps)

When you submit a description, Copilot Studio's AI generates a starting name, description, and instructions, and suggests triggers, knowledge sources, and tools. None of it is permanent until you accept it — you review each suggestion and add, dismiss, or ignore it. If you'd rather skip natural language entirely, select create blank agent, name it yourself, and configure everything by hand.

## Segment 4 (screenshot)

Either path lands you on the same place: the agent's Overview page. This is the control center you'll return to constantly. From here you edit the agent's details and icon, write its instructions — up to eight thousand characters, the single most important thing you'll write for any agent — choose its underlying model, and add knowledge sources.

## Segment 5 (steps)

Before you add a single tool, use the test panel on the right to ask the agent a baseline question with nothing attached. That establishes what the instructions alone produce, so once you start layering on tools and flows, you'll know whether a weird response comes from a bad instruction, missing knowledge, or a misfiring tool.

## Segment 6 (outro)

Next up, Lesson 16: you'll give this agent something to actually do, by connecting it to a Power Automate-style flow.
