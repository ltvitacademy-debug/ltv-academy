# Lesson 23 — Program Maturity Assessment · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Chapter 3 covered KPIs and dashboards — the ongoing "is governance
healthy this month" view. A maturity assessment asks a slower-moving
question instead: how capable is this program, structurally, compared
to where it started, and compared to where it still needs to go.

## S2 · STEPS CARD (five generic levels)

There's no single official maturity model this course claims as
authoritative — vendors publish their own branded versions. What's
useful is the general shape: ad hoc, developing, defined, managed, and
optimized, where the program eventually improves itself instead of
needing to be reminded.

## S3 · STEPS CARD (score dimensions separately)

A program is rarely at the same level everywhere, so score dimensions
independently instead of collapsing into one number: stewardship,
policy and process, measurement, adoption and culture, and tooling. A
program that's managed on measurement but still ad hoc on adoption has
a specific, actionable gap a blended score would hide.

## S4 · STEPS CARD (feeding it back)

An assessment that changes nothing is just an exercise. A weak
dimension becomes a Now or Next item on the roadmap from Lesson 21.
A dimension that moved up a level becomes evidence in the value
realization report from Lesson 22 — proof the budget produced real
structural improvement.

## S5 · OUTRO CARD

Treat the five levels as a shared vocabulary for an honest
conversation, not a certification to chase for its own sake. Next: a
full case study applying every chapter of this course, start to
finish.
