# Script — What Is Cloud Computing?

## Segment 1 (title)

"Someone else's computer" undersells what actually changed. Cloud computing is renting compute, storage, and networking from a provider — available in minutes, billed by actual usage, resizable without buying anything new.

## Segment 2 (code: CapEx vs OpEx)

Capital expenditure is a large upfront purchase that depreciates over years. Operating expenditure is an ongoing cost that scales with actual use, like a utility bill. Cloud computing turns most infrastructure spending from CapEx into OpEx — that's why a startup can run production infrastructure without raising capital for hardware first.

## Segment 3 (steps: the five characteristics)

On-demand self-service, broad network access, resource pooling, rapid elasticity, measured service — five real, specific traits, not vague marketing language.
