# Script — Subscriptions & Resource Groups

## Segment 1 (title)

A subscription is Azure's billing and access boundary. A resource group is a logical container for related resources inside it — managed together, and deleted together.

## Segment 2 (screenshot: create resource group)

Creating one just asks for three things: which subscription, a name, and a region for the group's own metadata.

## Segment 3 (screenshot: list resource groups)

Once you have a few, the portal lists them like any other resource — searchable, sortable, each one showing how many resources it contains.

## Segment 4 (steps: why grouping matters)

They're managed together — apply a permission or tag once. And they're deleted together — the fastest way to tear down a whole test environment in one action.
