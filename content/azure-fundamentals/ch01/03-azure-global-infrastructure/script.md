# Script — Azure Global Infrastructure: Regions & Availability Zones

## Segment 1 (title)

An Azure region is a set of datacenters in one geographic area, connected by a low-latency network. Every resource you create asks you to pick one.

## Segment 2 (code: region and zones)

Inside a region, availability zones are physically separate datacenters — each with its own power, cooling, and networking. If one zone fails, spreading your resource across zones keeps it running.

## Segment 3 (steps: why the region choice matters)

Latency — put resources near the users who'll actually use them. Data residency — some data must legally stay within a country's borders. Service availability — not every Azure service is offered in every region.
