# Script — Azure Monitor Basics

## Segment 1 (title)

Azure Monitor is Azure's platform-wide observability service — it collects data from almost every resource automatically, no separate agent required for the basics.

## Segment 2 (screenshot: overview diagram)

Applications, operating systems, Azure resources, even whole subscriptions and tenants all flow into Azure Monitor, which feeds visualizations, analysis, and alerting.

## Segment 3 (steps: metrics, logs, alerts)

Metrics are numbers over time, like CPU percentage. Logs are detailed event records — what actually happened. Alerts watch metrics or logs and notify you when a condition is met.
