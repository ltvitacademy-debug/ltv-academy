# Script — Azure Storage Overview

## Segment 1 (title)

Every Azure storage service lives inside a Storage Account. This lesson covers two of them at the awareness level: Blob Storage and Azure Files.

## Segment 2 (code: the two services)

Blob Storage holds unstructured files — images, video, logs, backups — built to scale cheaply. Azure Files is a fully managed, SMB-accessible file share, mountable by multiple machines at once.

## Segment 3 (steps: picking between them)

If multiple systems need to mount a shared drive, Azure Files fits. If you're just storing and retrieving files without needing to browse them like a folder, Blob Storage is the simpler fit.

## Segment 4 (outro)

Neither is "better" — they solve different shapes of the same problem: where a file actually lives. Next up: Azure Networking Basics and virtual networks.
