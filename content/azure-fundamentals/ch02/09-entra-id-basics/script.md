# Script — Microsoft Entra ID Basics

## Segment 1 (title)

Microsoft Entra ID is Azure's identity service, formerly called Azure Active Directory. It's where Azure keeps track of who exists and what they're allowed to do.

## Segment 2 (code: users and groups)

A user is an identity that can sign in. A group is a collection of users — grant a permission once to the group instead of fifty times to individual people.

## Segment 3 (steps: why it matters)

Signing into the portal, running a command, an app accessing a resource on your behalf — every one of those checks against Entra ID first: is this a real identity, and is it allowed to do this?

## Segment 4 (outro)

The same Entra ID tenant can span multiple subscriptions — it's the separate, overarching answer to who's allowed to do what. Next up: Azure Monitor and platform-wide observability.
