# Script — Azure Compute Overview: VMs & App Service

## Segment 1 (title)

Chapter 2 gets hands-on with real services, starting with compute — where your application's code actually runs. Two options: Virtual Machines and App Service.

## Segment 2 (code: comparison)

Virtual Machines are IaaS — you manage the OS, runtime, and app; setup is slower but you get full control. App Service is PaaS — you just deploy your code, and scaling is built in.

## Segment 3 (steps: when to pick each)

Pick a VM when you need OS-level control, or you're running legacy software that won't run any other way. Pick App Service when you're building a standard web app or API and want less to manage.

## Segment 4 (outro)

The real decision is whether you need OS control badly enough to manage it yourself. Next up: Azure Storage — Blob Storage and Azure Files.
