# Script — Compliance Basics

## Segment 1 (title)

Compliance means meeting external legal, industry, or contractual standards about how data is handled. In the cloud it's shared: Microsoft secures the underlying platform, the customer is responsible for how they configure and use it.

## Segment 2 (code: trust center)

The Microsoft Trust Center publishes Azure's compliance posture — certifications, audit reports, documentation a company's own compliance team can use as evidence. It's the real reference point, not marketing copy.

## Segment 3 (steps: frameworks by name)

SOC 2, an auditor's report on security controls. ISO 27001, an international information-security standard. GDPR, EU data privacy regulation. HIPAA, US health-information regulation. You need to recognize these names, not memorize their details.

## Segment 4 (code: honest scope)

Deep compliance work is its own specialization — mapping controls to regulations, managing audits. AZ-900 doesn't require mastering that. It requires knowing compliance is a real constraint, and that being on Azure never by itself means you're compliant with anything.

## Segment 5 (outro)

That's Chapter 3, complete. Chapter 4, Working in Azure, moves from concepts to practice — starting with the Azure CLI.
