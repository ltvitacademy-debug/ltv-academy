# Script — AZ-900 Exam Overview

## Segment 1 (title)

AZ-900 tests exactly the ground this course covered — not hands-on engineering skill, but whether you understand cloud concepts, core Azure services, and how security, pricing, and governance work conceptually.

## Segment 2 (steps: exam areas map to chapters)

Cloud concepts maps to Chapter 1. Azure architecture and services maps to Chapter 2. Azure management and governance maps to Chapter 3. If you've worked through these 18 lessons honestly, you already have the ground this exam tests.

## Segment 3 (code: format)

AZ-900 is a proctored, multiple-choice exam, roughly 40 to 60 questions, about an hour, no lab component and no code to write. Microsoft's own free AZ-900 learning path plus a practice exam is the most useful next step.

## Segment 4 (code: the full arc)

Four chapters, eighteen lessons: cloud and Azure concepts, core Azure services, security pricing and governance, and working in Azure. Enough to walk into any Azure-flavored course in this catalog without being lost on vocabulary.

## Segment 5 (outro)

Course complete. Azure Database Administrator and Data Factory both assume this foundation, and PowerShell Fundamentals is a natural next step if you want scripting skills alongside the CLI habits from this chapter.
