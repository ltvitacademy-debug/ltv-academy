## What AZ-900 actually tests

**AZ-900 (Microsoft Azure Fundamentals)** is Microsoft's entry-level
certification, and it tests exactly the ground this course covered — not
hands-on engineering skill, but whether you understand cloud concepts, core
Azure services, and how security, pricing, and governance work at a
conceptual level. Microsoft groups the exam into roughly four areas:

| Exam area | What it maps to in this course |
|---|---|
| Cloud concepts | Chapter 1 — CapEx/OpEx, IaaS/PaaS/SaaS, regions |
| Azure architecture and services | Chapter 2 — compute, storage, networking, Entra ID, Monitor |
| Azure management and governance | Chapter 3 — RBAC, pricing, Policy, tags, compliance |
| (Working knowledge, not directly scored) | Chapter 4 — CLI, ARM/Bicep, deploying a resource |

If you've genuinely worked through this course's 18 lessons, you already
have the conceptual ground AZ-900 tests. The exam doesn't ask you to write a
Bicep file or run a CLI command from memory — it asks whether you understand
*what* these things are and *why* they exist, exactly the level this course
was built at.

## Format and how to approach it

AZ-900 is a proctored, multiple-choice/multiple-select exam, roughly 40-60
questions, about an hour. There's no lab component and no code to write. The
most useful preparation beyond this course is Microsoft's own free official
AZ-900 learning path on Microsoft Learn, plus a practice exam or two to get
used to the question style — the concepts should already be familiar if
you've been doing the "Check yourself" question at the end of each lesson
honestly.

```
Chapter 1 — Cloud & Azure Concepts
  What cloud computing is, IaaS/PaaS/SaaS, regions, the Portal, resource groups

Chapter 2 — Core Azure Services
  Compute, storage, networking, Entra ID, Monitor

Chapter 3 — Security, Pricing & Governance
  RBAC, pricing and cost tools, Policy/tags/management groups, compliance

Chapter 4 — Working in Azure
  CLI, ARM & Bicep, your first real deployment, and this exam overview
```

Eighteen lessons, four chapters — enough to walk into any Azure-flavored
course in this catalog without being lost on vocabulary, and enough to sit
the AZ-900 exam with real understanding, not memorized flashcards.

## Where to go next in this catalog

This course doesn't complete a career path by itself — it's the foundation
two Job-Ready-stage courses in the **Azure Database Administrator** career
path build on directly. Specifically:

- **Azure Database Administrator** (DP-300 prep) — assumes you already know what a resource group, RBAC, and the Portal are; this course is that prerequisite
- **Data Factory** — same assumption, applied to data pipelines instead of databases
- **PowerShell Fundamentals** — not required next, but a natural companion if you want scripting skills alongside the CLI habits from Lesson 15

None of those three courses are fully built out in this catalog yet, but
when you're ready to continue past this foundation, that's the direction —
either toward database administration, toward data pipelines, or toward
scripting.

## Key terms

| Term | Meaning |
|---|---|
| AZ-900 | Microsoft's entry-level, concept-focused Azure certification exam |
| Proctored exam | A monitored exam, taken online or at a testing center |
| Microsoft Learn | Microsoft's own free learning platform, including an AZ-900 path |

You're ready when you can explain, in plain language, what a resource group
is, what IaaS/PaaS/SaaS mean, and why a company would choose OpEx cloud
spending over CapEx hardware, to someone with zero cloud background.
