## S1 · TITLE CARD

## S2 · STEPS CARD (sidebar)

The entire left sidebar maps almost exactly to this course.
Workspace is notebooks and files — that's this lesson. Compute is
clusters — Lesson 4. Jobs and pipelines covers scheduled runs and
Lakeflow — Lesson 11 and this course's entire Chapter 5. And
Catalog is Unity Catalog — this course's Chapter 4.

## S3 · CODE CARD (file browser)

Clicking Workspace opens a file browser you'd recognize from any
cloud storage UI. Your home folder is private by default. A shared
folder is visible to the whole workspace. Notebooks live here as
regular files, organized in folders — nothing exotic about it.

## S4 · CODE CARD (personal vs shared)

And that split is a real decision, even early on. Home for
exploratory, practice work. Shared for anything meant to be reused
or reviewed by a team. It's the exact same instinct as Foundations'
raw and cleansed data zones — just applied to code instead of data.
