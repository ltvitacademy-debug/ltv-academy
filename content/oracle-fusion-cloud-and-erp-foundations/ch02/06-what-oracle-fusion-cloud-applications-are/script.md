# Script — What Oracle Fusion Cloud Applications Are

## Segment 1 (title)

Chapter 1 covered ERP in general. Now let's get specific: what exactly is Oracle Fusion Cloud, and how does it fit into Oracle's much larger product history?

## Segment 2 (code: Oracle's modern suite)

Oracle Fusion Cloud Applications is Oracle's modern, multi-tenant SaaS suite, built from the ground up on Oracle Cloud Infrastructure. It's the strategic successor to older product lines Oracle still supports — E-Business Suite, PeopleSoft, JD Edwards, and Siebel — but it's where Oracle is investing its newest capabilities.

## Segment 3 (steps: the pillars)

The suite is organized into pillars: ERP, covering Financials, Procurement, and Project Management — where this path lives. SCM, covering supply chain. HCM, covering human capital management. CX, covering sales, service, and marketing. And EPM, covering planning and consolidation.

## Segment 4 (steps: one unified data model)

What makes this a real suite rather than just several apps sold together is a single, shared data model. A customer, supplier, or person record is the same underlying record across every pillar — not separate copies stitched together by middleware.

## Segment 5 (outro)

This career path's name tells you which pillar matters most: Oracle Fusion Cloud ERP, specifically Financials. Next up, Lesson 7: the SaaS model in more depth, and exactly what Oracle manages for you.
