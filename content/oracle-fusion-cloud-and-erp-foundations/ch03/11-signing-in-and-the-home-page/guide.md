# Signing In and the Home Page

## Signing in

Oracle Fusion Cloud is accessed entirely through a web browser, at a URL specific to the customer's own environment (recall from Lesson 9 that Production and non-production each have their own separate address). A user signs in with credentials tied to their **user account**, which carries whatever **security roles** have been assigned to them — Lesson 19 and the later Oracle Fusion Security course cover how those roles determine what a person can see and do. Two different people signing into the exact same environment can see noticeably different home pages, menus, and work areas, entirely based on their assigned roles.

## The home page, piece by piece

Once signed in, a user lands on the **home page** — Oracle's term for the landing screen, not just "the first page you happen to see." A few consistent pieces make it up:

- **Global header.** A bar across the top of every page containing the Oracle logo area, a global search field, a notifications bell, and the user's own account menu.
- **Navigator.** A menu icon in the global header that opens the full list of work areas a user has access to, organized by product family (Lesson 12 covers this in depth).
- **Springboard.** The grid of icons on the home page itself, each one a shortcut into a work area the user has access to — their most frequently needed starting points, one click away.
- **Infolets.** Small, interactive widgets on the home page that surface a quick, glanceable summary of information relevant to that user's role — for example, an AP clerk might see an infolet summarizing invoices awaiting approval.
- **Notifications.** Pending approvals and alerts that need a user's attention, visible from the bell icon in the global header.

## Why the design favors glanceable information

Oracle built the Fusion home page around the idea that a user should be able to tell, within seconds of logging in, what needs their attention that day — without digging through menus first. Infolets exist specifically for this: rather than opening a report to see how many invoices are stuck in approval, the number is already sitting on the home page the moment you sign in. This "tell me what matters, right away" design philosophy carries through the rest of Fusion's interface, which the next few lessons build on.

## Key terms

| Term | Meaning |
|---|---|
| Home page | Oracle's term for the landing screen after sign-in |
| Global header | The top bar present on every page: search, notifications, account menu |
| Springboard | The grid of work-area shortcut icons on the home page |
| Infolet | A small interactive widget surfacing glanceable, role-relevant information |
| Security role | What determines which work areas and data a signed-in user can see |
