# Searching, Favorites and Saved Searches

**Chapter 3 · Working in Oracle Fusion · Lesson 14 of 20**

Lesson 12 briefly introduced Favorites. This lesson covers it properly, alongside two closely related tools every daily Oracle Fusion user relies on: global search and saved searches.

## What you'll learn

- How global search works across the application
- Favorites, revisited in depth
- What a "saved search" is and how it differs from a Favorite
- Why these three tools together define day-to-day efficiency

## Global search

A search icon sits in the global header on every page (Lesson 11), giving access to **global search** — a single search box that can look across both **transactions** (specific invoices, journals, purchase orders) and **setup/navigation** (work areas, tasks, reports) depending on what's configured and what the user has access to. Typing a supplier's name or an invoice number into global search can take a user directly to the relevant record, without first figuring out which work area it lives in.

## Favorites, revisited

**Favorites** let a user mark a specific work area, task, report, or even a specific saved search (below) for one-click access later, typically from a Favorites menu in the global header. Unlike the springboard, which usually reflects broader defaults for a role, Favorites are personal — two AP clerks doing the same job might still favorite slightly different things based on their own habits.

## Saved searches

A **saved search** is different from a Favorite in an important way: it isn't just a shortcut to a page, it's a stored set of **search or filter criteria** on a specific list or search page, so the user doesn't have to re-enter the same filters every time. For example, an AP clerk who regularly needs to see "all invoices over $5,000, still pending approval, for the Manufacturing business unit" can save exactly that filter combination as a saved search, and re-run it with one click instead of rebuilding the filter from scratch. Saved searches can often be marked as the default view for a page, so the user's preferred filter loads automatically.

## How these three work together

Think of them as three different shortcuts for three different problems:

- **Global search** — "I know roughly what I'm looking for; find it anywhere."
- **Favorites** — "I go to this exact page or report constantly; take me there in one click."
- **Saved search** — "I always filter this list the same specific way; remember that filter for me."

A proficient Oracle Fusion user combines all three rather than relying only on the full Navigator every time. Training end users to use these tools well is a real, practical part of a consultant's job during and after implementation — a user who only ever navigates through the full menu structure is working much harder than they need to.

## Key terms

| Term | Meaning |
|---|---|
| Global search | A single search box covering transactions and navigation across the application |
| Favorite | A personal, one-click shortcut to a specific page, task, or report |
| Saved search | Stored filter criteria on a specific list or search page, re-runnable with one click |
