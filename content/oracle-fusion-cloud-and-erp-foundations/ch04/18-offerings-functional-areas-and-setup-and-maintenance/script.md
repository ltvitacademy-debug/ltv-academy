# Script — Offerings, Functional Areas and Setup and Maintenance

## Segment 1 (title)

Every lesson so far has referenced configuration without pinning down exactly where that happens. Here's the actual place: the Setup and Maintenance work area, and the hierarchy Oracle uses to organize every configuration decision inside it.

## Segment 2 (code: setup and maintenance)

Setup and Maintenance is the dedicated work area where all of an implementation's configuration tasks live — the structured front door to configuring Fusion Cloud, instead of hunting for setup screens scattered across the application.

## Segment 3 (steps: the hierarchy)

Three levels. An Offering is the broadest grouping, like Financials. A Functional Area groups related configuration within it, like Payables or Receivables. And a Task is the actual specific activity, like Manage Payment Terms.

## Segment 4 (steps: implementation projects)

An implementation project is a named, scoped set of offerings, functional areas, and tasks for one company's rollout. A team selects exactly what's in scope, assigns tasks to specific people with target dates, and tracks progress with a real number — not a guess.
