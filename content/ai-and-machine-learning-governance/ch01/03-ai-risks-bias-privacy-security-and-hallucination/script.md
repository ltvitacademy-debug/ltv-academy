# Lesson 3 — AI Risks: Bias, Privacy, Security and Hallucination · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Four risk categories show up across nearly every AI governance program. This lesson walks through each one in plain language.

## S2 · STEPS — Bias

Bias is a model's outputs systematically favoring or disfavoring a group, in a way that doesn't track what the model is actually supposed to measure. It's rarely one bad decision — usually it's the training data reflecting a real-world imbalance, and the model faithfully reproducing it at scale.

## S3 · STEPS — Privacy

Privacy risk is the chance an AI system exposes personal information it shouldn't. Training data can contain information that was never meant to end up in a model. A model can sometimes be prompted into reproducing memorized training data. The model itself can become the exposure, with no traditional breach required.

## S4 · STEPS — Security

Security risk covers ways an AI system gets attacked or manipulated. Adversarial inputs designed to fool a classification. Prompt injection that overrides a generative system's instructions. Data poisoning during training. Theft of the model itself. Because models behave probabilistically, some of this is hard to fully rule out in advance.

## S5 · STEPS — Hallucination

Hallucination is specific to generative AI — fluent, confident output that's factually wrong. It happens because these models produce the most statistically likely next output, not verified truth, with no built-in way to say "I don't know." The danger is the confident tone giving no signal to double-check it.
