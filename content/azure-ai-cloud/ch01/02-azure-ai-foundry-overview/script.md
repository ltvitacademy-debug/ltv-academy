Let's open the portal this entire chapter runs through: Azure AI Foundry.

The Foundry portal does four jobs. The model catalog lets you browse and deploy over ten thousand models. Playgrounds — chat, agents, images, video — let you test a model before writing any code. Build and customize tools cover fine-tuning, prompt flow, and agent tooling. And assess and improve brings tracing, evaluation, and safety and security into one place.

Here's the real catalog landing page. Search for a model by name, select its card, and you're one click away from deploying it — this is literally where you'd find gpt-4o.

Once a model is deployed, you land in the chat playground. Set a system message, pick your deployment, and send a test prompt — all in the browser, before you write a single line of SDK code.

The agents playground works the same way but for agents: instructions, tools, knowledge sources, and a quick evaluation metrics panel you can turn on right from the Metrics menu, so you catch quality problems before you ship.

One thing worth knowing up front: this product has been renamed twice. It started as Azure AI Studio, became Azure AI Foundry, and as of 2026 Microsoft calls it Microsoft Foundry. The portal address — ai.azure.com — hasn't changed, and most job postings and documentation still say Azure AI Foundry, so both names are fair game.
