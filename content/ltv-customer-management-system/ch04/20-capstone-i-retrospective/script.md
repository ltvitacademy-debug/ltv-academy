# Lesson 20 — Capstone I Retrospective · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Twenty lessons, one company, one build. This lesson closes the loop — checking every requirement from Lesson 1 against what you actually built, and being honest about what you'd do differently.

## S2 · CODE — Every requirement, closed

Every one of the ten Definition of Done requirements is checked off: the full object model and custom objects from Chapter 2, the security model, Flows, validation rules, and approval process from Chapter 3, and reports, sample data, testing, and documentation from Chapter 4.

## S3 · STEPS — An honest design evolution

Worth saying honestly: two fields weren't in the original Lesson 3 data model. Primary Contact and Discount Percent both emerged in Chapter 3, once real automation requirements surfaced. That's realistic — a data model evolves slightly as you build, and documenting that honestly matters more than pretending the original design predicted everything.

## S4 · CODE — What you have now

What you have now is concrete: a working org, a data model diagram, a security matrix, four validation rules, two Flows, one approval process, three reports and a dashboard, realistic sample data, a full test pass, and a written handoff document — a defensible piece of work, not a badge.

## S5 · OUTRO

This closes out the Salesforce Administrator path's entire build arc. Next up is the path's final course, Salesforce Career Preparation — interview practice and mock technical interviews that draw directly on the walkthrough you built in Lesson 19.
