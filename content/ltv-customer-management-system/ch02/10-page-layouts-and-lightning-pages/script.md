# Lesson 10 — Page Layouts and Lightning Pages · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Everything in Chapter 2 comes together in this lesson — page layouts and a Lightning App Page built for how Cascade's own users actually work.

## S2 · STEPS — Three Account layouts

Account's six Record Types from Lesson 6 collapse into three layouts. The Restaurant layout leads with equipment interest and location count. The Key Account layout surfaces related Service Contracts for Hotel and Healthcare accounts — Priya Nair's multi-location customers. And a simpler Standard layout covers Education, Catering, and Dealer.

## S3 · STEPS — The Opportunity layout

The Opportunity layout puts the five-stage Path component right at the top, visually tracking Qualifying through Closed Won. Below it: core fields like Amount and Close Date, the Products related list showing the equipment package, and a related list for Installation Project so a rep can see install status without leaving the record.

## S4 · CODE — Custom object layouts

Each custom object gets its own focused layout. Installation Project surfaces the site, date, status, and installer that Marcus Webb's team edits. Service Contract surfaces the dates, tier, value, and renewal status that Angela Wu's team edits.

## S5 · STEPS — The Sales Workspace

Then comes the Lightning App Page — Sales Workspace. The Opportunity Path sits at the top, core fields in the left column, and the right column stacks an Account highlights panel, related Contacts, and the related Installation Project — the one coherent view Tom Baptiste and Priya Nair actually want to work from.

## S6 · STEPS — Checking off the Definition of Done

This single lesson checks off two full lines from Lesson 1's Definition of Done at once: page layouts matched to real Record Types, and a Lightning App Page built for a real workflow — not generic defaults left untouched.

## S7 · OUTRO

The data and objects are built. Next lesson opens Chapter 3 — implementing the real security model you designed back in Lesson 4.
