# Lesson 1 — Governance in Microsoft Fabric · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE CARD

Welcome to Fabric Data Governance. Microsoft Fabric bundles what used to be separate products into one platform — and this course teaches you how to govern it.

## S2 · STEPS CARD (what Fabric is)

One sentence worth remembering: one tenant, one lake, many workloads. Fabric bundles the lakehouse, the warehouse, Data Factory pipelines, Power BI, Real-Time Intelligence, and Data Science into a single SaaS platform, all built on one underlying lake called OneLake. Every item you create stores its data there automatically.

## S3 · STEPS CARD (why its own governance layer)

General governance theory applies everywhere, Fabric included. But because every workload shares the same lake, a permission mistake or an ungoverned workspace isn't boxed into one tool — it's visible tenant-wide by default. That's why this course goes deep on how governance shows up specifically inside Fabric's UI and architecture, not generic theory you'd find elsewhere in this catalog.

## S4 · STEPS CARD (the roadmap)

Five chapters, broad to narrow. Foundations — tenant, capacity, the admin portal, domains, workspaces. OneLake itself, lakehouses and warehouses, OneLake security and shortcuts. Security and protection — permissions, row and column security, sensitivity labels, auditing. Discovery and lineage. And governed analytics, closing with a case study and a practice lab.

## S5 · OUTRO CARD

This course assumes you already know how to build a lakehouse or pipeline — that's the separate Fabric and Real-Time Analytics course. Next lesson: the tenant and the capacity, the two-level structure everything else in Fabric sits inside.
