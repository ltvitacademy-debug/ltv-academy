# Script — Variables, Constants and Formulas

## Segment 1 (title)

Lesson 3 introduced resources as containers a flow references but never shows on the canvas. This lesson goes deep on the three you'll use constantly: variables, constants, and formulas.

## Segment 2 (screenshot: New Resource button)

You create one from the Toolbox's New Resource button — or from inside an element's own configuration panel while you're building.

## Segment 3 (screenshot: New Resource window)

That opens this window: Resource Type, API Name, and for a variable, a Data Type. The Resource Type dropdown is where variables, constants, formulas, and text templates diverge.

## Segment 4 (screenshot: formula resource)

A variable's value can change while the flow runs. A constant is fixed, set once, reused everywhere. A formula is calculated from other resources — like a spreadsheet formula — and Flow Builder recalculates it automatically.

## Segment 5 (screenshot: text template resource)

And a text template mixes literal words with merged values from other resources — the thing you'd reach for to build the body of an email or a Chatter post.
