# Lesson 10 — Survivorship Rules · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Survivorship rules are the explicit, documented logic that decides which
source wins for each attribute when building a golden record — not left
to whoever happens to be merging the record that day.

## S2 · STEPS CARD (common strategies)

Most recent wins — good for anything that changes over time, like a
phone number. Trusted source wins — a specific system is authoritative
for a specific attribute, like the ERP for billing address. Most
complete wins — a populated value beats a blank one by default.

## S3 · STEPS CARD (per attribute, not global)

A blanket rule like "the CRM always wins" usually breaks down — great for
contact details sales reps update constantly, terrible for billing
fields they never touch. Real survivorship logic is defined per
attribute, not as one global rule for the whole record.

## S4 · CODE CARD (a survivorship rule table)

Phone number: most recent source wins. Legal address: trusted source,
always the ERP. Segmentation field: most complete, since it's rarely
filled in anywhere. Each attribute gets its own rule, written down.
