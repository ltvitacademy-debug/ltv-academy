# Script — Combined Sets & Set Analysis

## Segment 1 (title)

Once you have two sets built on the same dimension, you can combine them into a new set that answers a comparison question neither one answers alone — and you can let a click on your dashboard update a set's membership live.

## Segment 2 (screenshot: combine dialog)

This is the real Create Set dialog in combine mode, building a new set called "Customers 2012 and 2013" from two existing yearly sets. You get four options: all members in either set, only the shared members present in both, or one set except whatever it shares with the other — in either direction. That last pair is exactly how you'd isolate customers who didn't return, or customers who are brand new.

## Segment 3 (screenshot: Add Set Action dialog)

This is a real Set Action, configured to run when someone selects a mark, assigning the values of whatever they clicked straight into a target set. This is the mechanism behind a dashboard where clicking one region updates every other chart on the page — it's all one set, and its membership just changed.

## Segment 4 (steps: what each combine option returns)

All members in both sets is a union — everyone in either one. Shared members in both sets is an intersection — only the overlap. And "except shared members" isolates whatever is unique to just one of the two sets.
