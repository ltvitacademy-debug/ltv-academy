# Script — Scatter Plots

## Segment 1 (title)

Every chart so far in this chapter puts a dimension on one shelf and a measure on the other. A scatter plot breaks that pattern: drag a measure to Columns and a second measure to Rows, and with no dimension anywhere in the view, Tableau plots exactly one mark — the grand totals of both measures against each other.

## Segment 2 (steps: from one mark to many)

Drag a dimension onto Detail on the Marks card, and that single mark splits into one per category — now you're comparing how Sales and Profit relate across each group, not just their overall totals.

## Segment 3 (screenshot: scatter plot with trend lines)

Here's a finished scatter plot — Sales against Profit, colored by Category, with a linear trend line per category from the Analytics pane. Hover over any trend line and Tableau shows the statistical model behind it — the equation, and an R-squared value for how well the line actually fits the points. It's a best-fit relationship, not a forecast and not proof of causation.
