# Lesson 2 — Installing Tableau Desktop & Tableau Public

**Chapter 1 · Getting Started · Lesson 2 of 95**

## What you'll learn

  course uses) and Tableau Public (free, saves only to the public web)

  Windows or Mac
- How to install Tableau Public separately, so you have a place to

- Why this course has you install both, not just one

## Tableau Desktop vs. Tableau Public

**Tableau Desktop** is the full authoring application — it can connect
to virtually any data source (Excel, CSV, SQL Server, and dozens more),
save workbooks privately to your own machine or to a licensed Tableau
Server/Cloud site, and is what you'll use for essentially every lesson
in this course. It normally requires a paid license, but Tableau offers
a free 14-day trial that's more than enough to get through this
course's early chapters while you decide on a long-term license.

**Tableau Public** is a separate, completely free application. It looks
almost identical to Desktop, but with one major restriction: every
workbook you save is published publicly to Tableau's public web
gallery — there's no private save option, and it can only connect to a
smaller set of data sources (no live database connections like SQL
Server). This course has you install it anyway, because Chapters 17-18
have you build portfolio dashboards, and Tableau Public is the free way
to host them online with a shareable link for job applications.

## Installing Tableau Desktop

1. Go to Tableau's [product page](https://www.tableau.com/products/desktop) and start the free trial download for your operating system.
2. Run the downloaded installer and step through the setup wizard — choose an install location, and optionally create desktop/Start menu shortcuts.
3. Launch Tableau Desktop and activate it with your trial (or licensed) key when prompted.

## Installing Tableau Public

Tableau Public is a separate download from a separate page —
installing Tableau Desktop does not also install Tableau Public, and
vice versa. Go to [public.tableau.com](https://public.tableau.com/en-us/s/download), download the installer for your OS, and run
it the same way.

![Real screenshot of the Tableau Public installer's license-agreement screen, showing the 'Public Edition' badge in the left column, the license-agreement checkbox, and Customize/Install buttons.](/courses/tableau/ch01/02-installing-tableau-desktop-and-public/public-install.png)
*Notice the "Public Edition" label — this is what confirms you're installing Public, not Desktop.*
Source: [Tableau Help — Download and Install Tableau Desktop](https://help.tableau.com/current/desktopdeploy/en-us/desktop_deploy_download_and_install.htm)

You can have both applications installed side by side without any
conflict — they use separate program folders and separate workbook
file types under the hood (Public workbooks are tied to your Tableau
Public online account).

## Key terms

| Term | Meaning |
|---|---|
| Tableau Desktop | The full, licensed authoring application — private saves, all connectors |
| Tableau Public | The free authoring application — public-only saves, limited connectors, used for portfolio hosting |
| Trial license | A free 14-day full-featured license for Tableau Desktop |
| Activation | The one-time step of entering a license key to unlock Desktop after install |

## Lab

1. Install Tableau Desktop using the free trial from Tableau's product page and confirm it opens to the start page.
2. Separately install Tableau Public from public.tableau.com and confirm it also opens — note the "Public Edition" label so you always know which one you're in.
3. Create a free Tableau Public account (you'll need it starting in Chapter 15) at the same site, so it's ready when you need to publish later in this course.
