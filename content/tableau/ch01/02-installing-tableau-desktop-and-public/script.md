# Script — Installing Tableau Desktop & Tableau Public

## Segment 1 (title)

This lesson, you're installing the two tools you'll use throughout this course: Tableau Desktop and Tableau Public.

## Segment 2 (screenshot: Desktop installer)

Tableau Desktop is the full authoring application — it connects to nearly any data source, saves workbooks privately, and is what you'll use for almost every lesson here. Download the free 14-day trial from Tableau's product page, run the installer, and step through the setup wizard like this one.

## Segment 3 (screenshot: Public installer)

Tableau Public is a separate, completely free download from public.tableau.com. It looks almost identical to Desktop, but every workbook you save publishes publicly to the web, and it supports fewer data connectors. Notice the "Public Edition" label here — that's how you tell the two installers apart.

## Segment 4 (steps: why install both)

You'll install both because Chapters 17 and 18 have you build portfolio dashboards, and Tableau Public is the free way to host that portfolio online with a shareable link for job applications. The two apps install side by side with no conflict.
