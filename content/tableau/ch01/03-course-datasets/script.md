# Script — Downloading and Understanding the Course Datasets

## Segment 1 (title)

This lesson is about the data you'll actually be working with — starting with Sample Superstore, which is already sitting on your machine.

## Segment 2 (screenshot: start page)

Sample Superstore ships bundled with Tableau Desktop itself. Open Tableau, and under Saved Data Sources on the start page, you'll see "Sample - Superstore" — click it, and you're connected immediately. It's fictional office-supply retailer data: orders, customers, products, regions, profit.

## Segment 3 (screenshot: data pane)

Once connected, the Data pane shows every field, split into Dimensions and Measures. Customer, Order, Location, and Product folders hold the Dimensions; Sales, Profit, Discount, and Quantity are the Measures. One row is a single line item on a single order — get familiar with these field names now, because almost every chapter through Chapter 13 uses this same structure.

## Segment 4 (steps: beyond Superstore)

Later chapters, especially the portfolio projects in Chapters 17 and 18, have you bring in other real datasets. Tableau's own "Find Good Data Sets" page lists reliable free sources — government open-data portals, Kaggle, the World Bank — bookmark it now for later.
