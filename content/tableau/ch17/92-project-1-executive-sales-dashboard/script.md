# Script — Project 1: Executive Sales Dashboard

## Segment 1 (title)

This is the first of three real portfolio projects, and it's built on the Sample Superstore dataset you've used since Lesson 3. The scenario: leadership wants one dashboard they can open Monday morning and understand in under thirty seconds.

## Segment 2 (steps: the four required pieces)

You need four things on one screen: a KPI header for Total Sales, Total Profit, and Profit Ratio; a sales-by-region map colored by Profit Ratio, not raw sales, so it shows where the business is actually healthy; a profit-trend line chart with a reference line for context; and a top-10-products bar chart built with a real Top N filter. Then you connect them with a filter action — click a region on the map, and the trend and top-10 chart both filter to it.

## Segment 3 (steps: what makes it strong)

The difference between passable and strong is entirely in the details: a filter action that reliably works every time you click it, not one that's flaky. Color that means something instead of Tableau's default palette. A layout that fits one screen with no scrolling. A title and a one-line caption so a first-time viewer knows how to read it. None of that requires a sixth chart — it requires finishing the four you have.

## Segment 4 (outro)

Project 2 goes further: a customer segmentation dashboard using RFM analysis, LOD expressions, and parameters — a step up in both technique and business framing.
