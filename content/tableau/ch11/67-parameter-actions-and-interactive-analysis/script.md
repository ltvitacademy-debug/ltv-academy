# Script — Parameter Actions & Interactive Analysis

## Segment 1 (title)

Every parameter so far has been driven by someone manually dragging a slider or picking from a dropdown. A Parameter Action removes that step: interacting directly with a mark in the view sets the parameter automatically.

## Segment 2 (screenshot: Add Action menu)

You build one from the same Actions menu you may already know — Change Parameter sits right alongside Filter, Highlight, Go to URL, and Go to Sheet.

## Segment 3 (screenshot: Edit Parameter Action dialog)

This is the real Edit Parameter Action dialog. You choose the source sheet the interaction comes from, whether it runs on Hover, Select, or Menu, which parameter gets targeted, and which field's value — from whatever mark was interacted with — gets written into it.

## Segment 4 (steps: the full chain)

Click a mark, and the Parameter Action sets the parameter. The calculated field from Lesson 64 re-evaluates against that new value. And anything built on that calculation — a reference line from Lesson 66, a color, the whole view — updates immediately. That's the entire chapter, working together in one click.

## Segment 5 (outro)

That's Chapter 11 finished. Chapter 12 moves to Level of Detail expressions — controlling exactly what level of granularity a calculation runs at, independent of whatever's on your view.
