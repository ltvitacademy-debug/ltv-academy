# Script — What-If Analysis with Parameters

## Segment 1 (title)

What-if analysis means testing how results would change under a different input, without touching your actual data — and a parameter is exactly the tool that supplies that adjustable input.

## Segment 2 (screenshot: parameter-driven reference line)

This is the real Edit Reference Line dialog. Normally a reference line sits at a fixed number or an aggregation — but that same Value dropdown lists a parameter as an option. Pick it, and the line's position moves live as someone adjusts the parameter's control, turning a static reference into a movable target.

## Segment 3 (code: worked scenario)

Here's a complete what-if scenario: a Target Profit Margin parameter, and a calculated field that measures the gap between actual margin and that target. Move the parameter's slider, and you can watch, in real time, which sub-categories flip from meeting the target to missing it — without editing a single filter or touching the underlying data.

## Segment 4 (steps: three real tools, not one menu)

There's no single "What-If" menu in Tableau. It's three tools you already know, combined: a parameter for the adjustable target, a calculated field comparing actual results against it, and a reference line making that target visible on the chart itself.

## Segment 5 (outro)

Next lesson goes one step further: instead of someone manually moving a slider, a Parameter Action lets a click or hover directly on the view update the parameter automatically.
