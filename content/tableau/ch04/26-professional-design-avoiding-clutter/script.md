# Script — Professional Visualization Design & Avoiding Clutter

## Segment 1 (title)

Everything in Chapter 4 so far has been about what you can add to a chart — color, labels, tooltips, reference lines, annotations. This lesson is about the opposite skill: knowing what to take away.

## Segment 2 (screenshot: before)

This is the same five-number bar chart most people would build without thinking twice — a gradient background, a gray plot area, a full color legend duplicating what the axis already says, heavy borders, and bold gridlines everywhere. None of it changes the data. All of it competes with the data for attention.

## Segment 3 (screenshot: after)

This is the exact same five numbers, after a well-known removal sequence from the data visualization studio Darkhorse Analytics. The background is gone. The legend is gone — the labels do that job now. The gridlines are gone. And only the one bar that actually matters, Bacon, is still in color; everything else recedes to gray.

## Segment 4 (steps: removal sequence)

The sequence is always subtraction, never addition. Remove backgrounds and gradients first. Remove redundant labels — anything the axis or legend already says. Reduce color to a single accent for what matters, gray for the rest. And remove bolding and gridlines last, until only the data itself is left on the page.
