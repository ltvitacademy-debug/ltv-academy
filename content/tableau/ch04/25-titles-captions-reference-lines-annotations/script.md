# Script — Titles, Captions, Reference Lines & Annotations

## Segment 1 (title)

Four more pieces round out a chart's context: titles, captions, reference lines, and annotations. Each adds a different layer of meaning directly onto the view.

## Segment 2 (screenshot: titles)

Every worksheet has a title, defaulting to the sheet's own name. Double-click it — or use Worksheet, Show Title — and the Edit Title dialog opens, with a <Sheet Name> placeholder you can rewrite, reformat, or replace entirely with something more descriptive.

## Segment 3 (screenshot: captions)

The caption sits below the view and, by default, Tableau writes it for you — describing which fields are on which shelves and which filters are currently active, all in a plain sentence. You can edit it just like the title, or leave Tableau's auto-generated version in place.

## Segment 4 (screenshot: reference lines)

A reference line adds a fixed or computed value directly onto the chart — here, an Average line cuts across every bar, so a reader can tell at a glance which segments beat the average and which fall short, without needing a separate calculation.

## Segment 5 (screenshot: annotations)

An annotation is a callout attached to one specific mark, a point, or an area — a small text box with a pointer line, explaining exactly what that one mark represents. Right-click any mark and choose Annotate to add one.
