# Script — Data Blending & Cross-Database Analysis

## Segment 1 (title)

Everything so far in this chapter produces one combined table. Data blending doesn't. This lesson is about the one technique that keeps your sources completely separate.

## Segment 2 (screenshot: blended scatter plot)

Here, Bookshop and Movie Adaptations are two entirely independent data sources. Tableau queries each one, aggregates the results, and lines them up by title — no combined table ever exists behind this chart. That's fundamentally different from a join or relationship.

## Segment 3 (screenshot: field mapping)

When the linking field names don't match between your two sources, you map them manually here — pick the primary field, then its counterpart in the secondary source, so Tableau knows how to line up the two aggregated results.
