# Script — URL, Parameter & Set Actions

## Segment 1 (title)

Six action types live in one Actions dialog. You already know Filter and Highlight. Today, three more: URL actions, parameter actions, and set actions.

## Segment 2 (screenshot: the full Actions dialog)

Here's the complete Add Action dropdown — Filter, Highlight, Go to URL, Go to Sheet, Change Parameter, Change Set Values. A URL action is the one type that reaches outside the workbook entirely, sending a click to a web address built from field values. A parameter action lets a click set a parameter's value, instead of a dropdown control — the chart itself becomes the input.

## Segment 3 (screenshot: a configured set action)

A set action changes set membership on a click. This dialog defines two behaviors: what happens when the action runs — assign values to the set — and what happens when the selection clears — add all values back. That two-part design is what makes set actions powerful for building selected-versus-everything-else comparisons.

## Segment 4 (steps: what each one builds on)

URL actions are new. Parameter actions build directly on Chapter 11's parameters. Set actions build directly on Chapter 10's sets. In every case, the action layer is just letting a click do what a manual control used to do.
