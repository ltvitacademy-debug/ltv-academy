# Script — Building Your First Professional Dashboard

## Segment 1 (title)

Welcome to Chapter 14 — Dashboards. Every chart you've built so far has lived on its own worksheet. A dashboard combines worksheets, filters, and objects onto one canvas, so a viewer sees several related answers at once. This is the actual deliverable most BI Developer and Data Analyst jobs ask for.

## Segment 2 (screenshot: dragging a worksheet in)

Here's the real Tableau Dashboard pane. On the left, the Sheets list shows every worksheet in your workbook. Drag one onto the canvas and Tableau adds it as a live zone — not a picture, a window onto the same worksheet. Edit that worksheet's formatting or calculations on its own tab, and the dashboard updates immediately.

## Segment 3 (steps: the 5-step build order)

Professionals follow a build order. First, finish every worksheet's formatting before it touches the dashboard. Second, set the dashboard's size — Range or Fixed, not Automatic — before dragging anything in. Third, place your largest, most important view first as an anchor. Fourth, add supporting views and filters. Fifth, add the KPI header and global filters last, once you can see the dashboard's actual shape.
