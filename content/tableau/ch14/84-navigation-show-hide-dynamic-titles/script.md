# Script — Navigation, Show/Hide Containers & Dynamic Titles

## Segment 1 (title)

Three ways to make a dashboard feel intentional rather than static: navigation between dashboards, toggling floating objects, and titles that react to what's selected.

## Segment 2 (screenshot: Navigation object)

The Navigation object lives right in the Objects panel alongside every container type. Drag it in, set its destination dashboard, and viewers can move between pages without hunting for tabs. The Go to Sheet action does the same job from a click on a mark instead of a dedicated button — configured through the same Actions dialog as filter, highlight, URL, parameter, and set actions.

## Segment 3 (screenshot: Show/Hide button)

Recall floating objects from Lesson 80. A Show/Hide button adds a small X toggle to a floating object — click it, and the panel tucks away, leaving a small icon to bring it back. This is exactly what makes floating layout genuinely useful: a filter panel that stays out of the way until someone wants it.

## Segment 4 (screenshot: dynamic title)

A title doesn't have to be static. The Edit Title dialog's Insert menu drops in placeholders like Sheet Name, or a field or parameter value. Pair this with a parameter action, and a dashboard's own title confirms exactly what a viewer just clicked.
