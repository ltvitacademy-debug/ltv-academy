# Script — Advanced Chart Challenge

Four things, one dashboard: a dual-axis combination chart with Sales as a line and Profit as bars, a KPI view built from a real threshold calculation on Shape, a Pareto chart with a genuine running-total and percent-of-total line, and a dynamic reference line driven by a parameter and moved by a parameter action.

## Segment 3 (code: the formulas you already have)

Every formula you need already exists in your last four lessons — the KPI threshold, the two table calculations behind the Pareto line, and a parameter referenced as a reference line's value. Nothing here is new syntax.

## Segment 4 (steps: self-check, not a grade)

There's no single correct screenshot for this one — too many equally valid layouts exist. Instead, check your own work against five requirements: real mark-type variety, a real threshold-driven KPI, real table calculations, a real parameter action, and all four living on one dashboard together.
