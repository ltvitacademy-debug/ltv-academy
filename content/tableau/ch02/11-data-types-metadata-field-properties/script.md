# Script — Data Types, Metadata & Field Properties

## Segment 1 (title)

This lesson zooms into the Data pane itself — data types, metadata, and the field properties you can set once to save yourself repeated work.

## Segment 2 (screenshot: data pane icons)

Every field carries a small icon showing its data type: Abc for text, a hash for number, a calendar for date, a globe for a geographic role. This is metadata Tableau infers from the source — and when it guesses wrong, like a ZIP code read as a plain number, right-click the field and choose Change Data Type to fix it.

## Segment 3 (screenshot: default properties menu)

Beyond data type, every field has default properties you set once: a default aggregation, so a percentage field defaults to Average instead of Sum; a default number format, so Sales always shows as currency; even a default color, so every chart colors the same category the same way automatically.

## Segment 4 (steps: why set these early)

Set these once at the field level, in the Data pane, not per worksheet. Every future worksheet that uses that field inherits the setting automatically — save the reformatting time now, once, instead of every single time.
