# Script — Connecting to Excel & CSV Files

## Segment 1 (title)

Chapter 2 starts here: connecting Tableau to real external data, beginning with the two most common file types — Excel and CSV.

## Segment 2 (screenshot: Excel connection)

Connect to an Excel workbook, and you land on the Data Source page, not a worksheet. The Sheets list on the left shows every sheet in the workbook — each can become its own table. Notice the Live/Extract toggle top-right; every connection asks you this immediately.

## Segment 3 (screenshot: CSV connection)

A CSV file works almost the same way, but with one real difference: a plain text file has no built-in column names or data types. If Tableau guesses wrong, you'll see generic F1, F2, F3 headers like this — fixable from the table dropdown, or from Text File Properties, where you can set the delimiter and text qualifier manually.

## Segment 4 (steps: what's different)

Excel workbooks carry sheet names and named ranges. CSV files carry none of that — just raw delimited text. Both end up on the same Data Source page, with the same Live/Extract choice, which Lesson 9 covers in full.
