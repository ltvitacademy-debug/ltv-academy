# Script — Tableau Desktop vs. Public vs. Cloud vs. Server

## Segment 1 (title)

Every workbook you've built so far has lived entirely inside Tableau Desktop. But Desktop isn't how anyone else sees your work — for that, you publish to one of three destinations: Tableau Public, Tableau Cloud, or Tableau Server. This lesson is about what actually separates those three.

## Segment 2 (steps: the four products)

Tableau Desktop is the local authoring application — where you build. Tableau Public is free, but everything you publish there is visible to anyone on the internet, which makes it the right home for a public portfolio and the wrong home for company data. Tableau Cloud is a paid product where Tableau itself hosts and manages the server for you. Tableau Server is the same product as Cloud, feature for feature, except your own company hosts and manages it.

## Segment 3 (steps: choosing between them)

So the real question is never "which one is better" — it's who's going to host this, and who's allowed to see it. A student portfolio piece belongs on Tableau Public. A company that wants zero server management picks Tableau Cloud. A company with strict data-residency or compliance rules picks Tableau Server, because their own infrastructure controls exactly where the data lives.
