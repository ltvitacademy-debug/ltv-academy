# Lesson 47 — Building a Date Table · Voiceover script

Segments map 1:1 to slides. Each segment is one TTS call so slide timing follows
the audio. Target: ~2 minutes total.

---

## S1 · TITLE CARD (SVG: lesson title, LTV brand)

Every time intelligence function this chapter covers depends on one
thing: a table with a row for every single day, no gaps. Here's how to
build and mark one.

## S2 · IMAGE: date-tables_02.png (Mark as date table context menu)

Right-click your date table in the Fields pane — Mark as date table,
Mark as date table again. Power BI's automatic date/time detection is
convenient, but marking your own table gives you control over fiscal
years and custom hierarchies.

## S3 · IMAGE: date-tables_03.png (Mark as date table dialog, validated)

Pick the column that holds the actual date values. "Validated
successfully" means it passed every check.

## S4 · STEPS: Unique values -> No nulls -> Contiguous dates -> Consistent timestamp

Four rules, checked every time: unique values, no nulls, contiguous
dates with no gaps, and — if it's a Date/Time column — the same
timestamp on every row. Fail any one, and Power BI tells you why.
