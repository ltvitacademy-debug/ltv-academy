# Lesson 90 — Add Interactivity · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

One slicer per page, chosen for what that page is actually for — not
five slicers nobody will touch.

## S2 · STEPS: Regional -> CalendarYear | Profitability -> Category | Fulfillment -> Region

Each page's slicer matches its purpose directly: year for regional
comparison, category for profitability, region for fulfillment.

## S3 · CODE: Right-click territory -> drillthrough -> Territory Detail page

A hidden fourth page holds the detail. Right-clicking any territory
on Page 1 jumps straight there, pre-filtered — summary stays clean,
detail is one click away.

## S4 · CODE: Cross-filtering ON by default -> Edit interactions to exclude deliberately

Check every page: selecting a bar should filter the rest of the page.
If something doesn't respond, that's Edit interactions — confirm it's
intentional, not an accident.

## S5 · OUTRO CARD

Interactivity added where it earns its place, nowhere else. Lesson 91
finally publishes this to the Power BI service.
