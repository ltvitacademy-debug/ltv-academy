# Lesson 91 — Publish to Power BI Service · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

A dedicated workspace, a real publish, a dashboard, and an app — four
steps, all familiar from Chapter Nine.

## S2 · CODE: New workspace -> Publish -> confirm all four pages render

Create a workspace just for this project, publish from Desktop, then
open it in the service and confirm every page — including the hidden
drillthrough page — renders correctly.

## S3 · STEPS: Pin Total Sales -> Pin Gross Margin % -> Pin fulfillment gauge

A dashboard pinning one tile from each report page gives the VP a
genuine at-a-glance view, each tile still linking back to its full
report.

## S4 · CODE: Setup -> Content -> Audience -> Publish app

Package it as an app: name it, add the report and dashboard, create
one audience, and publish.

## S5 · OUTRO CARD

Published doesn't mean shared, and it doesn't mean current. Lesson 92
covers both of those, deliberately.
