# Lesson 77 — Scheduled Refresh · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

One menu holds every setting this lesson covers — Refresh, then
Schedule refresh, on any semantic model.

## S2 · IMAGE: semantic-model-schedule-refresh.png

Open the workspace, select the semantic model, and that one menu
option is where frequency, credentials, and gateway all live.

## S3 · IMAGE: scheduled-refresh.png

Turn the schedule on, pick daily or weekly, and add time slots. Each
one counts toward the daily quota from Lesson 75.

## S4 · IMAGE: gateway-connection.png

This section shows which gateway is online and available. If Lesson
76's install isn't online yet, fix that before anything else here
matters.

## S5 · IMAGE: data-source-credentials-pgw.png

With a personal gateway, you supply credentials once, and they're
retained after that.

## S6 · IMAGE: data-source-credentials-egw.png

With a standard gateway, this section is grayed out instead — an
admin already configured it centrally.

## S7 · OUTRO CARD

One quiet trap: two months with no one viewing the report pauses the
schedule automatically. Lesson 78 covers this and every other way
refresh can fail.
