# Lesson 2 — Installing Power BI Desktop · Voiceover script

Segments map 1:1 to slides. Each segment is one TTS call so slide timing follows
the audio. Target: ~3 minutes total.

---

## S1 · TITLE CARD (SVG: lesson title, LTV brand)

In the last lesson we talked about what Power BI is. Now let's actually get it
onto your machine. This lesson is short on purpose: install it here, and every
lesson after this one, you'll have it open right alongside the video.

## S2 · IMAGE: getpbid_downloads.png (Power BI service download menu)

There are two ways to get Power BI Desktop, and both install the exact same
free tool. The first: if you're already signed into the Power BI service in a
browser, click the Download icon in the top right corner and choose Power BI
Desktop from the menu. That's the fastest path if you already have an account.

## S3 · IMAGE: getpbid_04.png (Microsoft Store install button)

That takes you to the Microsoft Store page for Power BI Desktop — or you can go
there directly by searching "Power BI Desktop" in the Store. Select Install,
and you're done. This is the method I recommend for almost everyone: Windows
updates it automatically every month, it doesn't require administrator rights,
and it matches Power BI Desktop's language to your Windows language on its own.

## S4 · IMAGE: download-desktop-exe.png (Download Center, 64-bit exe selected)

The second way is a direct download from the Microsoft Download Center — an
installer file you run yourself. Organizations use this method to roll Power BI
Desktop out to hundreds of machines at once with scripted, silent installs.
If you use this method, always choose the 64-bit version — the 32-bit build is
no longer supported.

## S5 · IMAGE: desktop-install-01.png (setup wizard welcome screen)

Whichever way you chose, here's the setup wizard for the direct download:
choose your language, accept the license agreement, and click through with the
defaults. The Store version skips this entirely — Windows just installs it in
the background. Either way, in a couple of minutes, Power BI Desktop is on your
computer.

## S6 · IMAGE: desktop-splash-screen.png (post-launch start screen)

Launch it, and this is what greets you: a start screen offering a blank report,
or a direct connection to Excel, SQL Server, sample data, and more. Don't touch
any of these yet — in the next lesson we take this exact screen apart, piece by
piece, so you know what every button does before you click it.

## S7 · OUTRO CARD (SVG: next lesson, LTV seal)

That's the install, start to finish: pick Microsoft Store unless your workplace
says otherwise, install it, launch it. In the next lesson, we tour the Power BI
Desktop interface together — the ribbon, the canvas, and the panes you'll live
in for the rest of this course. See you there.
