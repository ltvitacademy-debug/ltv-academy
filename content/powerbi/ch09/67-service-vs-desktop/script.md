# Lesson 67 — Power BI Service vs. Desktop · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

Every lesson so far has happened inside Power BI Desktop. Starting now,
the other half of Power BI — the service — takes over.

## S2 · IMAGE: pbid_publish_publishbutton.png (Desktop Publish button)

Desktop is where you connect to data, clean it, model it, and write
DAX. It's local authoring software. Publishing sends your work
somewhere else entirely.

## S3 · IMAGE: power-bi-new-workspaces.png (service workspace)

That somewhere else is the Power BI service — a website, not a
program you install. It's where finished work gets stored, refreshed
on a schedule, and shared with people who never open Desktop at all.

## S4 · CODE: Workspace -> Semantic model -> Report -> Dashboard -> App

Five concepts run through this entire chapter: the workspace that
holds everything, the semantic model your reports are built from, the
report itself, dashboards that pin tiles from reports, and apps that
package it all for a broad audience.

## S5 · OUTRO CARD

You can't create a workspace inside Desktop — that only happens in the
service. Lesson 68 starts with what license you actually need to do
any of this.
