# Lesson 69 — Workspaces · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

A workspace is where every dashboard, report, and semantic model in
this chapter actually lives.

## S2 · IMAGE: power-bi-new-workspaces.png

Here's a workspace's content list — a dashboard, a report, a workbook,
a dataset, all grouped together. Everything you've published so far
sits inside a workspace exactly like this.

## S3 · IMAGE: power-bi-workspace-new-settings.png

Creating one takes a name and a few optional settings — a contact
list, a workspace image, a linked OneDrive. All of it lives under
Workspace settings, reachable any time.

## S4 · CODE: Admin -> Member -> Contributor -> Viewer

Four roles control what colleagues can do inside your workspace:
Admin has full control, Member can publish and add members,
Contributor can publish but not manage access, and Viewer can only
look.

## S5 · IMAGE: pinned-list.png

Pin the workspaces you use most to the top of the list — small detail,
but it saves real time once you're working across several of them.

## S6 · OUTRO CARD

One warning before you move on: deleting a workspace is permanent,
no recovery. Lesson 70 covers what actually happens when you publish
into one.
