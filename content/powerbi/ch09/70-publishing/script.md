# Lesson 70 — Publishing Reports · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

One button in Desktop triggers publishing — but it's worth
understanding everything that button actually does.

## S2 · IMAGE: pbid_publish_publishbutton.png

File, Publish, Publish to Power BI. Sign in if asked, and that's the
whole first step.

## S3 · IMAGE: pbid_publish_select_destination.png

Search for and select the workspace you're publishing into — any
workspace you already have Contributor access or higher to shows up
here.

## S4 · IMAGE: pbid_publish_success.png

When it finishes, you get a direct link to the new report. Publishing
creates a semantic model and report with the same name as your file.

## S5 · CODE: Republish -> Same-name conflicts -> Broken visuals -> Immediate refresh

Republishing is where the real risks live: duplicate names can break
it, renamed fields can break existing visuals, and it kicks off an
immediate refresh on top of any schedule you already had.
