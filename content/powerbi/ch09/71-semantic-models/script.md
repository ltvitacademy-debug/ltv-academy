# Lesson 71 — Semantic Models · Voiceover script

Segments map 1:1 to slides. Target: ~3 minutes total.

---

## S1 · TITLE CARD

Every measure and relationship you've built lives inside what the
service now calls a semantic model — the modern name for what used to
be called a dataset.

## S2 · CODE: Import -> DirectQuery -> Composite

Three ways a semantic model gets its data. Import copies data in for
speed, but needs refreshing. DirectQuery queries the source live for
currency, at the cost of speed. Composite mixes both in one model.

## S3 · IMAGE: live-connection-dataset.png

Sometimes a model already lives outside Power BI entirely, in
Analysis Services. A live connection passes every query straight
through instead of copying anything in.

## S4 · OUTRO CARD

Not every user who opens a semantic model can edit it — ownership and
row-level security both control that. Lesson 72 covers sharing access
properly.
