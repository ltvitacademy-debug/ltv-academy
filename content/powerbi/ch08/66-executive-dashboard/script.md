## S2 · CODE: Audience -> Metrics that pass the test -> Placement by reading order -> Honest visuals, one screen

Answer the audience questions first. Keep only metrics that would
actually change a decision, each with a real target. Sketch placement
by reading order before building anything. Choose every visual against
the distortion checklist, consistent scale and color throughout. Fit
it to one screen, no scrollbars.
