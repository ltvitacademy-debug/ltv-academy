# Lesson 58 — Cross Filtering & Visual Interactions · Voiceover script

Segments map 1:1 to slides. Each segment is one TTS call so slide timing follows
the audio. Target: ~2 minutes total.

---

## S1 · TITLE CARD (SVG: lesson title, LTV brand)

By default, every visual on a page already talks to every other one.
Here's how to see that, and how to change it.

## S2 · IMAGE: power-bi-interaction.png (Format ribbon, Edit interactions)

Select a visual, then Format, Edit interactions. That's the switch that
turns on a live control panel for how that visual affects everything
else on the page.

## S3 · IMAGE: power-bi-turn-on.png (interaction icons on every visual)

Every other visual now shows Filter, Highlight, and None icons. Filter
narrows what the other visual shows. Highlight dims the rest while
keeping it visible. None means no effect at all. One exception: line
charts, scatter charts, and maps can only be filtered, never
highlighted.

## S4 · OUTRO CARD (SVG: next lesson, LTV seal)

And drilling stays contained to its own visual by default — set Apply
drill down filters to Entire page, and drilling updates everything
else too. Next: drill down and drill through — moving from a summary
straight to the detail behind it.
