# Lesson 59 — Drill Down & Drill Through · Voiceover script

Segments map 1:1 to slides. Each segment is one TTS call so slide timing follows
the audio. Target: ~2 minutes total.

---

## S1 · TITLE CARD (SVG: lesson title, LTV brand)

Two features with similar names, and genuinely different jobs. Let's
tell them apart.

## S2 · IMAGE: column-drill.png (four drill icons)

Drill mode stays inside one visual — up a level, down a level, or
expand everything at once, the same four icons from Chapter 7's third
lesson.

## S3 · STEPS: New page -> Drillthrough filter -> Back button -> Focused visuals

Drillthrough is bigger: it takes you to an entirely separate report
page. Add a page, drag a field into the Drillthrough filters well, and
Power BI adds a Back button automatically. Build visuals around that
one filtered item — a card, a table, a trend line.

## S4 · STEPS: Right-click a data point -> Drillthrough -> Select page -> Filtered automatically

Right-click any data point that shares the drillthrough field, hover
Drillthrough, pick the page — Power BI navigates there, already
filtered to what you clicked. A button with its action set to
Drillthrough works the same way, just more visible than a right-click.
