## S2 · IMAGE: analytics-pane_4.png (average line on a line chart)

The most common addition: a reference line. Select a line type, Add,
name it, pick the measure — here, an average line labeled Average
sales. Min, max, median, and percentile lines all work the same way.

## S3 · IMAGE: analytics-pane_8.png (forecast with confidence interval)

With real time-series data, Forecast projects future values from
historical trend. The shaded band is the confidence interval — how
certain the prediction is, widening the further out it goes.
Forecasting and anomaly detection both need a line chart with genuine
dates to work from.

## S4 · STEPS: Decomposition tree -> Key influencers -> Smart narrative

And beyond the Analytics pane, a few AI-powered visuals worth
recognizing: decomposition tree for drilling across dimensions in any
order, key influencers for surfacing what actually affects a result,
smart narrative for automatically writing up the takeaway in plain
language.
