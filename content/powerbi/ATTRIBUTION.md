# Image attribution — Power BI course

Screenshot and diagram images in this course are Microsoft product screenshots and
documentation images sourced from Microsoft Learn (https://learn.microsoft.com),
© Microsoft Corporation. They are used in this training material in accordance with
Microsoft's "Use of Microsoft Copyrighted Content" guidelines
(https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions),
which permit the use of unaltered product screenshots in instructional materials.
Historic Microsoft documentation was published under CC BY 4.0.

Images are unaltered except for resizing/compositing; overlay callouts and captions
are additions around the screenshots, authored by Lifting the Veil Academy.

Each lesson's `sources.json` records the exact source URL for every image used.

## Sample data downloads

Where a lesson has students practice on a Microsoft-provided sample dataset
(e.g. the Financial Sample workbook), the file is hosted directly on this site
under `public/downloads/power-bi/` rather than linking out to Microsoft — so a
student never has to leave the course to get a required file, and the link
never rots if Microsoft moves it. Files are redistributed unmodified, exactly
as Microsoft publishes them for free use in its own tutorials. Each lesson's
`sources.json` records the original Microsoft URL the file came from under a
`downloads` key.

All written guides, scripts, quizzes, and labs are original works of
Lifting the Veil Academy © 2026. Facts are drawn from current Microsoft
documentation and verified at production time.
