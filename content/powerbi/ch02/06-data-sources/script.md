## S1 · TITLE CARD (SVG: lesson title, LTV brand)

Chapter one built the fundamentals. Chapter two is about getting your own
data into Power BI — every way there is to do it. We start with the map:
what kinds of sources exist, and how they're organized.

## S2 · IMAGE: data-sources-02.png (Get Data dialog, all categories)

Power BI Desktop can connect to hundreds of data sources, and that number
grows every month. The good news: they all sort into just seven categories.
File. Database. Microsoft Fabric. Power Platform. Azure. Online Services.
And Other, for everything that doesn't fit neatly anywhere else. You don't
need to memorize the hundreds of specific connectors — just these seven
buckets.

## S3 · IMAGE: data-sources-01.png (Get data button, Common data sources list)

There are two ways to get to them. The Home ribbon's Get data button opens a
short list called Common data sources — Excel, SQL Server, Text, Web, the
ones you'll actually use most weeks. If what you need isn't on that list,
selecting More opens the full dialog with all seven categories.

## S4 · IMAGE: data-sources-08.png (Other category, Web highlighted)

Here's the Other category, with Web selected. Every one of these dozens of
connectors works the same basic way: pick it, and select Connect.

## S5 · IMAGE: datasources-fromwebbox.png (From Web dialog, URL entered)

Then Power BI asks for whatever that specific source needs to find your
data. A URL, for Web. A server name, for a database. A file path, for a
folder. The question changes. The idea behind it — tell me where this lives
— never does.

## S6 · IMAGE: datasources-fromnavigatordialog.png (Navigator dialog)

And no matter which connector you started from, you land in the same place:
Navigator. Pick what you want, and select Load — or Transform Data, if you
want to clean it up first in Power Query Editor, which is all of Chapter
Three.

## S7 · OUTRO CARD (SVG: next lesson, LTV seal)

Category, connector, connection details, Navigator, Load. That's the whole
pattern, and it's the same pattern for every source you'll ever connect to.
Next lesson, we do it for real with Excel — the most common starting point
of all. See you there.
