# Script — Azure DBA Interview Preparation

## Segment 1 (title)

A DBA interview rarely asks "define an index." It asks something closer to real work — a situation, then "walk me through how you'd handle it." The strongest answers clarify the constraint, name the relevant tool, explain the trade-off, then state what they'd verify afterward.

## Segment 2 (steps: sampled scenarios)

The database is suddenly slow — start with methodology, not a guess. A query was fast yesterday and slow today — that's Query Store's exact job. A developer can't connect — firewall, VNet, DNS, TLS, in that order. Twelve real scenarios like these, spanning everything this course covered.

## Segment 3 (code: explaining it plainly)

RPO is how much recent work you could lose. RTO is how long you'd be down. Being able to drop the jargon on request, in two plain sentences, is itself a real interview signal.
