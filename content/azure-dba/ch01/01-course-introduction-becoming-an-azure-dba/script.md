# Script — Course Introduction: Becoming an Azure Database Administrator

## Segment 1 (title)

T-SQL Development already covered writing SQL — queries, joins, procedures, schema design. This course doesn't re-teach any of that. Every one of those skills gets redirected toward a different job: keeping the database itself running, secure, fast, and recoverable.

## Segment 2 (code: developer vs administrator)

A developer's SQL knowledge answers "how do I get the data I need?" A DBA's job starts after that query already works — does it run fast enough, is the right person allowed to see it, what happens if the server goes down at 2 a.m.

## Segment 3 (steps: the DP-300 weighting)

This course follows Microsoft's DP-300 blueprint, and its section lengths deliberately mirror the real exam weighting — platform resources, security, monitoring and performance, automation, and high availability and disaster recovery, each getting the space the actual exam gives it.

## Segment 4 (outro)

Sixteen chapters, one arc: get an environment running, lock it down, know when something's wrong, automate the routine work, migrate a real database in, back it up, and make it survive an outage. Next up: on-prem SQL Server versus Azure SQL — the ecosystem this course actually lives in.
