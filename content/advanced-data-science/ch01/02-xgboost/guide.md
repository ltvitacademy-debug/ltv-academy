# XGBoost

In the last lesson you built gradient boosting from scratch. That version works, but it leaves out the things you need on real projects: regularization to fight overfitting, sensible handling of missing values, speed on large tables, and a way to stop training automatically. **XGBoost** (eXtreme Gradient Boosting) is an open-source library that adds all of these. It has been a staple of tabular-data competitions and production models for years, and its scikit-learn-style interface makes it easy to adopt.

## What you'll learn

- What XGBoost adds on top of plain gradient boosting
- How to train `XGBClassifier` with a proper train/validation/test split
- How early stopping picks the number of trees for you
- How to read feature importances, and their limits

## What XGBoost adds

- **Regularization.** The objective includes a penalty on tree complexity: `reg_lambda` (L2 on leaf weights), `reg_alpha` (L1), and `gamma` (the minimum loss reduction required to make a split). Boosting on messy data overfits easily, and these knobs help.
- **Second-order information.** Trees are fitted using both the gradient and the second derivative of the loss, which gives better split scoring than residuals alone.
- **Native missing values.** At every split, XGBoost learns which direction rows with a missing value should go. You can pass `NaN` in without imputing.
- **Speed.** Recent versions grow trees on histograms of binned feature values, and can use multiple CPU cores (and GPUs).
- **Row and column subsampling.** `subsample` and `colsample_bytree` borrow the randomness trick from random forests.

## The data

We use a synthetic churn table, generated by the code below. It is illustrative, not real customer data: 6,000 customers, about 30% churn, and about 5% of `support_calls` deliberately blanked out to represent missing values. The next few lessons reuse this same generator.

```python
import numpy as np
import pandas as pd

def make_churn(n=6000, seed=42):
    rng = np.random.RandomState(seed)
    df = pd.DataFrame({
        "tenure_months": rng.exponential(24, n).round().clip(1, 72),
        "monthly_spend": rng.gamma(4, 20, n).round(2),
        "support_calls": rng.poisson(1.5, n).astype(float),
        "days_since_order": rng.exponential(40, n).round(),
        "plan": rng.choice(["basic", "plus", "premium"], n,
                           p=[0.5, 0.35, 0.15]),
    })
    logit = (-2.4 + 0.03 * df.days_since_order
             + 0.35 * df.support_calls
             - 0.03 * df.tenure_months
             - 0.9 * (df.plan == "premium")
             + 0.8 * ((df.monthly_spend > 120) & (df.support_calls >= 3))
             + 0.02 * df.monthly_spend * (df.tenure_months < 6))
    df["churned"] = (rng.uniform(size=n) < 1 / (1 + np.exp(-logit))).astype(int)
    df.loc[rng.uniform(size=n) < 0.05, "support_calls"] = np.nan
    return df
```

## Three splits

Early stopping needs a validation set to watch. To keep the test set honest, we split three ways: train, validation, and test.

```python
from sklearn.model_selection import train_test_split

df = make_churn()
df["plan"] = df["plan"].map({"basic": 0, "plus": 1, "premium": 2})
X = df.drop(columns="churned"); y = df["churned"]
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)
X_fit, X_val, y_fit, y_val = train_test_split(
    X_tr, y_tr, test_size=0.2, random_state=0, stratify=y_tr)
```

This gives 3,600 rows to fit, 900 to validate, and 1,500 to test.

## Train with early stopping

```python
import xgboost as xgb

model = xgb.XGBClassifier(
    n_estimators=500, learning_rate=0.05, max_depth=3,
    subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0,
    eval_metric="auc", early_stopping_rounds=30,
    random_state=0)
model.fit(X_fit, y_fit, eval_set=[(X_val, y_val)], verbose=False)
```

We ask for up to 500 trees but tell XGBoost to stop once validation AUC has not improved for 30 rounds. On this data it ran 147 rounds and kept round 116 as the best (validation AUC 0.851). When you call `predict_proba`, the model uses the best round automatically in current versions.

## Results

```
logistic regression, test AUC   0.805
XGBoost with early stopping     0.828
XGBoost, 500 trees, no stopping 0.819
```

XGBoost beats the linear baseline because the synthetic churn signal includes interactions and thresholds that a linear model cannot express. Stopping at the right round also helped compared with training all 500 trees. The curve in the video shows validation AUC rising quickly, then flattening near the marked best round.

## Feature importance, with care

`model.feature_importances_` returned roughly: `days_since_order` 0.36, `tenure_months` 0.32, `support_calls` 0.12, `plan` 0.12, `monthly_spend` 0.09. These numbers describe how much the trees used each feature, not causal effect, and they can mislead when features are correlated. Treat them as a starting point for investigation.

## Recap

XGBoost is gradient boosting with regularization, missing-value handling, and speed. Use a validation set with `early_stopping_rounds` so the data chooses the number of trees, and keep the test set untouched for the final score.
