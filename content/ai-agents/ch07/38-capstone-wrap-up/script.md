# Script — Capstone: Wrap-Up & Portfolio Presentation

## Segment 1 (title)

Most agent demos show the happy path — user asks, agent succeeds. That's table stakes. What makes this capstone worth presenting is everything on top of it: the rejection path, a stopping condition actually firing, a real audit log entry.

## Segment 2 (code: six chapters, one agent)

One sentence ties it together: a tool-using agent with a human-approval checkpoint on its one consequential action, backed by append-only logging, iteration and cost limits, and least-privilege credentials — verified working, not just demoed. Every clause in that sentence is a lesson you can speak to.

## Segment 3 (steps: show the failure paths)

When you present it, don't just show success. Show a human declining the refund and the agent handling it gracefully. Show a stopping condition firing. Show the audit log from a real run. That's what a working interviewer who builds agents has rarely seen a candidate actually demonstrate.
