## S1 · TITLE CARD

Welcome to Data Security, Privacy and Classification. Before anything else,
this course needs two words defined precisely, because people use them
interchangeably and they're not the same thing: security, and privacy.

## S2 · STEPS CARD (the CIA triad)

Data security protects data from unauthorized access, alteration, or
destruction. It's usually broken into three properties, the CIA triad.
Confidentiality: only authorized people can see it. Integrity: the data
is accurate and untampered with. Availability: it's there when legitimate
users need it. Notice what this never asks — whether the data should
have been collected at all.

## S3 · STEPS CARD (privacy is appropriate use)

Data privacy asks that exact question. It's about the rights and
obligations around how personal data is collected, used, and shared.
Did the person know? Did they agree? Is it being used for what they
were told? Security protects data. Privacy governs whether using it
this way is appropriate in the first place.

## S4 · STEPS CARD (related but distinct)

These are related but genuinely distinct. A system can be perfectly
secure — encrypted, access-controlled, audited — and still violate
privacy if it collects personal data without consent. And a careful
privacy policy is worthless without security behind it: a policy is
just paper if anyone can read the underlying database. You need both.
