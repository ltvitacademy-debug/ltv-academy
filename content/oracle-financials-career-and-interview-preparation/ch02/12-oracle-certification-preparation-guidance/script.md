# Lesson 12 — Oracle Certification Preparation Guidance · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

This is guidance, not a guarantee. LTV Academy does not issue Oracle certifications, and completing this path doesn't earn you one automatically - that requires Oracle's own proctored exam.

## S2 · STEPS — The general tiers

Oracle organizes Cloud Applications certifications into tiers - a foundational tier for broad conceptual knowledge, and an implementation tier confirming you can actually configure a specific module. Oracle has renamed these tiers before, and a rename doesn't invalidate what was already earned under the old name.

## S3 · STEPS — Why this drifts

Exam codes are versioned to the year and refresh annually, because the cloud application itself keeps changing, unlike older fixed-version software. Any specific exam name or code you read anywhere, including in this lesson, may already be stale by the time you act on it.

## S4 · STEPS — Where to actually check

Go to Oracle University's own certification pages, and Oracle CertView once credentialed, for the current exams and prerequisites. Treat any third-party blog or study-guide site as a starting point to verify against Oracle's own page, not the final word.

## S5 · OUTRO

A realistic first target is an implementation credential in the module you're strongest in. Next lesson: turning that target into an actual study plan and practice habits.
