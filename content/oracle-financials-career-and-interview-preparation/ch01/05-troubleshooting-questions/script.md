# Lesson 5 — Troubleshooting Questions · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

If you've worked through the troubleshooting course and the capstone's crisis, you already have real experience. This lesson is about presenting it as a discipline, not a lucky guess.

## S2 · STEPS — The discipline, named

Every fix in this path follows four steps. Isolate the problem to something specific and provable. Confirm it with real evidence - logs, reports, diagnostics, not a hunch. Fix it narrowly rather than overcorrecting. Document what happened and why.

## S3 · STEPS — Common troubleshooting questions

A vague "the numbers are wrong" complaint needs specifics first - the exact expected figure, the exact seen figure, and the timing of each report. An FBDI load failure needs the row-level error log checked before deciding how to reload. A batch stuck Incomplete needs the Create Accounting error detail checked for a missing account rule.

## S4 · STEPS — Knowing the boundary

When you've isolated a problem to something outside Financials' own configuration - security, an interface, infrastructure - that's the point to loop in the right team. Knowing that boundary is a sign of experience, not a weakness.

## S5 · OUTRO

Asked for a real example, use one of the capstone's six January 31 problems and walk it through isolate, confirm, fix, document. Next lesson: Oracle implementation interview questions.
