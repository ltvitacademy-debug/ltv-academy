# Script — The Import Wizard

## Segment 1 (title)

The third tool is the Import Wizard, and it's already inside your org. It's the simplest of the three, and its limits are just as real.

## Segment 2 (code: built into setup)

You'll find it in Setup, under Data Management, as the Data Import Wizard. Click Launch Wizard. There's no install and no separate login, and it walks you through each step.

## Segment 3 (steps: the wizard's flow)

The flow is short. Choose the data: which object, whether to add new records, update existing ones, or both, and which field to match on. Upload your CSV. Map the fields. Start the import, then track it in the job list.

## Segment 4 (code: the real limits)

Now the limits, because they decide when you use it. It handles up to fifty thousand records at a time. It supports Accounts, Contacts, Leads, Solutions, Campaign Members and custom objects, but not Opportunities or Cases. And it's import only. No export, no delete.

## Segment 5 (outro)

Simple, guided, and limited. Next up: choosing the right tool for the job, the decision framework across all three.
