# Lesson 17 — RACI for Data Governance · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE CARD

Every lesson so far in this chapter has described roles and responsibilities in prose. This
lesson gives you the tool that makes all of it precise, on paper: the RACI matrix.

## S2 · STEPS CARD (the four letters)

RACI is four letters crossed against a list of tasks. R is Responsible — does the actual
work. A is Accountable — owns the outcome, with final sign-off, and there should be exactly
one A per task. C is Consulted — gives input before a decision. And I is Informed — kept
aware after the fact, one-way.

## S3 · STEPS CARD (mapping roles to letters)

Map that onto the roles you already know. The owner is typically Accountable. The steward is
Responsible for daily work. The custodian is Responsible specifically for technical
implementation tasks. And the consumer is usually just Informed — aware of the outcome
without driving the decision.

## S4 · STEPS CARD (the one rule that matters)

Here's the one rule that keeps a RACI matrix useful instead of decorative: exactly one A per
row. Two people both marked Accountable for the same task isn't clarity — it's the ambiguity
you were trying to fix, written back down on paper. And notice the A can legitimately shift
by task: the owner holds it for approving a rule, but the custodian holds it for implementing
that rule correctly.

chapter's structure actually stick inside a real organization: executive sponsorship. See
