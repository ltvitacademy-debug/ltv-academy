Not every interaction needs a full record edit. This lesson covers actions and quick actions — the shortcut buttons that let a user log a call or create a related record in two clicks instead of ten.

Here's the full catalog of what's available to add to any page: standard actions like Log a Call, New Task, and New Case, sitting right alongside any custom quick action your org has built. This is the palette publisher layouts and page layouts both pull from.

The plus icon in the header opens Global Actions — available from literally anywhere in the org, with no record context required. New Event, New Campaign, New Contact: none of these need you to already be looking at a specific record.

On a record page, it's different. The action overflow menu is scoped to that specific object — Submit for Approval, Change Owner, Sharing Hierarchy. These only make sense in the context of the record you're already looking at.

So: a global action needs no record context at all. An object-specific action is scoped to one object type. A quick action, either kind, is just a shortcut — fewer fields than the full record, built for speed. And the publisher layout is what actually controls which of these show up, and where.
