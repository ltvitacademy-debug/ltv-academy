Lesson 1 covered what an app is. Now let's actually build one — start to finish, no code, using the wizard built into Setup.

From Setup, search App Manager, and click New Lightning App. The wizard walks you through four stages: Details — name, description, icon, color; optional custom branding; Navigation Items — which tabs to include; and User Profiles — who's allowed to open it.

Navigation Items is the stage that actually defines the app's content. You move objects and pages from Available Items into Selected Items, then reorder them — that ordered list becomes the app's tab bar, exactly as users will see it.

Once you save, the app is live. It gets its own nav bar — app name on the left, the app picker next to it, and your chosen tabs running across the top in the order you set them.

And it's immediately discoverable: open the App Launcher, search the app's name, and there it is, sitting right alongside Sales and Service like it's always been part of the org.

That's the whole build: four wizard stages, zero code. Next, before you build the next one, we'll slow down and talk about how to actually decide what an app should contain in the first place.
