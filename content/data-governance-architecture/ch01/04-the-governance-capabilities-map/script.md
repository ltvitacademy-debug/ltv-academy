# Lesson 4 — The Governance Capabilities Map · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

A capability map lists what an organization needs to be able to do, separate from who does it or which tool does it. Let's build the one this course uses for governance.

## S2 · STEPS — What vs. who

A capability is what the organization needs to be able to do. Implementation — who does it, which tool does it — is a separate question entirely. The map stays the same no matter the answer.

## S3 · STEPS — Eight domains, part one

The first four domains: metadata management — knowing what data exists and what it means. Cataloging and discovery — letting people actually find it. Lineage tracking — where it came from and everywhere it flows. Classification and labeling — tagging what kind of data something is.

## S4 · STEPS — Eight domains, part two

The next four: access control and enforcement — turning classification into real permissions. Data quality management — measuring whether data is accurate and consistent. Stewardship workflow — routing approvals to the right owner. And audit and monitoring — a record of what actually happened.

## S5 · CODE — Where this course covers each one

This course doesn't cover all eight equally everywhere. Chapter 3 goes deep on metadata, cataloging, and lineage. Chapter 4 covers classification and access control. Quality and stewardship practice were already covered in Foundations. Audit and monitoring cuts across the later chapters.
