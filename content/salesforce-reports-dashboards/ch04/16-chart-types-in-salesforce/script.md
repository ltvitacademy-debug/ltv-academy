# Script — Chart Types in Salesforce

## Segment 1 (title)

Salesforce gives you a fixed set of chart types. That's a limit, but it also means the choice is manageable if you match each type to the question it answers.

## Segment 2 (screenshot: picker)

This is the Display As grid from a real Lightning chart dialog. Each icon is a chart type. Notice a few are greyed out. This report, Opportunities by Stage, has only one grouping, and the stacked variants need a second one. So a greyed-out option usually means the report is missing a grouping, not that something is broken.

## Segment 3 (steps: which chart)

Here's how to choose. Bars compare categories, and they are your default. Lines show change over time. Donuts show parts of a whole, but only with a few slices. Funnels show records narrowing through ordered stages. Scatter plots relate two measures. And dashboards add a metric for one big number, and a gauge for a number against a target.

## Segment 4 (screenshot: donut)

Here's a donut on a real Leads dashboard. Lead Source slices, with the total record count of twenty-two in the center. Lightning uses donuts where Classic had pies. It reads well because there are only four slices.

## Segment 5 (steps: limits)

Be honest about the limits. The set of types is fixed, so no maps or heat maps. Styling is modest. Too many slices ruin a donut, so filter or combine small groups. And a chart is only as good as the report behind it.

## Segment 6 (outro)

When you need richer visuals, that's where CRM Analytics and Tableau come in later in this path. Next up: formatting for readability.
