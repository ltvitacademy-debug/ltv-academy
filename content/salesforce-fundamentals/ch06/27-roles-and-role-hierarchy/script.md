# Script — Roles & the Role Hierarchy

## Segment 1 (title)

Licenses set the outer ceiling on access. This lesson covers the next layer: roles, and the Role Hierarchy — the mechanism that decides which individual records a user can actually see.

## Segment 2 (code: the org chart as a tree)

A Role Hierarchy is a tree that generally mirrors the real org chart. The core rule: visibility flows upward. A Sales Manager sees their own records plus every record owned by the reps beneath them, automatically, with no manual sharing required.

## Segment 3 (steps: up, not sideways)

Visibility doesn't flow sideways or downward by default. Two reps at the same level, reporting to the same manager, don't automatically see each other's records — only the manager above sees both. That's often why two people running the same report get different numbers, and it's not a data bug.

## Segment 4 (outro)

Roles decide what records a user can see. Next up: Profiles and Permission Sets — what a user can actually do, not just which records they can see.
