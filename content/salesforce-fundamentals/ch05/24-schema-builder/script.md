# Script — Schema Builder

## Segment 1 (title)

You've learned Lookup, Master-Detail, and junction objects as concepts you have to hold in your head. Salesforce also gives you a tool that draws the whole thing as an actual diagram: Schema Builder.

## Segment 2 (screenshot: a real object card)

This is a real object card from Salesforce's own Schema Builder documentation. Look at the field-type column: Master-Detail(Property), Lookup(User) — the exact relationship types from the last two lessons, labeled right on the row, no guessing required.

## Segment 3 (steps: why look first)

Schema Builder lays objects out as connected cards on a canvas instead of forcing you to click through Object Manager one object at a time. As an analyst, you don't need to build anything in it — you need to read it: which objects connect, and whether each link is Lookup or Master-Detail, in about two minutes instead of trial and error.

## Segment 4 (outro)

You now have all three relationship types, plus a tool to see them visually. Next up: putting it all together on a real worked example — reading an actual org's data model before writing any query.
