# Lesson 17 — Cloud Security and Compliance Frameworks · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE CARD

Cloud Security and Compliance Frameworks — an orientation to how cloud platforms
track compliance, not legal or compliance advice for your specific organization.

## S2 · SCREENSHOT (compliance drilldown)

Microsoft Defender for Cloud's Regulatory compliance dashboard tracks multiple
standards at once. Selecting one shows its controls; selecting a control shows
exactly what's being checked.

## S3 · SCREENSHOT (control detail)

Every control splits into automated checks the platform runs itself, and manual
items that need a person to attest, with evidence attached.

## S4 · SCREENSHOT (sample recommendation)

A failed control resolves all the way down to real resources — here, the exact
virtual machines currently missing disk encryption.

## S5 · STEPS (framework, controls, assessment)

The shape repeats across every framework: a standard defines controls, controls get
assessed — automated or manual — and that rolls up into a compliance score.

## S6 · OUTRO CARD

Next up: Azure Policy — the mechanism behind many of those automated checks.
