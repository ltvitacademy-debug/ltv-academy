# Script — Capstone: A Project With a Real GitHub Workflow

## Segment 1 (title)

Everything from this course, applied to a real repository of your own. This capstone proves you can run a project through a real GitHub workflow, start to finish, without a lesson walking you through each step.

## Segment 2 (steps: five deliverables)

Real history with a feature branch, a pull request, and a deliberately resolved merge conflict. A reviewed pull request with a real description and an addressed inline comment. A written branching choice and an annotated release tag. And a real CI/CD workflow: tests on every PR, a deploy job gated to only run on a real merge to main.

## Segment 3 (steps: what done looks like)

A stranger should be able to open the Actions tab and see real runs with real pass and fail history, open the pull requests, and understand exactly how this project is built, reviewed, and shipped — without you explaining anything out loud.

## Segment 4 (steps: a realistic order)

Get the project working locally first. Set up .gitignore and your branching note early, not after fifty commits. Do the branch-PR-conflict cycle for real before adding any automation, then add CI once there's something real for it to validate.
