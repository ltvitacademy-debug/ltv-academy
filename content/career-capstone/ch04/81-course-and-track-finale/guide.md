## The track, from the top

Four courses, each building on the last, each teaching a real layer of
the same overall job:

```
1. Data Engineering Foundations
   The vocabulary and first tools: what a pipeline is, how data moves.

2. Azure Databricks & Delta Lake
   Where that pipeline actually runs at scale: Delta tables, ACID
   transactions, medallion architecture, MERGE INTO, Structured Streaming.

3. Microsoft Fabric & Real-Time Analytics
   A second, unified platform for the same work, plus the real-time half
   this track hadn't covered yet: Eventstreams, KQL, windowing, Activator.

4. Data Engineering Career & Capstone (this course)
   System design thinking to plan any of it, DP-700 certification prep,
   AI as a tool alongside the craft, and three capstone projects that
   prove all three earlier courses actually compose into real systems.
```

This course's own Chapter 1 gave you the vocabulary to *design* a system
before building it — Kappa vs. Lambda, grain, idempotency, delivery
guarantees. Chapter 3 was honest about where AI genuinely helps in that
work (drafting documentation, generating starter notebooks, explaining a
gnarly KQL query) and, just as importantly, where it doesn't — the
judgment behind a trade-off decision is still yours to make and defend,
which is exactly what Lesson 80 just had you practice out loud.

## Three projects, one arc, proven

Project 1's retail analytics platform, Project 2's warehouse migration,
and Project 3's streaming fraud detector weren't three disconnected
exercises — together they're evidence that batch pipelines, a real
migration with a real cutover, and a sub-second streaming system can all
be built with the same underlying toolkit this track taught. That's the
whole point of a capstone: not new material, but proof the earlier
material actually works, on your own systems, that you can explain
end to end.

Lesson 79 turned those three projects into a portfolio; Lesson 80 turned
their retrospectives into an interview story. Both of those are now
yours to use — not homework, but the actual evidence you bring to a job
search.

## Where to go from here

This track is a complete, real foundation — and it's also a foundation,
not a ceiling. A few directions worth knowing exist, if you want to keep
building:

| Direction | Where it lives in the catalog |
|---|---|
| Deployment and CI/CD discipline for data pipelines | The Git/GitHub/CI-CD course |
| Infrastructure as code for the platforms you just learned | Terraform and Bicep-focused material building on this track's IaC mentions |
| Orchestrating pipelines at scale, beyond a single platform | The Airflow course |
| Event streaming beyond a single vendor's Eventstream | A Kafka-focused course, for the vendor-neutral version of Lesson 76's ideas |

None of these are required to call this track finished. They're there
for whenever the next system you want to build asks for them.
