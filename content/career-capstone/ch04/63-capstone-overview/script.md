# Script — Capstone Overview: What You'll Build

## Segment 1 (title)

Three capstone projects, built in sequence, each one forcing everything from this track — system design, Databricks, Fabric, and the exam material — to work together on a single real system.

## Segment 2 (code: the three projects)

Project 1 is a real-time retail analytics platform. Project 2 is a multi-source data warehouse migration. Project 3 is a streaming fraud detector. They're sequential, not parallel — each one is a complete small system, not a toy exercise.

## Segment 3 (steps: kickoff, build, wrap-up)

Every project runs the same shape: a kickoff that applies Chapter 1's system-design process, build lessons that go layer by layer — ingestion, transformation, serving — a hardening lesson for production concerns, and a wrap-up retrospective.

## Segment 4 (code: why citations matter)

Every build lesson names the specific prior lesson a decision comes from. A project you can't explain using specific, named techniques is one you copied steps for, not one you understood — and that's exactly what Lesson 24's whiteboarding practice is training you to avoid.

## Segment 5 (outro)

Three projects, one format: kickoff, build, wrap-up. Next up: Project 1 kickoff — scoping a real-time retail analytics platform from scratch.
