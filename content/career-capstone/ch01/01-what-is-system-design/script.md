# Lesson 1 — What Is System Design, for Data Engineers? · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

What is system design, for data engineers — welcome to the final
course in this track.

## S2 · CODE CARD (a different kind of question)

Every course so far asked how to build one thing correctly. System
design asks a different question — given a problem with no
prescribed tools, which pieces do you choose, and why, before
writing any code at all.

## S3 · CODE CARD (borrowed building blocks)

Nothing here is a brand-new tool. Every building block comes from
the three courses before this one — python and SQL, delta lake and
structured streaming, eventstreams and KQL. This chapter is about
when and why to reach for each one.

## S4 · OUTRO CARD

That's the actual skill a senior data engineer uses daily, and the
skill a real interview actually tests. Next up: requirements
gathering — the first question in any real design.
