# Lesson 2 — Requirements Gathering · Voiceover script

Segments map 1:1 to slides. Target: ~2.5-3 minutes total.

---

## S1 · TITLE CARD

Requirements gathering — functional versus non-functional, the
first real question in any design.

## S2 · CODE CARD (two kinds of requirement)

A functional requirement is what the system does. A non-functional
requirement is how well it has to do it — speed, reliability,
cost. Neither one is enough by itself.

## S3 · CODE CARD (turning vague into real)

A vague prompt like analyze NYC taxi trips doesn't specify
anything real yet. Who's it for? How fresh does it need to be? How
many trips a day? Every answer leads to a different correct
design.

## S4 · OUTRO CARD

This is exactly where a real SLO's number comes from in the first
place. Next up: back-of-the-envelope estimation — turning these
requirements into real numbers.
