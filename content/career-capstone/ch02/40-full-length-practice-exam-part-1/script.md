# Script — Full-Length Practice Exam, Part 1

## Segment 1 (title)

This is a timed, mixed-domain practice set — the first half of a full mock exam split across this lesson and the next. Nothing new is taught here; it's nine questions back-to-back, the way the real exam mixes domains.

## Segment 2 (code: how to take it)

Set a timer for about eighteen to twenty minutes before you start. Answer all nine questions first, without checking explanations along the way, then review every explanation in one pass at the end — exactly how the real exam works.

## Segment 3 (steps: what this set covers)

Domain 1 questions on Lakehouse versus Warehouse, OneLake shortcuts, and Direct Lake Mode. Domain 2 questions on Eventstream ingestion and a Delta merge pattern for slowly changing dimensions. Domain 3 questions on the narrowest-control pattern and the monitoring-versus-deployment pattern.

## Segment 4 (code: score and sort)

After finishing, score yourself, then sort your misses by domain. If misses cluster in one domain, that's the signal to go back to that domain's chapter before the second half.

## Segment 5 (outro)

One mixed-domain set down. Next up: the second half — different questions, same format, completing the full mock exam.
