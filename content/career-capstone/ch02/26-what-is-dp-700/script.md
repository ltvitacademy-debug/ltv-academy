# Script — What Is the DP-700 Certification?

## Segment 1 (title)

DP-700 is Microsoft's associate-level exam for the Fabric Data Engineer role. It validates exactly the Fabric skills from Course 3 of this track — Lakehouses, Warehouses, Eventstreams, KQL, notebooks, and the pipelines that connect them.

## Segment 2 (code: exam format)

Scoring is reported on a one-to-a-thousand scale, with Microsoft's passing threshold set around seven hundred. That's where the certification's number comes from — not the question count. The exam mixes standalone questions with case studies: shared scenarios followed by several questions about them.

## Segment 3 (steps: two question styles)

Standalone questions test one fact at a time. Case studies give you a page of background about a fictional company's data platform, then ask several questions that all reference that same scenario — the "given this scenario, which of the following" style you'll drill starting in Lesson 31.

## Segment 4 (code: what this chapter does)

This chapter doesn't teach anything new — it reviews what Courses 1 through 3 already covered, organized the way Microsoft organizes the exam. When a lesson here cites "Fabric Lesson 21" or "Databricks Lesson 15," that's pointing you back to where it was actually taught.

## Segment 5 (outro)

DP-700 assumes hands-on Fabric experience, not a prerequisite exam. Next up: the exam's three official domains and how much of the exam each one is worth.
