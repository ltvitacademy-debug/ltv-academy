# Lesson 41 — Full-Length Practice Exam, Part 2

**Chapter 2 · DP-700 Certification Prep · Lesson 41 of 81**

## What you'll learn

- Nothing new — this is the second half of the mock exam started in
  Lesson 40, with a different set of nine questions covering the ground
  Part 1 didn't
- Together, Lessons 40 and 41 add up to eighteen questions spanning all
  three DP-700 domains — a realistic-scale mock exam, not a short quiz
- How to do a proper post-mortem across *both* halves once you've
  finished this one

## Keep the same discipline as Part 1

Same format as Lesson 40: set a timer for roughly 18-20 minutes, answer
all nine questions before checking any explanation, then review every
explanation in one pass. If you took Part 1 in a single sitting, take
this one in a separate sitting with a real break in between — back-to-
back with no break isn't how the actual exam works, and it isn't how
your stamina on exam day will work either.

## What this set covers

This half leans slightly more into Domain 3 and the security/governance
material, while still mixing in Domain 1 and Domain 2 questions, so the
combined Part 1 + Part 2 set covers all three domains close to their
real ~30-35% weighting:

- Dataflow Gen2 versus Data Factory pipelines — when transformation-
  first beats orchestration-first (Domain 2)
- KQL `summarize` for a time-windowed aggregation (Domain 2)
- Sensitivity labels surviving an export, revisited with a twist
  (Domain 3)
- Access reviews and least privilege in a staffing-change scenario
  (Domain 3)
- Blue-green deployment for a pipeline change with a fast-rollback
  requirement (Domain 3)
- Observability (logs/metrics/traces) versus the Monitoring Hub, in a
  root-cause scenario (Domain 3)
- A CAP-theorem-adjacent trade-off question connecting back to this
  course's Chapter 1 system design material (Domain 1)
- A lookalike-item-type trap combining Eventstream and Eventhouse
  (Domain 2)
- A buried-qualifier question where the last clause of the stem changes
  the correct SKU/capacity choice (Domain 1)

## The real post-mortem: both halves together

Once you've scored Part 2, combine your miss list with Part 1's. Sort
the combined eighteen by domain, the way Lesson 38 described. This
combined view is more reliable than either half alone — a single miss
in a domain might be noise, but the same domain showing up across both
halves is a real signal about where to spend your remaining study time.
