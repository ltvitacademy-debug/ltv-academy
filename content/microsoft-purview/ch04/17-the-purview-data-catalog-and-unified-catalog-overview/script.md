# Lesson 17 — The Purview Data Catalog and Unified Catalog Overview · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

Chapter Four is Catalog and Glossary — and it starts with the Microsoft Purview Data Catalog and its modern Unified Catalog experience.

## S2 · STEPS — Data Catalog, Unified Catalog, Data Map

Three names come up constantly here, and they're not interchangeable. Data Catalog is the solution area in the Purview portal's left navigation. Unified Catalog is the modern, business-friendly governance experience that lives inside it. And Data Map is the separate solution that actually scans your sources and feeds everything the catalog shows.

## S3 · SCREENSHOT — The Purview portal home page

This is the Microsoft Purview portal home page. Data Catalog is one of the solution cards here, alongside Information Protection, Data Loss Prevention, and Insider Risk Management — Purview is one portal with many solutions, and Data Catalog is the one this chapter lives in.

## S4 · SCREENSHOT — Data Map and Data Catalog side by side

Data Map and Data Catalog sit side by side in that solutions row. Data Map scans and inventories your sources — SQL Server, Azure Data Lake, Snowflake, Fabric, and dozens more. Data Catalog is where people actually find, understand, and govern what Data Map found.

## S5 · SCREENSHOT — Grouped under Data Governance

The full solutions page groups Data Catalog under Data Governance, and describes it plainly: find and curate data across your org with this searchable inventory of data assets and metadata.

## S6 · STEPS — What Unified Catalog adds

What Unified Catalog adds on top of the raw technical map is business context. Governance domains group data by business area — Finance, Sales, HR. Data products and glossary terms give that data curated, discoverable meaning. And lineage, insights, and policies tie it all together — trust, health, and access, in one place.
