# Lesson 33 — Purview Case Study: Enterprise Rollout · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Thistledown Retail Group, a fictional mid-sized retailer, has four regional distribution centers, each with its own spreadsheet defining SKU and in-stock — and nobody at the corporate level can say what data exists, where it lives, or who can see it.

## S2 · STEPS CARD (the scenario)

Four regions, four spreadsheets, zero shared picture. No catalog, no shared definitions, no way to know what's actually out there.

## S3 · STEPS CARD (Ch 1-3 applied)

Chapter 1: collections set up per region, roles assigned. Chapter 2: every source registered and scanned on a schedule, including tracking down a firewall rule blocking one region's scan. Chapter 3: classifiers flag a legacy table still storing partial card numbers, and sensitivity labels get applied consistently across all four regions.

## S4 · STEPS CARD (Ch 4-6 applied)

Chapter 4: one glossary-defined SKU instead of four competing versions. Chapter 5: lineage traces the real path from pipeline to Power BI report, and insights surface exactly which sources still have no owner. Chapter 6: an access policy, a self-service workflow, a data quality rule catching a feed error in a day, and a publish approval workflow — all actually running.

## S5 · OUTRO CARD

Six months in, any analyst in any region can search one catalog, trust one SKU definition, and request access without a ticket — because the rollout touched every layer of this course, in the order it taught them. Next: a hands-on practice lab applying all six chapters yourself.
