# Lesson 32 — Purview and Compliance Features Overview · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

---

## S1 · TITLE CARD

Everything this course has covered — the Data Map, the catalog, policies, workflows — lives inside the same Purview portal as a much wider set of solutions. This lesson is an orientation to that bigger picture, not a new skill.

## S2 · SCREENSHOT (portal home)

The portal's home page makes the breadth visible immediately: governance solution cards sit right next to cards for Information Protection, Data Loss Prevention, and Insider Risk Management.

## S3 · SCREENSHOT (solution cards)

Data Map and Data Catalog are what this course has spent six chapters on. Information Protection, Data Loss Prevention, and Insider Risk Management are different solutions entirely, with their own setup and their own specialists.

## S4 · SCREENSHOT (solutions page)

The full Solutions page groups everything into four sections: Core, Risk and Compliance, Data Governance, and Data Security. This course lives entirely inside one of those four.

## S5 · SCREENSHOT (compliance posture)

One card is worth naming specifically: Compliance posture status, a score from a separate solution called Compliance Manager. It's a real, useful score — but it's an assessment-tracking number, not a legal determination of regulatory compliance.

## S6 · OUTRO CARD

Whether an organization's data handling actually satisfies a given regulation is a call for qualified legal and compliance professionals, not a dashboard. Next: Lesson 33, a case study pulling this whole chapter together.
