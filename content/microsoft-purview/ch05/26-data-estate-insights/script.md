# Lesson 26 — Data Estate Insights · Voiceover script

Segments map 1:1 to slides. Target: ~2-3 minutes total.

## S1 · TITLE

We've scanned, classified, curated, and traced lineage across four and a half chapters. This lesson is where Purview turns all of that into dashboards — automatically.

## S2 · STEPS — Three sections, not reports you build

Every dashboard falls into one of three sections. Health — curation, ownership, and adoption rates, for a Chief Data Officer. Inventory and ownership — what's actually in the catalog, and its state. Curation and governance — glossary, classification, and sensitivity label coverage. Nobody builds these by hand — they're generated automatically from whatever you've already scanned.

## S3 · SCREENSHOT — Three sections, six reports

Health, Inventory and ownership, Curation and governance — three sections, six named reports underneath. One naming note: the classic portal called this whole application Data Estate Insights. The current portal moved it into Data Catalog, under Data Estate Health and Reports — same dashboards, new location.

## S4 · SCREENSHOT — Health, where a CDO starts

Three gauges tell the whole story at a glance. Asset curation — mostly not curated, here. Asset data ownership — one hundred percent with no owner. Catalog usage and adoption — nineteen monthly active users. The table underneath breaks those same numbers down per collection, so a steward can find exactly which one is dragging the org-wide number down.

## S5 · SCREENSHOT — Inventory and ownership

The Assets report answers a narrower question: what's in the catalog, and what state is it in. Total assets, unclassified percentage, unassigned ownership, net new and deleted in the last thirty days — with a View Detail path straight into the actual assets behind each percentage, not just the number itself.

## S6 · SCREENSHOT — Curation and governance

Classification insights, as one example: total assets classified, files versus tables, unique classifications found, and which categories — Financial, Personal, Government — actually show up most, and where. This is the starting point for deciding what needs tighter access controls.

## S7 · STEPS — From metrics to assigned work

A dashboard shows you the gap. The newer Health Management Actions page turns each gap into an actual task: a finding type, a severity, a target entity, and an assigned owner. The owner investigates, fixes it, and marks it Resolved — but the next scheduled refresh re-checks the catalog, and reopens the action automatically if the underlying issue is still there.

## S8 · OUTRO

Chapter Five closes with one more lesson: reports and dashboards — the mechanics of how these insights actually get shared and exported.
